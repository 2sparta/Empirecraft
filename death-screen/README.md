# Epic Death Screen для Empirecraft

Клієнтський мод із наданого `epicdeathscreen_forge_1.20.1_1.1.0_beta.2.jar`
оновлено до локальної версії **1.1.0-beta.2-empirecraft.1**. Оригінал із
SHA-256 `a54e337cd4879c410aa67a4bfb4d158268880dec49f11ee14ca61971c6a35107`
збережено в `native-inputs/`. Ліцензія MIT та авторські відомості збережені.

Встановлюйте новий JAR у **клієнтську** папку `mods/`. На сервері потрібен
лише оновлений список дозволених модів ADM із комплекту. Серверний мод,
додатковий процес або бібліотека не потрібні. Приберіть іншу версію
Epic Death Screen, якщо вона вже встановлена. Готовий комплект —
`dist/Empirecraft-Epic-Death-Screen-1.zip`.

## Додані причини смерті

Усі **39 типів шкоди**, наявні у ресурсах установлених модів, мають окремі
фрази. Серед них — бур, пилка, прес, каток, поїзд і картопляна гармата Create;
ядра, шрапнель, картеч та розплавлений метал Create Big Cannons; мушкет;
бомби, рогатка й бамбукові шипи Supplementaries; зброя Epic Knights;
гаряча плита, окріп, замок із розрядом, наслідки надмірного пиття;
морський їжак, вулкан, висихання та удар чи вибух кита.

Також є **20 профілів сутностей**: рекрути й командири, стрільці,
кавалеристи, облогові машини та їхні камені, ядра й великі стріли.
Падіння кокоса визначається за блоком усередині падаючої сутності.
Повний перелік і фрази — у `catalog.json`; перевірені визначення шкоди —
у [звіті](../validation/epic-death-screen-1.json).

Пріоритет: точний тип шкоди → падаючий блок → безпосередній снаряд →
нападник. Тому бомба рекрута має фразу про бомбу, а не про його меч.
Звичайні стріли рекрутів визначаються за власником. Якщо потрібної інформації
немає на клієнті або причина невідома, залишається звичайна тема мода.
Смерті від невикористовуваних ресурсів і лише наявних рядків перекладу
не видаються за нові типи шкоди.

## Звуки, мови та налаштування

Додано **16 коротких звукових ефектів** із субтитрами: механізм, поїзд,
ядро, постріл, вибух, сталь, шипи, пара, розряд, серцебиття, сухий вітер,
підводний удар, вулкан, витягування досвіду, удар і стріла. Це власні
синтезовані ефекти; початкові записи й їхні ліцензії збережені.

Ефект причини програється один раз разом із початковими звуками сцени.
Гучність задається параметром **«Звуки касети»**; нуль вимикає ці ефекти.
Закриття, пропуск, завершення сцени та переривання через відродження
зупиняють її звук. Зміна розміру вікна не запускає його повторно.
Початкові налаштування автоповернення, hardcore та сумісність із системами
порятунку гравця збережені.

Російські початкові фрази збережені; нові фрази й субтитри перекладені.
Додано український інтерфейс, усі початкові теми, нові фрази та субтитри.
Мова береться з налаштувань Minecraft, також збережено англійську.

Власні фрази: `config/epicdeathscreen/phrases/uk_ua.txt` або `ru_ru.txt`.
Український шаблон створюється автоматично. Файли гравця не перезаписуються.
Приклад:

```ini
[damage:musketmod:bullet]
Куля знайшла свою ціль.

[entity:recruits:bowman]
{attacker} виявився влучнішим.
```

Зміни читаються з наступної смерті або перегляду. Налаштування
`phrases=replace` залишає власні фрази зі стандартним запасним варіантом.

## Відтворення й перевірка

Потрібні JDK 17, Python 3 та підготовлений SDK `sails/build/` зі справжнім
клієнтським API Forge/Minecraft 1.20.1. Збережіть установлений Sails,
підготуйте SDK через `sails/build.py --sails-only` та поверніть оригінальні
встановлені JAR Sails, перш ніж збирати реліз.

```sh
python3 death-screen/build.py
python3 death-screen/test.py
python3 death-screen/release.py
```

OGG вже збережені в ресурсах. Для їх відтворення з початкових хвиль потрібен
FFmpeg із libvorbis: `python3 death-screen/tools/generate_audio.py`.
Генератор закріплює випадкові послідовності й серійні номери OGG.

Перевірки використовують справжній початковий парсер фраз, таблиці шкоди
встановлених модів та JVM-перевірку класів проти справжнього клієнтського API.
Всі OGG декодуються FFmpeg; незмінені класи й початкові звуки порівнюються
побайтово з оригіналом. Звіт окремо зазначає межі: графічний клієнт і живе
прослуховування не запускалися.
