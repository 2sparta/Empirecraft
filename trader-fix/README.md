# Торговці та вирізані предмети

Мандрівний торговець більше не намагається пити зілля невидимості вночі.
Видалено його дію пиття зілля; денне пиття молока збережено. Якщо старий
торговець збережений із пляшкою в руці, під час завантаження вона прибирається.

Напис **Uncraftable Steel Arrow** мав окрему причину: Overgeared вважав
будь-яку стрілу з додатковим NBT предметом без ефекту зілля. Звичайні стріли
з даними якості тепер мають звичайну назву свого матеріалу. Їхні бойові
характеристики та рецепти збережені.

Перевірка обмінів використовує чинні списки вилученого вмісту. Вона охоплює
обидві складові ціни та результат. Початковий заборонений предмет запам'ятовується
перед міграцією, тому пропозиція зі стрілою з ефектом чи зачарованою книгою
не перетворюється на продаж звичайної стріли або книги за старою ціною.
Ця позначка існує лише в пам'яті сервера та не додає тегів до предметів гравців.

Нові пропозиції перевіряються перед додаванням до торгівлі. Уже збережені
пропозиції очищуються під час відкриття. Недійсні обміни, які після старої
міграції лише повертають той самий предмет за додаткову плату, теж прибираються.
Дозволені обміни зберігають кількість використань, попит, знижки та запас.
Звичайні залізні й сталеві стріли, вода та напої модів залишаються доступними.
Із власного переліку товарів також прибрано три раніше вилучені сирі руди
Boomsticks. Уніфікацію звичайних металів збережено.

## Встановлення

Зупиніть сервер і клієнт. Із `dist/Empirecraft-Trader-Fix-1.zip` скопіюйте
`client/` у клієнт, а `server/` — у серверну збірку, замінивши файли.
`empirecraft-world-rules-1.0.2.jar` потрібен лише серверу;
`empirecraft-forging-1.1.3.jar` оновлюється на обох сторонах.
Застосуйте комплектний ADM разом із відповідними клієнтськими файлами.
Світ, торговців та їхні дозволені обміни видаляти не потрібно.

Пакет також містить актуальний Locks із попереднього оновлення, щоб його
клієнтський JAR відповідав комплектному ADM. Якщо він іще не встановлений,
видаліть старий `Locks-SteelOnly-forge-1_20_1-1_2_4_nogen (1).jar` та його
контрольну суму з обох каталогів `mods/`.

## Перевірка

`validation/trader-cut-items.json` фіксує точні JAR та результати двох запусків
тимчасового Mohist зі всім установленим серверним набором модів. Перевіряються
реальна ніч із нашим календарем, відсутність пиття протягом багатьох тактів,
старі пляшки, обидві складові ціни, заборонені результати, назви звичайних
стріл із NBT, напої та перезапуск світу.

Для аудиту торгових пропозицій беруться кілька випадкових варіантів кожного
доступного шаблону професій і мандрівного торговця. Генератори карт скарбів,
які виявляються за класом або вкладеним постачальником, пропускаються й явно
перелічені у звіті. Це обмеження аудиту не вимикає їхню штатну торгівлю.
Виробничі світи не використовувалися. Графічний клієнт вручну не запускався;
Mixin назви стріл перевірено на обох фізичних сторонах.

```sh
python3 trader-fix/catalog.py --check
python3 world-rules/build.py
python3 forging-balance/build.py
python3 world-rules/test.py --classpath-dir server/libraries --classpath-dir server/mods
python3 forging-balance/test.py
python3 trader-fix/native.py --java /path/to/java21
python3 trader-fix/release.py --check
```

Для компіляції потрібен JDK 17 у `JAVA_HOME` і `PATH`; для native-тесту —
окремий Java 21. Використовується підготовлений SDK `sails/build/`.
Код виправлення міститься у `world-rules/`, `forging-balance/` та цьому каталозі.
