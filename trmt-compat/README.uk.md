# Стежки, які пам’ятають ґрунт

TRMT empirecraft.2 підтримує 38 поверхонь: ґрунти, дерен, глину, торф і каолін TFC, сім кольорів піску TFC, чорнозем Empirecraft, червоний пісок і глину Minecraft. Рілля й мокрий ґрунт залишаються поза протоптуванням.

Гравці, вершники та тварини на повідку залишають рівні стежки з п’ятьма стадіями піксельного зносу. На дерені поступово проступає місцевий ґрунт, а на відкритому ґрунті й піску окремі пікселі темніють. Діють налаштування порогів, множників і часу заростання `config/trmt.json`. Стояння на місці не зношує землю.

Кожний тип стежки кодує початковий блок. Повний стан початкового блока та лічильники зберігаються у Forge capability відповідного чанка, окремо для кожного виміру. Після заростання повертається початковий ґрунт; будівництво чи руйнування стежки прибирає її історію. Додаткових блокових сутностей, примусових завантажень чанків та сканування світу немає. При копанні діє випадіння предметів початкового ґрунту.

**Уже перетворені старою версією стандартні стежки TRMT втратили походження.** Вони зберігають попередню поведінку; автоматично визначити їхній колишній ґрунт неможливо. Нові стежки мають пам’ять від першого протоптування.

Встановлюйте однаковий JAR empirecraft.2 на сервер і всі клієнти. Нові блоки потребують узгодженого комплекту.

Відтворення:

```sh
python trmt-compat/build_remembered.py --base trmt-compat/upstream/trmt-0.5.1b-1.20.1-forge-empirecraft.1.jar --reference-repo /path/to/reference --sdk /path/to/sdk --jdk /path/to/jdk17 --test
```

`audit/remembered-runtime.json`: 76 сценаріїв справжнього обробника ходіння та 76 перевірок після перезапуску JVM. `audit/remembered-client.json`: запуск Forge-клієнта та перевірка 760 моделей. Тести використовують лише позначені тестові світи.
