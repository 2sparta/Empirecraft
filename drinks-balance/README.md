# Empirecraft: напої та реальна витримка вина

Нативні зміни в Brewin’ and Chewin’ 3.2.1 та Vinery 1.4.41, Minecraft 1.20.1 Forge. Готові JAR установлені в `mods/` і `server/mods/`; обидві сторони мають отримати однакові файли. Попереднє очищення рецептів Create у B&C збережено. Версії в `mods.toml` збережені для сумісності; маркер патча — у назві JAR і `META-INF/empirecraft-drinks.json`.

## Рецепти без Незеру

Нагрівальна бочка: **казан по центру** замість порошку іфрита, **багаття знизу по центру** замість магми. Решта схеми незмінна.

| Рецепт | Заміни інгредієнтів |
|---|---|
| Dread Nog | Незерський наріст → коричневий гриб; мариноване павуче око → отруйна картопля |
| Red Rum | Багряний гриб → червоний гриб; наріст → буряк; мариноване око → коричневий гриб; грибосвіт → світні ягоди |
| Steel Toe Stout | Багряний гриб → червоний гриб; наріст → буряк |
| Withering Dross | Троянда візера → конвалія; наріст → отруйна картопля |
| Scarlet Cheese | Багряний гриб → червоний гриб; наріст → буряк |
| Scarlet Pierogi | Наріст → буряк |
| Cristel Wine | Стрижень іфрита → кроляча лапка |
| Подвоєння прапора Vinery у ковальському столі | Незеритовий злиток → золотий злиток; незеритовий шаблон → папір |

Світлопил збережено, зокрема в Glittering Grenadine та Mellohi Wine. Температура, кількість і тривалість бродіння не змінюються. Нативні досягнення для відкриття рецептів також оновлені.

## Вилучені вина

**Chorus Wine** (телепортація) та **Clark Wine** (подвійний стрибок) більше не реєструються як блоки або предмети. Вилучено рецепти, моделі, блокові loot tables, записи творчого меню, посилання з тегів, луту та вимоги досягнень. Внутрішні поля модифікації спрямовані на Red Wine, тому випадкові нативні споживачі та торговці не отримують відсутній RegistrySupplier. Старі блоки й предмети переносяться в **Red Wine** через MissingMappingsEvent.

## Витримка

- Місяць визначений як **30 × 24 години** реального часу.
- Свіже вино: **I рівень**, 1 хв 20 с. Тривалість плавно зростає до **12 хвилин** за 30 діб.
- Рівно через 30 діб: **II рівень**, він максимальний. Подальша витримка не підвищує силу чи тривалість.
- Дата розливу `EmpirecraftBottledAtMs` записується в NBT **до** збереження або викидання готової пляшки з бочки. Повторне штампування не скидає дату. Пляшки різних дат не зливаються у старішу стопку; зайва пляшка використовує штатне викидання біля бочки.
- Час враховується в інвентарі, скринях, стелажах, непрогружених чанках і під час вимкненого сервера. При вживанні вік обчислюється за датою розливу, навіть якщо кеш давно не оновлювався. Немає потреби примусово завантажувати чанки.
- Сон, `/time set`, ігрові сезони та TPS не прискорюють витримку. Обчислення відбувається на сервері. Клієнт відображає синхронізований кеш; в інвентарі він оновлюється штатно приблизно раз на 10 секунд, а при знятті зі стелажа — відразу.
- Старі пляшки мають лише ігрове поле `Year`, яке неможливо достовірно перевести у реальний час. Для них відлік починається при першій серверній обробці після оновлення; старий високий рівень не переноситься. Старі непрочитані пляшки у скринях починають відлік після першого доступу.
- Відкат годинника не зменшує вже зафіксованої витримки. Коректність абсолютного часу залежить від системного годинника сервера.
- Напої зі штатною фіксованою короткою дією (наприклад Creeper’s Crush) залишають цю коротку дію; межі II та 12 хв для витримуваного вина задані в нативному коді незалежно від старого конфіга Vinery.

## Збірка та перевірка

`build.py` приймає тільки дві перевірені SHA-256 вхідних JAR із коміту `764a8a071ff77f9aa4fb56ccab94f68fbf302a16`. Каталоги classpath мають містити SRG runtime Minecraft/Forge 1.20.1, залежності Forge, Architectury і Vinery. Із JDK 17 використовується вбудований компілятор та ASM. Додатковий окремий мод для роботи не потрібний.

```sh
python drinks-balance/build.py --upstream upstream --classpath-dir runtime/toolchain --classpath-dir runtime/libraries --install
python drinks-balance/test.py --upstream upstream
python drinks-balance/smoke.py --upstream upstream --runtime forge-runtime --toolchain runtime/toolchain
```

Smoke-тест запускає окремий Forge-світ тричі: з оригінальними модами, після нативного вилучення вина та після імітації 30 діб вимкненого сервера. Перевіряються перенесення старих ID, творчі вкладки, NBT, межа 30 діб, максимальні значення, незалежність від ігрового часу та фактичний ефект випитого вина. Керований тестовий годинник існує лише через reflection у тестовому JAR; команди зміни віку в ігровий мод не додаються. Це перевірка Forge 47.4.23 з потрібними залежностями, а не повний запуск усіх плагінів живого Mohist-сервера чи графічного клієнта.

## Оновлення збірки

Заміни обидва старі JAR на файли `*-empirecraft-drinks.1.jar` **на клієнті та сервері**, перенеси оновлений ADM зі збереженням власних сторонніх записів і перезапусти гру та сервер. У репозиторії вже оновлені SHA-256, lock-файл, integrityHash ADM та інвентаризація сезонного моду. Старі й нові копії одного моду одночасно залишати не можна.
