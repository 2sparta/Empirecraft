# Сервер без Caupona

Пакет прибирає Caupona та його активні серверні інтеграції з поточної збірки після оновлення 3. Погоджені механіки TFC, Create, календар, LSO, броня, тварини й кораблі збережено.

## Що змінено

- Прибрано JAR Caupona, його конфіг, власні дерева worldgen та теги datapack, посилання в масах блоків, No End, сезонних тегах і вбудованих перекладах. Старі файли зберігаються поза активними папками.
- З природного відновлення та ринку саджанців вилучено сільфій, інжир, горіх і дерезу Caupona. Залишаються **32 дикі рослини та 24 записи дерев**, включно з ванільними; інжир Fruits Delight і горіх Ecologics працюють далі.
- Кулі виготовляються зі стрижнів заліза або чавуну: 50 одиниць → 5 заготовок. Рецепти нового свинцевого стрижня та окремого свинцевого маршруту прибрано. Старий реєстровий ID стрижня доповнення збережений для наявних предметів: їх можна витратити через залізний рецепт без нового джерела свинцю. Стрижень приховано з творчого списку, його текстура використовує Minecraft.
- Оновлено довідник: 334 статті, 1018 сторінок. Вилучено недоступні рослини та інструкції про новий свинець. ID книги й рецепт з одного паперу збережено.
- Серверний ADM більше не вимагає Caupona; оновлено хеші й версії спільних модів без зміни інших записів.

| Модуль | Версія | Сторони |
|---|---|---|
| TFC Integration | 1.0.3 | Клієнт і сервер |
| World Rules | 1.0.4 | Сервер |
| Calendar | 1.2.3 | Клієнт і сервер |
| Seasonal Leaves | 1.3.4 | Клієнт і сервер |
| No End | 1.0.1 | Клієнт і сервер |
| Pack Fixes | 1.0.1 | Клієнт і сервер |
| Handbook | 1.0.2 | Клієнт і сервер |

Для календаря, листя, No End і Pack Fixes всі Java-класи байтово збережено. У World Rules змінено лише списки рослин/торгівлі; генератор захисного коду змінив службове ім’я, його еквівалентність перевірена. У TFC Integration змінено лише видимість старого стрижня у творчому списку; решта класів, включно з одноразовою генерацією, залишилися тими самими. Базовий TFC 3.2.30 empirecraft.1 та TFC Muskets не замінюються.

## Установлення

Зупини гру й сервер, збережи копію світу: після вилучення Caupona його власні предмети та блоки більше не реєструються. Розпакуй `Empirecraft-Caupona-Removal-1-install.zip` в окрему папку. Не встановлюй старі архіви супровідних модів поверх цього пакета.

Запусти з розпакованої папки Python 3.11 або новіший:

```sh
python update_installation.py --server /шлях/до/сервера --apply
python update_installation.py --client /шлях/до/Minecraft --apply
```

Можна передати обидва шляхи однією командою. Інсталятор перевіряє хеші нових JAR та наявний підпис ADM перед заміною, прибирає попередні версії семи модулів і Caupona, очищає відповідні теги/дерева/конфіг та оновлює ADM. Власні ліміти популяцій, шанс дерев, рідкість рослин та інші налаштування зберігаються. Повторний запуск не робить нових змін.

Резервні копії лежать у сусідній до гри папці `Empirecraft-cleanup-backups`, окремо для сервера й клієнта. Світ і його NBT/регіони інсталятор не читає й не змінює. Античіт залишається ввімкненим. Усі клієнти мають отримати шість спільних оновлених JAR і прибрати Caupona; World Rules встановлюється тільки на сервері.

## Перевірка та відтворення

Нативний набір запускає Mohist/Forge двічі в окремому створеному світі без Caupona. Він перевіряє відсутність модів/реєстрових ID/рецептів видаленого простору імен, доступність інгредієнтів власних рецептів, торгівлю й списки відновлення, лиття, нові та старі стрижні, боєприпаси, книгу, Create, розмноження, корабельні таймери й повторне завантаження. Точні JAR та результати наведені в `verification.json`. Графічний клієнт не запускався. AntiXray виключений лише з тесту без клієнтських пакетів чанків; у збірці він збережений.

Інсталятор окремо перевірено на реальних JAR у тимчасовій папці: власний шанс дерев, сторонні записи ADM, правильний підпис, резервні копії, повторний запуск і незмінні байти тестового регіону.

З репозиторію: `python server-cleanup/repack.py`, звичайна staged-збірка World Rules і TFC Integration, `python handbook/build.py`, `python server-cleanup/stage.py`, збірка TFC fixture, далі:

```sh
python tfc-integration/smoke.py --java-home /path/to/java21 --runtime /workspace/work/server-cleanup/runtime --full-pack --server-cleanup --staged-mods server-cleanup/build/staged
python server-cleanup/test_installer.py
python server-cleanup/release.py --install
```

Робочий світ під час розробки не відкривався. Історичні архіви, перевірки та вимкнені JAR містять старі назви для відтворення; вони не належать до активного серверного вмісту.
