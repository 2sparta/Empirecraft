# Immersive Smithing в Empirecraft

Горн, ковадло, корито, молот і щипці належать Immersive Smithing. TFC відповідає за плавлення руд, сплави та лиття злитків. Для звичайної сталі використовуються білий чавун і флюс у тиглі TFC.

Присядь і натисни ПКМ порожніми руками на ковадлі Immersive Smithing, щоб відкрити поетапне складання броні. У меню можна перевірити матеріали для всіх чотирьох етапів і ремонту. Для кування деталі поклади відповідну оправку в інвентар. Оправка багаторазова. Викуй деталь та загартуй її в кориті. Якість деталей впливає на якість готового обладунку.

У старому столі складання можна забрати інвентар і перенести незавершений обладунок на нове ковадло. Під час завантаження світу Forge замінює відомі старі матеріали, щипці, молоти й інструменти Overgeared на відповідники. Збережіть копію світу перед заміною модів. Старі спеціалізовані верстати Overgeared та їхні внутрішні інвентарі не переносяться, тому перед оновленням заберіть їхній вміст.

Для повторної збірки запусти `immersive-smithing/build.py` із JAR Immersive Smithing 1.3.1, Java 17, Forge SDK та бібліотеками Mohist. Параметр `--help` показує потрібні шляхи. Скрипт отримує базові JAR із зафіксованої версії репозиторію. Після встановлення `immersive-smithing/check.py` звіряє активні файли, рецепти деталей та заміну сталі. `immersive-smithing/native.py` запускає тест складання в окремому світі Mohist.
