# Відкладені моди

Hybrid Aquatic 1.5.4 не входить до активної збірки: на Mohist 71a84ff7 спричиняє помилку завантаження класу Player. Відтворено також із версією 1.5.3; Player-mixin у 1.5.1–1.5.4 однаковий. Без Hybrid Aquatic оновлена збірка проходить завантаження.

Не копіювати цей JAR у `mods/` або `server/mods/` без окремої перевірки сумісності. На вихідному сервері цього мода не було. Новіші 1.6+ змінюють ідентифікатори та потребують окремого плану переходу світу.
