# Замінені файли — 01.11.2026

Це архів попередніх JAR, а не активна збірка. Шляхи `mods/`, `server/mods/`
та `server/plugins/` усередині архіву показують їхнє колишнє розташування.

- Create Drafting Posters 1.2.0 замінено на 1.4.0 на клієнті та сервері.
- Seasonal Leaves 1.2.0 замінено на 1.2.2 лише на сервері.
- Старі TownyRecruitsBridge та Empirecraft Recruits Integration замінено
  одним Forge-модом `townyrecruits-1.0.0.jar` на обох сторонах.
  Клієнтський `TownyRecruitsBridge-1.0.jar` був Bukkit-плагіном без Forge metadata.

Не копіюйте цей каталог у гру. Для відкату потрібен узгоджений попередній
набір модів та ADM, а не одночасне встановлення старих і нових мостів.
