# Фауна Empirecraft 1.2.0

У 1.2.0 тварини з’являються попереду в напрямку руху гравця. Летючі птахи утворюють зграї, розлітаються від пострілів, вибухів і прольоту куль та збираються після затишшя. Встановлення разом із виправленнями льону й броні описано в [ecology-update/README.uk.md](../ecology-update/README.uk.md).

Серверний мод для Mohist 1.20.1 / Forge 47.4.23, Towny 0.101.2.0 та Empirecraft Calendar 1.2.0. Гравцям не потрібно встановлювати додатковий мод або реєструвати ферми. Повідомлення відображаються українською або російською відповідно до мови клієнта; для консолі та інших мов використовується `defaultLocale`.

## Міста й поголів’я

Усі види зі списку `domesticTypes` займають спільну місткість міста за фактичним розташуванням у ділянках Towny. Власник, приручення, кількість гравців і відстань між ділянками не впливають на облік. Переміщення тварини, зміна меж, рівня або столиці автоматично оновлюють підрахунок.

| Ступінь розвитку | Ефективний номер рівня Towny | Місткість за замовчуванням |
| --- | --- | --- |
| Мале поселення | 0–1 | 20 |
| Звичайне поселення | 2–3 | 35 |
| Місто | 4–5 | 80 |
| Велике місто | 6–7 | 150 |
| Мегаполіс | 8 і вище | 200 |
| Столиця держави | будь-який | щонайменше 200 |

Це відповідність числовим рівням Towny, а не кількості жителів чи перекладеній назві міста. Враховується також ручний рівень Towny. Для іншої шкали розвитку змініть `townLevelCapacity`; між заданими ключами діє попереднє значення. `capitalCapacity` задає мінімальну місткість столиці.

На межі місткості блокується народження та додавання нових тварин відповідної групи. Наявні тварини зберігаються, зокрема після зниження рівня, завантаження чанка чи перенесення в переповнене місто. Щойно поголів’я стає меншим за ліміт, розмноження відновлюється. Місткість не видаляє тварин і не забороняє перевезення наявних: для фактичного навантаження є окремий моніторинг.

За межами міст діють окремі обмеження для свійських тварин: 200 на весь сервер і 32 у регіоні. Регіон — квадрат `regionChunks × regionChunks` чанків, прив’язаний до координат світу; за замовчуванням 16 × 16 чанків. Вивантаження чанка не звільняє місце. Ферма на нічийній території не обходить обмеження розмноження.

Приручені коти, вовки, папуги й модові приручувані тварини обліковуються як улюбленці. Види з `domesticTypes`, зокрема коні, залишаються свійськими; явний `petTypes` має пріоритет. Ліміти улюбленців `petTownLimit` і `petWildernessLimit` за замовчуванням вимкнені (`-1`).

## Сезони й дика фауна

Calendar уже задає місячні профілі для тварин модпаку та враховує клімат і погоду. Fauna застосовує до цих профілів додатковий коефіцієнт чисельності без повторного сезонного кидка. Не додаються види, яких немає в таблиці спавну відповідного біому. Монстри не потрапляють до обліку тварин.

Для спроби природного спавну коефіцієнт чисельності дорівнює найменшому залишку місткості серед застосовних лімітів: `max(0, 1 − кількість / ліміт)`. Порожня популяція має коефіцієнт 1, заповнена наполовину — 0,5, заповнена повністю — 0. Зменшення чисельності підвищує шанс наступних спроб. Додатково змінюється відносна вага виду: коефіцієнт × `densityWeightMaximum` (типово 2). Для народження діє перевірка вільного місця без випадкового відхилення.

Для диких тварин за замовчуванням діють:

- `wildGlobalLimit`: 1000 завантажених диких тварин сумарно у всіх вимірах; вивантажені особини залишаються в індексі, але звільняють активний бюджет;
- `wildRegionLimit`: 160 у квадраті регіону;
- `biomeRegionLimits`: ліс 100, рівнини 80, гори 50, болото 40 у межах регіону; `#` означає тег біомів;
- `speciesGlobalLimits` та `speciesRegionLimits`: додаткові словники за ID виду, спочатку порожні.

Застосовується найсуворіше відповідне обмеження. Наприклад, `"naturalist:deer": 30` у `speciesRegionLimits` обмежує оленів у кожному регіоні. Нуль вимикає новий спавн відповідної групи; наявні особини залишаються. Свійські тварини та приручені улюбленці виключаються також із ванільного підрахунку природного ліміту, тому ферми не займають місця дикої фауни.

## Команди

Доступ: консоль, рівень оператора від 2 або право Bukkit `empirecraft.fauna.admin`.

| Команда | Призначення |
| --- | --- |
| `/fauna admin stats` | Свійські тварини в містах, поза містами, дика фауна, улюбленці |
| `/fauna admin stats domestic` | Міське поголів’я, сума місткостей, вільні місця й заповненість; окремо поголів’я поза містами |
| `/fauna admin stats wild` | Дика фауна та глобальний ліміт |
| `/fauna admin stats pets` | Приручені улюбленці |
| `/fauna admin stats wilderness` | Свійські тварини поза містами |
| `/fauna admin cities` | Усі міста з поголів’ям і заповненістю |
| `/fauna admin city <назва або UUID>` | Рівень, місткість, види та кількість тварин міста |
| `/fauna admin monitor` | Загальна й завантажена чисельність, MSPT сервера, час поточного оновлення обліку, кількість відхилених додавань і прочитаних чанків |
| `/fauna admin reload` | Перевірити та застосувати JSON без перезапуску; при помилці зберегти попередні налаштування |

Назви міст із пробілами приймаються без лапок; підкреслення також підтримуються. Відсотки мають локалізований формат, наприклад `83,3%`. Чисельність міст порівнюється із сумою їхніх місткостей; свійські тварини поза містами показуються окремо.

## Установлення й облік

Зупиніть сервер, перенесіть `server/mods/empirecraft-fauna-1.2.0.jar` із ZIP до серверної папки `mods` і приберіть попередній JAR. Наявний `config/empirecraft-fauna.json` збережіть; довідковий файл із ZIP потрібен для першої установки. За відсутності файла мод створить типові налаштування. Calendar, Serene Seasons і Towny вже мають бути встановлені з налаштуваннями поточної збірки.

На старті індекс `data/empirecraft-fauna.dat` звіряється з NBT у папках `region` і `entities` усіх вимірів. Читання виконується у фоновому потоці лише для читання, без примусового завантаження чанків. Для імпортованих світів беруться збережені палітри біомів. Під час першого перепису або недоступності Towny нові тварини тимчасово не додаються, а наявні завантажуються нормально. Статистика позначає незавершений перепис. Порожні файли регіонів є штатними й не вважаються пошкодженими. Якщо окремі чанки справді не читаються, їхні відомі тварини зберігаються, новий спавн і розмноження призупиняються лише в зачеплених регіонах і містах. Решта світу працює; повторний фоновий облік виконується не частіше разу на хвилину, однакове попередження — раз на п’ять хвилин.

Лічильники змінюються за подіями завантаження, видалення, народження й переміщення. Резервне оновлення позицій розбивається на порції до 512 особин і приблизно 2 мс за такт; `positionRefreshTicks` типово 40. Перед народженням і командою статистики позиції завантажених особин звіряються повністю. Налаштування Towny звіряються щосекунди та перед перевіркою розмноження. Одночасні додавання під час генерації резервують місця атомарно.

`loadedAnimalWarning` типово 1500: при перевищенні мод записує попередження з інтервалом `monitorIntervalSeconds` (300). Це сигнал для адміністратора; автоматичне видалення тварин не виконується. Час обліку в команді моніторингу не є повним профілем усіх подій та фонового читання.

## Перевірка й відтворення

З JDK 17: `bash gradlew test build exportDefaults smokeJar`. З JDK 21: `python3 fauna/smoke.py --java /path/to/java` з кореня репозиторію. Тестовий мод запускається лише в тимчасовому світі: справжні Towny, Naturalist, DragN's Livestock Overhaul, народження, ванільні ліміти, генерація чанків, обидві мови та повторний запуск. Перевірки NBT підтверджують незмінність байтів і часу модифікації файлів регіонів.

Графічний клієнт і робочий світ сервера не використовуються в автоматичних перевірках. Історичний індекс не замінює облік тварин, які інші інструменти редагують безпосередньо у файлах світу під час роботи сервера; такі зміни потрібно робити зі зупиненим сервером.

Версія 1.1.1 підтримує календар 1.2.0 з роками та адміністративною зміною дати. Правила місткості, налаштування й збережений облік тварин збережені.

## Додатковий сезонний спавн 1.1.1

[Таблиця 42 груп](seasonal-animal-spawn.md) і [CSV для Excel](seasonal-animal-spawn.csv) відповідають `src/main/resources/nearby-fauna.json`. Додаткові перевірки раз на 30 реальних секунд підсилюють появу тварин у завантаженій місцевості поблизу гравців; ліси тепер також придатні для білок. Нічийні природні тварини поза приватами можуть зникати після трьох хвилин без гравця ближче 160 блоків. Названі, приручені, розведені, з інвентарем, у приватах і тварини невідомого походження зберігаються; чанк не завантажується заради очищення.

У статистиці диких тварин показується активний бюджет і окремо весь індекс, включно з вивантаженими особинами. Міське поголів’я продовжує враховуватися навіть у вивантажених чанках. Зупиніть сервер і при оновленні видаліть попередній `empirecraft-fauna-*.jar`, щоб залишити одну версію. Наявний конфіг зберігайте: відсутні нові параметри отримують типові значення.

Резервна збірка без Gradle: `JAVA_HOME=/path/to/jdk17 python3 fauna/build.py --sdk sails/build --junit /path/to/junit-platform-console-standalone.jar` після підготовки SDK через `sails/build.py`. Перевірки сервера охоплюють також Ecologics, Spawn та Horse Genetics, природне походження, біоми, приват, місцеві ліміти, радіус появи, зникнення та повторний запуск.
