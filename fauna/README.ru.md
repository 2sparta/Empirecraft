# Фауна Empirecraft 1.0.1

Серверный мод для Mohist 1.20.1 / Forge 47.4.23, Towny 0.101.2.0 и Empirecraft Calendar 1.1.1. Игрокам не требуется устанавливать дополнительный мод или регистрировать фермы. Сообщения выводятся на русском или украинском языке согласно языку клиента. Для консоли и других языков используется `defaultLocale`.

## Города и поголовье

Все виды из `domesticTypes` занимают общую вместимость города по фактическому расположению в участках Towny. Владелец, приручение, число игроков и расстояние между участками не влияют на учёт. Перемещение животных, изменение границ, уровня города или статуса столицы автоматически обновляют подсчёт.

| Ступень развития | Эффективный номер уровня Towny | Вместимость по умолчанию |
| --- | --- | --- |
| Малое поселение | 0–1 | 20 |
| Обычное поселение | 2–3 | 35 |
| Город | 4–5 | 80 |
| Большой город | 6–7 | 150 |
| Мегаполис | 8 и выше | 200 |
| Столица государства | любой | не менее 200 |

Это соответствие числовым уровням Towny, а не числу жителей или переведённому названию города. Учитывается ручной уровень Towny. Для другой шкалы развития измените `townLevelCapacity`: между заданными ключами действует предыдущее значение. `capitalCapacity` задаёт минимальную вместимость столицы.

При заполнении вместимости блокируются рождение и добавление новых животных соответствующей группы. Существующие животные сохраняются, в том числе после снижения уровня, загрузки чанка или переноса в переполненный город. Когда поголовье становится меньше лимита, размножение возобновляется. Вместимость не удаляет животных и не запрещает перевозку существующих: фактическую нагрузку показывает отдельный мониторинг.

Вне городов действуют самостоятельные ограничения для сельскохозяйственных животных: 200 на весь сервер и 32 в регионе. Регион — квадрат `regionChunks × regionChunks` чанков, привязанный к координатам мира; по умолчанию 16 × 16 чанков. Выгрузка чанка не освобождает место. Ферма на ничейной территории не позволяет обойти ограничения размножения.

Приручённые кошки, волки, попугаи и приручаемые животные из модов учитываются как питомцы. Виды из `domesticTypes`, включая лошадей, остаются сельскохозяйственными; явный список `petTypes` имеет приоритет. Лимиты питомцев `petTownLimit` и `petWildernessLimit` по умолчанию отключены (`-1`).

## Сезоны и дикая фауна

Calendar уже задаёт месячные профили животных сборки с учётом климата и погоды. Fauna дополняет их коэффициентом численности без повторной сезонной проверки. Виды, которых нет в таблице спавна биома, не добавляются. Монстры не входят в учёт животных.

Для попытки естественного спавна коэффициент численности равен наименьшему остатку вместимости среди применимых лимитов: `max(0, 1 − количество / лимит)`. При пустой популяции он равен 1, при заполнении наполовину — 0,5, при полном заполнении — 0. Снижение численности повышает шанс следующих попыток. Относительный вес вида также умножается на коэффициент × `densityWeightMaximum` (обычно 2). Для рождения проверяется свободное место без случайного отказа.

По умолчанию для диких животных действуют:

- `wildGlobalLimit`: 1000 на сервер, включая выгруженные чанки и другие измерения;
- `wildRegionLimit`: 160 в квадрате региона;
- `biomeRegionLimits`: лес 100, равнины 80, горы 50, болото 40 в пределах региона; `#` обозначает тег биомов;
- `speciesGlobalLimits` и `speciesRegionLimits`: дополнительные словари по ID вида, изначально пустые.

Применяется самое строгое подходящее ограничение. Например, `"naturalist:deer": 30` в `speciesRegionLimits` ограничивает оленей в каждом регионе. Ноль запрещает новый спавн соответствующей группы; существующие особи сохраняются. Сельскохозяйственные животные и приручённые питомцы исключаются также из ванильного подсчёта естественного лимита, поэтому фермы не занимают места дикой фауны.

## Команды

Доступ: консоль, уровень оператора от 2 или право Bukkit `empirecraft.fauna.admin`.

| Команда | Назначение |
| --- | --- |
| `/fauna admin stats` | Сельскохозяйственные животные в городах, вне городов, дикая фауна, питомцы |
| `/fauna admin stats domestic` | Городское поголовье, сумма вместимостей, свободные места и заполненность; отдельно поголовье вне городов |
| `/fauna admin stats wild` | Дикая фауна и глобальный лимит |
| `/fauna admin stats pets` | Приручённые питомцы |
| `/fauna admin stats wilderness` | Сельскохозяйственные животные вне городов |
| `/fauna admin cities` | Все города с поголовьем и заполненностью |
| `/fauna admin city <название или UUID>` | Уровень, вместимость, виды и количество животных города |
| `/fauna admin monitor` | Общая и загруженная численность, MSPT сервера, время текущего обновления учёта, число отклонённых добавлений и прочитанных чанков |
| `/fauna admin reload` | Проверка и применение JSON без перезапуска; при ошибке сохраняются предыдущие настройки |

Названия городов с пробелами принимаются без кавычек; подчёркивания тоже поддерживаются. Проценты выводятся в локализованном формате, например `83,3%`. Поголовье городов сравнивается с суммой их вместимостей; сельскохозяйственные животные вне городов показаны отдельно.

## Установка и учёт

Остановите сервер и перенесите `server/mods/empirecraft-fauna-1.0.1.jar` из ZIP в серверную папку `mods`. Сохраните существующий `config/empirecraft-fauna.json`; справочный файл из ZIP нужен для первой установки. При отсутствии файла мод создаёт стандартные настройки. Calendar, Serene Seasons и Towny должны быть установлены с настройками текущей сборки.

При запуске индекс `data/empirecraft-fauna.dat` сверяется с NBT в папках `region` и `entities` всех измерений. Файлы читаются в фоновом потоке только для чтения, без принудительной загрузки чанков. Для импортированных миров используются сохранённые палитры биомов. Во время первой переписи или недоступности Towny новые животные временно не добавляются, существующие загружаются нормально. Статистика отмечает незавершённую перепись. Ошибки чтения оставляют учёт неполным и вызывают повторную попытку через 10 секунд: непрочитанные чанки не считаются пустыми.

Счётчики меняются по событиям загрузки, удаления, рождения и перемещения. Резервное обновление позиций разбивается на порции до 512 особей и примерно 2 мс за такт; `positionRefreshTicks` обычно 40. Перед рождением и командой статистики позиции загруженных особей сверяются полностью. Данные Towny сверяются раз в секунду и перед проверкой размножения. Одновременные добавления при генерации резервируют места атомарно.

`loadedAnimalWarning` обычно равен 1500: при превышении мод записывает предупреждение с интервалом `monitorIntervalSeconds` (300). Это сигнал для администратора; автоматического удаления животных нет. Время учёта в мониторинге не является полным профилем всех событий и фонового чтения.

## Проверка и воспроизведение

С JDK 17: `bash gradlew test build exportDefaults smokeJar`. С JDK 21: `python3 fauna/smoke.py --java /path/to/java` из корня репозитория. Тестовый мод работает только во временном мире: настоящие Towny, Naturalist, DragN's Livestock Overhaul, рождение, ванильные лимиты, генерация чанков, оба языка и повторный запуск. Проверки NBT подтверждают неизменность байтов и времени модификации файлов регионов.

Графический клиент и рабочий мир сервера не используются в автоматических проверках. Индекс не заменяет учёт животных, которых сторонние инструменты редактируют непосредственно в файлах мира при работающем сервере; такие изменения нужно выполнять при остановленном сервере.

Версия 1.0.1 поддерживает календарь 1.2.0 с годами и административной сменой даты. Правила вместимости, настройки и сохранённый учёт животных сохранены.
