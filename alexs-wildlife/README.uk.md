# Alex’s Mobs для Empirecraft

33 реалістичні види, географічний спавн за проєкцією та природними зонами Earth, заміна мурах Spawn і великий дроп китів. Citadel 2.6.3 входить до пакета.

Прибрано з ігрового процесу фантастичних мобів, мобів Nether/End, великих комах та інших надмірно збільшених членистоногих. Із комах залишено мурах-листорізів. Ведмеді, слони, носороги, газелі, лосі, тигри, лобстери, тюлені та інші дублікати з Alex’s Mobs вимкнені; наявні види інших модів збережені. Кашалоти й косатки Alex’s Mobs залишені разом з іншими китоподібними.

У Naturalist 5.0pre5 мурах немає: альтернативні мурахи цієї збірки — `spawn:ant`. Їхню появу, старих збережених мурах, рецепти мурашиних ферм і генерацію мурашників вимкнено. Мурашники Alex’s Mobs проходять географічну перевірку.

Вимкнені види не з’являються природно, через яйця, команди, спавнери, перетворення або завантаження старих сутностей. Їхні рецепти, яйця та пов’язані недоступні предмети прибрано з рецептів, творчих вкладок і JEI. Registry ID і класи збережено для сумісності: це вилучення з гри, а не видалення записів реєстру. Базовий Alex’s Mobs і оновлений Spawn вимагають мод політики, тому випадково запустити ці JAR без обмежень не вийде.

## Географія

Використовуються точна формула проєкції й запити природних зон з `earth-geography/Geography.java`. Якщо є `config/empirecraft-earth.json`, беруться його зміщення, масштаб, виміри та полігони; інакше — стандартні дані Earth 1:500 зі збірки. Географічний мод-кандидат Earth для цього встановлювати не потрібно. Цей пакет не вмикає його зміни рельєфу або руд. Після зміни Earth-конфіга потрібен перезапуск.

Ареали — наближені ігрові полігони, записані у `wildlife-policy.json`. Кенгуру й ему — Австралія, тасманійський диявол — Тасманія, качкодзьоб — схід Австралії та Тасманія, комодський варан — острови біля Комодо, горили — Центральна Африка, гелади — Ефіопія, мурахи-листорізи, тукани й капуцини — Центральна та Південна Америка. Для снігового барса враховано також висоту. Для морських тварин перевіряються фактична вода, морський басейн і глибина; китів немає у прісній воді, Чорному, Азовському, Каспійському й Балтійському морях.

Нові кандидати додаються до штатного природного спавнера в дозволених зонах, навіть якщо вихідний біом мапи не містив цього виду. Штатні перевірки поверхні, освітлення, ліміти Fauna й сезонні коефіцієнти Calendar залишаються чинними. Виміри поза Earth-профілем не отримують необмежений запасний спавн. Вже прийняті дозволені тварини, їх перевезення та розведення не обрізаються географічною перевіркою.

Повна таблиця видів, ареалів, глибин і вилучень — `src/main/resources/wildlife-policy.json`.

## Дроп дорослих китів

| Вид | Жир | М’ясо | Кістки | Зуби Alex’s Mobs |
| --- | ---: | ---: | ---: | ---: |
| Кашалот | 384–448 | 320–448 | 96–160 | 2–6 |
| Косатка | 192–256 | 128–192 | 32–64 | — |

Жир і м’ясо — ті самі ресурси WonderousSea, що й у наявній системі китобійства. Баланс спирається на встановлені профілі фінвала та малого кита. Китовий вус зубатим китам не додається. Кількість рахується в предметах, великі кількості розбиваються на звичайні стаки. `doMobLoot=false` вимикає дроп; дитинчата не дають дорослого врожаю. Лут інших модів не змінено.

## Встановлення

Зупини клієнт і сервер. Розпакуй **обидва архіви в одну папку**: `Empirecraft-Alexs-Wildlife-1.0.0.zip` та `Empirecraft-Spawn-Ant-Replacement-1.0.0.zip`. Spawn винесений окремо через розмір його аудіоресурсів. Виконай із цієї папки:

```sh
python install.py --client /шлях/до/клієнта --server /шлях/до/сервера
python install.py --client /шлях/до/клієнта --server /шлях/до/сервера --apply
```

Перша команда показує зміни, друга застосовує їх. Інсталятор перевіряє хеші, замінює тільки відомі попередні JAR, зберігає резервні копії та оновлює чотири записи ADM зі збереженням решти списку. Файли світів, бази міст і конфіги інших модів не редагуються. При повторному запуску ті самі JAR не переписуються. Резервні копії попереднього Spawn і ADM — у `.empirecraft-backups/wildlife-1.0.0` відповідного клієнта або сервера.

## Відтворення

```sh
python alexs-wildlife/make_policy.py alexs-wildlife/upstream/alexsmobs-1.22.9.jar
python alexs-wildlife/build.py --alexs alexs-wildlife/upstream/alexsmobs-1.22.9.jar
python alexs-wildlife/test.py
python alexs-wildlife/smoke.py --citadel mods/citadel-2.6.3-1.20.1.jar
python alexs-wildlife/smoke.py --citadel mods/citadel-2.6.3-1.20.1.jar --full-pack
python alexs-wildlife/release.py --citadel mods/citadel-2.6.3-1.20.1.jar
```

JDK 21 компілює за API встановленого Mohist/Forge; цільова платформа — Java 17 (`WILDLIFE_JDK17` задає шлях до JDK 17, якщо потрібен). Вхідні хеші закріплені в `inputs.json`. `audit/` містить результати перевірок: 139 географічних перевірок, 277 перевірок у мінімальному серверному складі та 276 — зі всіма серверними ігровими модами. Кількість перевірок стаків залежить від випадкової кількості луту. У повній тестовій збірці пропущено лише пакетний фільтр AntiXray, оскільки клієнтів і пакетів чанків немає; економіка Towny вимкнена тільки в тестовому конфігу. Серверні тести використовують тимчасовий плоский світ і справжні класи модів. Графічний клієнт і робочий світ не тестувалися.

Вихідний Alex’s Mobs і Citadel поширюються за LGPL; версія Alex’s Mobs позначена суфіксом `empirecraft.1`. Відтворювані зміни двох класів наведені в `PatchBiome.java`, інша нативна поведінка збережена. Ліцензії вихідних модів залишаються у відповідних JAR.
