# Empirecraft — шари броні та виправлення збірки

Minecraft 1.20.1 / Forge 47.4.23. Оновлення виправляє провізію для світів з різним календарем, облік фауни, права керування кораблями та рецепти каменю. Додає мод `empirecraft-layered-armor-1.0.0.jar` на клієнт і сервер.

## Шари броні

У звичайному інвентарі послідовно кладіть речі в той самий слот броні: **підкладка або шкіра → кольчуга → зовнішня броня**. Шари необов’язкові: можна носити одну річ або два сумісні шари. Для кожної частини тіла доступно максимум три різні шари; скласти кілька панцирів або шоломів одного типу не можна.

Порожня кнопка 8×8 біля слотів броні відкриває окремий огляд усіх шарів. Речі можна надягати й знімати в цьому меню. Зняття завжди починається із зовнішнього шару; та сама послідовність працює для звичайного кліку, Shift-кліку, викидання та перенесення на гарячу панель. Заміна зовнішньої речі не знімає внутрішні. За повного інвентарю Shift-клік нічого не викидає й не видаляє.

Кожна річ дає власні штатні характеристики, отримує власне зношення та зберігає NBT, фарбування й якість кування. Поломка зовнішнього шару залишає внутрішній одягненим. Після смерті речі передаються окремо в систему трофеїв: у тіло Corpse або у звичайний дроп. Правило `keepInventory` зберігається. Зачарування підпорядковуються наявним заборонам збірки. Відображення використовує рідні моделі й текстури речей: спочатку внутрішній шар, потім зовнішній.

Попередні додатки до захисту +4 / +2 / +1,5 / +1 прибрані у Forging 1.1.4. Якість кування та її бонуси довговічності збережені. Стандартна формула й обмеження захисту Minecraft лишаються чинними.

Тип шару визначається за сімейством обладунків. Власний datapack може уточнити класифікацію тегами предметів `empirecraft_armor:padded`, `empirecraft_armor:mail`, `empirecraft_armor:outer`.

## Інші виправлення

- Провізія читає календар світу домашньої ділянки міста. Календар публікує окремі часові прив’язки для імен та UUID світів; старий загальний протокол збережено для сумісності.
- Два нульові `.mca` файли більше не створюють помилкові «2048 непрочитаних чанків». Справжні проблеми читання зберігають наявних тварин і обмежують новий спавн лише в зачеплених регіонах та містах. Фонові повторні спроби не вимикають решту світу.
- Явно призначені капітан і екіпаж користуються дозволами системи флоту. Їх більше не відхиляє друга перевірка загального `vs_sails.ship.control`. Резервування корабля на продаж і відсутність потрібної ролі продовжують блокувати доступ.
- Відновлено стандартні рецепти каменю після фінальних проходів KubeJS. NBT-об’єкт із полем `tag` більше не обробляється як ім’я тегу інгредієнтів.

| Піч | 1 камінь | 1 гладкий камінь |

| Каменеріз | 1 гладкий камінь | 2 плити із гладкого каменю |

## Установлення

Закрийте клієнт і зупиніть сервер. Встановіть папки `client/` та `server/` з пакета `Empirecraft-Layered-Armor-Hotfix-1.zip`. Видаліть перелічені в `REMOVE-OLD.txt` старі версії Calendar, Forging, Sails, Fauna, Feudal, Bridge та TownyRecruits, залишивши по одному актуальному JAR. Застосуйте парний серверний ADM. Наявні світи, бази H2, файли міст і власні налаштування не видаляйте.

Pack Fixes має лише змінену межу сумісності Sails: усі інші записи його JAR залишаються побайтово однаковими. Engagement 1.1.1 включає мирні прапори з PR #118 та сумісність із TownyRecruits 2.0. Джерела перевірок — `compat_dependencies.py` і `naval/build_update.py`.

## Відтворення та перевірки

JDK 17 для компіляції, Java 21 для запуску Mohist; потрібен SDK `sails/build/` і залежності репозиторію.

```sh
python3 layered-armor/build.py
python3 layered-armor/test.py
python3 layered-armor/native.py --java /path/to/java21 --profile server --with-addon
python3 layered-armor/native.py --java /path/to/java21 --profile client --with-addon
```

`test.py` застосовує справжні Sponge Mixins до класів Minecraft і перевіряє байткод, включно з клієнтським рендерером. `native.py` запускає тимчасовий Mohist зі справжніми модами, натискає нативні слоти інвентарю та перевіряє рецепти, характеристики, меню, зношення й смерть. Окремі набори Feudal, Calendar, Forging, Sails і Fauna перевіряють свої зміни; флот і фауна додатково проходять перевірки з реальним Towny та перезапуском.

Графічний клієнт і виробничі світи цими сценаріями не запускаються. Усі серверні світи перевірок тимчасові.
