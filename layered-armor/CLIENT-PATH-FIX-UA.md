# Клієнтський збій Missing path — Armor 1.0.4

Клієнтський лог показує фатальну помилку `IllegalArgumentException: Missing path` у `ArmorLanguages.packs`. Під час події Forge `AddPackFindersEvent` мод броні 1.0.3 викликав `ModFile.findResource()` без аргументу. Forge відхиляє порожній шлях, і завантаження клієнта завершується до головного меню. На сервері цей клієнтський обробник не виконується.

У 1.0.4 обробник знаходить `pack.mcmeta` і бере його батьківську папку як корінь пакета перекладів. Українська, англійська й російська мови, автоматичне ввімкнення перекладів та поточне меню броні збережені. Змінено лише `ArmorLanguages.class`; решта 23 класів, серверна логіка, мережеві пакети, збережені шари, знос і підкладки байтово незмінні. Відображення лише верхнього шару броні збережено.

## Установлення

Зупини гру та сервер. У клієнтській і серверній папці `mods` заміни `empirecraft-layered-armor-1.0.3.jar` і його `.sha256` файлами **1.0.4** з відповідної папки архіву. Якщо встановлена ще давніша версія цього моду, також прибери її, щоб залишився один JAR броні. Потрібен однаковий спільний JAR на обох сторонах.

Після вилучення клієнтських Emotecraft і Pop-up Emotes серверний ADM також має відображати цей список. З розпакованого архіву запусти:

```sh
python update_armor_adm.py --id-file /шлях/до/сервера/config/admanticheat/idfile/admanticheat_id_list.json --jar server/mods/empirecraft-layered-armor-1.0.4.jar --remove-client-mod emotecraft --remove-client-mod pop_up_emotes
```

Скрипт перевіряє наявний підпис ADM, оновлює тільки броню та явно зазначені вилучені клієнтські ID, зберігає інші моди/налаштування й робить резервну копію. Повторний запуск не змінює файл. Caupona не додається назад, античіт не вимикається. Світ не потребує змін.

Серверні Emotecraft і Pop-up Emotes допускають відсутність цих клієнтських модів у перевірці версій мережевого каналу; залежностей збірки, які вимагали б їх на клієнті, не знайдено. Їхні наявні серверні JAR залишено. Player Animator потрібний також Better Combat і зберігається.

## Перевірка

Регресійний тест використовує справжні Forge `ModFile`, `ModList`, `AddPackFindersEvent`, Minecraft `PackRepository` та завантажувач мов. На Forge **47.4.23** і **47.4.28** стара версія відтворює саме `Missing path`; нова реєструє пакет і завантажує мови без цього винятку. Перевірено шлях із пробілами й українськими символами, англійську/українську/російську мови, резервну мову й повторне перемикання; додатково пройшли 60 попередніх перевірок перекладів. Повне графічне вікно Minecraft не запускалося. Робочий світ не запускався й не змінювався.

Збірка й тест із кореня репозиторію:

```sh
python layered-armor/client_path_build.py --sdk /path/to/named-toolchain --java-home /path/to/jdk17
python layered-armor/client_path_test.py --sdk /path/to/named-toolchain --java-home /path/to/jdk17 --forge-loader-28 /path/to/fmlloader-1.20.1-47.4.28.jar
python layered-armor/client_path_release.py --install
```

Точні хеші перевіреного JAR та API наведені в `audit/client-path.json` і `audit/client-path-build.json`. Сирий клієнтський лог із персональними даними не включено до пакета.
