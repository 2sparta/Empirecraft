# Original human skins

128 new standard 64x64 RGBA Minecraft skins, generated by `tools/generate_skins.py`.
The generator uses its own palettes, faces, facial hair, hair shapes and clothing details. No upstream Recruits texture is copied into these assets. Copyright 2026 EmpireCraft contributors; MIT, as in the project LICENSE.

`skins-preview.png` is a flat front-view contact sheet. In game, native Recruits biome/faction clothing layers and equipped armour may cover parts of the clothing shown here; face and hair variation remains.

To regenerate: `python3 -m pip install Pillow`, then `python3 tools/generate_skins.py`.

The source ZIP includes the generated PNGs. Git source keeps the generator and checksum manifest; build.py regenerates missing PNGs. Install requirements-assets.txt before building a fresh clone.
