# Тварини, сезонна карта й вітер Empirecraft

- Дикі наземні тварини звикають до окремих гравців, які спокійно перебувають поруч. Довіра накопичується приблизно за хвилину й повільно спадає після тривалої відсутності. Напад обнуляє довіру до нападника та відкладає її відновлення, а поранена тварина попереджає побратимів у радіусі 14 блоків. Зберігається пам’ять щонайбільше про вісьмох гравців для кожної тварини.
- Приведіть приручену тварину в загін, наведіть на неї приціл і введіть `/animal pen`. Після пострілу чи вибуху тварина спробує дістатися укриття в межах 48 блоків. Вона може побігти до знайомого господаря, якщо безпечне укриття не позначене або задалеко. `/animal pen clear` скидає позначку.
- У меню режимів JourneyMap відкрийте **«Сезонні ризики»**. Для розвіданої суші шар показує оцінки заморозків, посухи й снігу на поточний календарний місяць. Для давніх спостережень Earth без висоти застосовується оцінка на рівні моря, доки ви знову не обстежите місце. При кліку на відоме море або океан картка показує, куди зараз дме вітер, азимут від півночі або штиль.
- На Earth вітер змінюється плавно між пасатами, західними й полярними вітрами. Довгота додає різницю між океанами, а сезон змінює мусони на півночі Індійського океану. Показник на карті й вітрила використовують один серверний розрахунок. Фіксовані та радіальні правила вітру сервера діють у своєму режимі.
- Наведіть приціл на стіл Block & Board. `/table access` показує стан, `/table access private` закриває вільні місця для нових гостей, а `/table access public` відкриває їх. Столи за замовчуванням публічні, як раніше. Доступ змінює власник або оператор. Учасники поточної партії можуть її продовжити.
- Новий виріб майстерні бронника зберігає ім’я гравця, який почав складання, місто Towny майстерні та матеріал. Ремонт зберігає ці дані. У підказці пошкодженої броні рекомендована деталь із найнижчою якістю. Для старих обладунків із записаними деталями доступна та сама підказка.

Для крафту, карти та вітру потрібні відповідні клієнтська й серверна збірки цієї версії. Артефакти входять до `mods/` і `server/mods/`.

```sh
python seasonal-world/build.py --sdk /path/to/forge-sdk
python gameplay-interactions/test.py --sdk /path/to/forge-sdk --seasonal --overlay seasonal-world/build/libs --runtime /path/to/disposable-world
```
