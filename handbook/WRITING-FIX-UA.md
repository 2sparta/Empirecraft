# Довідник, папір і книги — виправлення 1.0.3

Закрий гру й зупини сервер. Розпакуй архів у окрему папку.

Встановлення з резервними копіями й оновленням запису довідника в ADM:

```sh
python update_installation.py --client "/шлях/до/клієнта" --server "/шлях/до/сервера"
```

Можна вказати лише одну зі сторін. Для одиночної гри достатньо `--client`. Потрібний Python 3.11 або новіший. Запускай скрипт з розпакованого архіву. Він зберігає попередні файли в `.empirecraft-backups/handbook-1.0.3`, замінює тільки довідник і рецепти письмових матеріалів та зберігає інші записи ADM.

Для ручного встановлення перенеси вміст `client` у папку клієнта, а `server` — у корінь сервера, зберігаючи структуру `mods` і `kubejs`. Прибери старі `empirecraft-handbook-*.jar` і їхні `.sha256`; залиш тільки 1.0.3. На сервері з ADM використовуй скрипт, щоб узгодити хеш книги. Перезапусти сервер і клієнт.

Рецепти:

- Три цукрові тростини в горизонтальному ряду → три аркуші паперу.
- Необроблений папір TFC + ніж → один звичайний аркуш; ніж залишається і втрачає одну одиницю міцності. Підходять ножі TFC і Farmer’s Delight.
- Три аркуші паперу + шкіра → звичайна книга.
- Один аркуш паперу → «Довідник Empirecraft».

Рецепти письмових матеріалів реєструються пізнім скриптом KubeJS. Вони доступні в JEI як крафти; папір TFC тепер має завершальний крафт у звичайній сітці. Ланцюжок вирощування папірусу, смужок, вимочування та ткацтва збережений.

Довгі заголовки довідника переносяться в межах сторінки. Повні назви статей і пошук збережені. Наявні екземпляри книги показують оновлений вміст.

Команда адміністратора (префікс обходить `/give` EssentialsX):

```mcfunction
/minecraft:give @s patchouli:guide_book{"patchouli:book":"empirecraft_guidebook:handbook"} 1
```

Перевірка реєстрації рецепта після перезапуску:

```mcfunction
/minecraft:recipe give @s empirecraft_guidebook:handbook
```

Автоматичні відкриття рецептів спрацьовують під час отримання матеріалів. Якщо матеріал уже був у сумці й у світі діє `doLimitedCrafting=true`, переклади його між слотами або скористайся командою відкриття рецепта. Правила світу інсталятор не змінює.
