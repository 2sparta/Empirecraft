# Empirecraft: збірка без Енду

Оновлення для Minecraft 1.20.1 / Forge 47.4.23 та сервера Mohist. Клієнтський і серверний архіви містять відповідні готові JAR та скрипти; нативні моди треба оновити на обох сторонах.

## Що вилучено

- Chipped: 139 зареєстрованих End-блоків і предметів — родини end stone та purpur, End-гарбузи та End-ліхтар. Попереднє вилучення незерських родин збережене; світлокамінь і обсидіан залишаються. У встановленому Chipped Extras відповідних End-реєстрацій уже немає, тому його JAR збережено.
- Contact: `ender_postcard`, `ender_parcel`, `ender_wrapping_paper` більше не реєструються. Звичайні листівки, листи, посилки та пакувальний папір залишаються.
- Farmer’s Delight: `diamond_knife` і `netherite_knife` більше не реєструються; рецепти й посилання з тегів вилучені. Залізний, кременевий і золотий ножі залишаються. Наявні зміни рецептів Farmer’s Delight збережені.
- Ванільний End-контент та End-декор інших установлених модів прибрані з рецептів, JEI й усіх творчих вкладок. Сервер конвертує залишкові недозволені предмети у звичайні аналоги, забороняє розміщення та використання End-блоків.
- Заблоковано перехід у `minecraft:the_end`, включно з телепортацією. Вихід із уже існуючого Енду залишається можливим. Enderman, Endermite, Shulker, Ender Dragon та End-снаряди не приєднуються до світу; інші істоти дозволені.

Наявний світ або файли виміру не видаляються. У старих збереженнях вилучений нативний декор переноситься на камінь, End-пошта — на звичайну, два ножі — на залізний. Назви й користувацькі NBT зберігаються, форма та властивості вилученого декору втрачаються. Вкладений в інвентар предмет шалкера перетворюється на скриню зі збереженням вкладеного списку предметів. Вміст особистого Ender Chest не переноситься автоматично у звичайні скрині.

## Доступні рецепти

У рецептах звичайних предметів перлина Краю та інгредієнтні теги перлин замінені на **аметистовий уламок**. Аудит установлених 111 модів і ванільних ресурсів охоплює 14 674 рецепти. Конкретні збережені рецепти з перлиною:

| Рецепт | Нова заміна |
|---|---|
| `dawnoftimebuilder:water_source_trickle` | Аметистовий уламок замість перлини; інші інгредієнти й кількість результату збережені |
| `immersive_melodies:ender_bass` | Аметистовий уламок замість перлини; звичайний музичний інструмент залишається |

Рецепти результатів, які самі належать до вилученого End-контенту, вимкнені. Наприклад, End-папір Contact не повертається через заміну інгредієнта. Динамічний прохід KubeJS працює після наявних змін прогресії: він обробляє прямі інгредієнти, теги, альтернативи, ковальські й машинні рецепти та рецепти, додані іншими скриптами. Обов’язковий вилучений інгредієнт вимикає рецепт; із переліку альтернатив вилучаються лише недозволені варіанти.

Повні ID, змінені/вимкнені рецепти, теги й контрольні суми вхідних модів: `audit/content.json`. Нативно вилучені ID: `audit/native.json`.

## Установлення

1. Зупиніть сервер і клієнт. Перед зміною реєстрів збережіть резервну копію світу.
2. На обох сторонах приберіть старі JAR із `REMOVE-OLD-JARS.txt` та встановіть `mods/` із відповідного архіву. Старі й нові версії тих самих модів одночасно залишати не можна.
3. На клієнті встановіть `kubejs/client_scripts/empirecraft_no_end.js`. На сервері встановіть серверні `kubejs/data/` та `kubejs/server_scripts/` з архіву, зберігаючи інші скрипти.
4. Оновіть відповідні записи ADM за `reference-configs/admanticheat_id_list.json`. Цей файл — довідкова копія списку збірки; користувацькі сторонні записи треба зберегти.
5. Повністю перезапустіть сервер та клієнти. Новий мод `empirecraft-no-end-1.0.0.jar` потрібен на обох сторонах. `/reload` не замінює перезапуск після зміни нативних реєстрацій.

## Збірка та перевірки

Потрібні JDK 17+, Python 3 та точні встановлені вхідні JAR із коміту, зафіксованого в `inputs.json`. Інші моди не перебудовуються.

```sh
python end-removal/audit.py --mods server/mods --inputs end-removal/build/inputs --vanilla TOOLCHAIN/client-original.jar
python end-removal/build.py --inputs end-removal/build/inputs --classpath-dir TOOLCHAIN --classpath-dir RUNTIME/libraries
python end-removal/test.py --rhino server/mods/rhino-forge-2001.2.3-build.10.jar --classpath-dir RUNTIME/libraries
python end-removal/update_metadata.py
python end-removal/update_metadata.py --check
python end-removal/smoke.py --runtime RUNTIME --toolchain TOOLCHAIN --inputs end-removal/build/inputs
python end-removal/package.py
```

`test.py` виконує рецептний скрипт на справжньому встановленому Rhino, перевіряє обов’язкові інгредієнти, альтернативи, NBT, теги та незмінені рецепти. ASM-перевірка підтверджує коректність змінених класів. `smoke.py` використовує лише тимчасовий локальний тестовий світ: спочатку початкові реєстри, потім ті самі дані з вилученням End-контенту, перевірками міграції, старих Nether-обмежень, мобів, телепортації й творчих вкладок. Це не запуск графічного клієнта або чинного світу сервера з усіма його плагінами.
