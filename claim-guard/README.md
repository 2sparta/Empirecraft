# Захист приватів від гармат і бомб

`server/mods/empirecraft-claim-guard-1.0.0.jar` — серверний мод для Mohist 71a84ff7 / Forge 47.4.23 / Minecraft 1.20.1, Supplementaries 1.20-3.1.44, Siege Machines 1.39 і Towny 0.101.2.0. Джерело територій і дозволів — Towny.

| Ціль у приваті | Правило |
| --- | --- |
| Блоки, рослини, блоки з інвентарем | Руйнування, дроп від руйнування, розтріскування й утворення вогню цими вибухами заборонені, зокрема для власника привату. |
| Рамки, картини, стійки для броні, транспорт, предмети та інші сутності, що не є гравцями або мобами | Захищені від ураження цими снарядами та вибухами. |
| Гравці | Шкода можлива лише там, де `TownyAPI.isPVP(location)` дозволяє PvP. Дозвіл на будівництво не обходить вимкнене PvP. |
| Моби | Шкода можлива, якщо встановлено гравця, який вистрілив/кинув бомбу, він онлайн і має дозвіл Towny `DESTROY` у точці моба. Використовується `PlayerCacheUtil.getCachePermission`, включно з дозволами конкретної ділянки. |
| Поза приватами або у світі без Towny | Початкова поведінка зброї. |

Перевірки виконуються в точці кожного блока й кожної цілі на момент влучання, в тому числі на межі приватів і в різних світах (`world`, `world_europe` тощо). Вибух ззовні не отримує права руйнувати блоки всередині. Чужі правила скасування подій не перевизначаються.

Перекрито власний алгоритм руйнування CannonBallExplosion, руйнування й ефекти BombExplosion, окреме отруєння SPIKY, синій вогонь, посилений звичайний вибух бомби, прямі влучання, відкидання, розтріскування блоків Siege Machines та його вибухи. Захищені також стріли баліст Siege Machines. Збереження UUID стрільця в Forge persistent data не залежить від того, хто перебуває у гарматі на момент влучання. Старі снаряди без встановленого стрільця не завдають шкоди мобам у приваті.

Коли Towny відсутній, вимкнений, не готовий або перевірка завершується помилкою, небезпечна дія забороняється, включно з територією, статус якої неможливо встановити. Повторне завантаження Towny обробляється автоматично; попередження обмежені одним на 30 секунд. Нових команд, дозволів LuckPerms і клієнтських модів немає.

## Встановлення

1. Зупинити сервер.
2. Додати `empirecraft-claim-guard-1.0.0.jar` із `server/mods/` до `mods/` робочого сервера. Залишити наявні Supplementaries, Moonlight, Siege Machines і Towny.
3. Запустити сервер звичайним для цієї збірки Java 21. Не застосовувати `/reload` для встановлення Forge-мода.
4. Виконати ігрову перевірку нижче перед відкриттям сервера гравцям.

Мод працює лише на сервері; клієнтський набір і його ADM-відбитки змінювати не потрібно. Після оновлення зброї слід перебудувати й перевірити сумісність: версії модів закріплені, Mixin-перехоплення обов'язкові, і невідповідність зупинить завантаження замість мовчазного вимкнення захисту.

## Збірка і перевірки

З кореня репозиторію, після встановлення бібліотек Mohist:

```sh
python claim-guard/build.py --server-home server
python claim-guard/test.py --classpath-dir server
```

Для ізольованої копії залежностей доступний `build.py --classpath-dir PATH`. Для тестів потрібен JDK 21 через версію Towny; байткод самого мода сумісний із Java 17. Збірка не завантажує залежності та не включає код сторонніх модів у результат.

Автоматично перевірено 45 сценаріїв через реальний рефлексивний міст з тестовими Bukkit/Towny: правила PvP, дозволи, об'єкти, негативні координати, межі, світи, створення/видалення привату, зміна дозволів, відсутній/офлайн-стрілець, відмова API, вимкнення та відновлення Towny. Окремо справжній Mixin 0.8.5 застосовано до 10 класів із точних JAR збірки; ASM перевірив стеки й потоки даних після трансформації. Перевірено 23 виклики захисту та сигнатури API встановленого Towny/Mohist. Це перевірка байткоду та правил, а не запуск живого сервера.

## Ігрова приймальна перевірка

На тестовій копії створити сусідні приват і незапривачену територію. Усередині розмістити звичайні блоки, квіти/посіви, рамки, картини, стійку для броні, тварин і ворожих мобів.

- Вистрілити Supplementaries і Siege Machines ззовні та зсередини; повторити для власника і стороннього гравця. Блоки, рослини та об'єкти в приваті мають зберегтися без дропу; ззовні зброя працює як раніше.
- Перевірити звичайну, BLUE і SPIKY бомби: без дозволу моби не втрачають здоров'я, не горять, не отруюються та не відкидаються; з дозволом отримують шкоду.
- При вимкненому PvP перевірити пряму й вибухову шкоду гравцям від власника та стороннього стрільця. Потім увімкнути PvP: ця перевірка повинна дозволяти ураження гравців, не дозволяючи руйнування блоків.
- Повторити на межі приватів, на негативних координатах, в `world_europe`, після перезаходу стрільця та після зміни дозволів, поки снаряд летить.
- Перевірити снаряд без власника: моби захищені; гравці керуються поточним PvP. Перевірити, що посадка іншого гравця в гармату не змінює автора вже випущеного снаряда.

Результат автоматичних перевірок і відбитки залежностей: `validation/weapon-claim-guard.md`. Доступу до живого сервера під час реалізації не було; ігрова приймальна перевірка ще потрібна.
