# Захист приватів від гармат і бомб

`server/mods/empirecraft-claim-guard-1.0.2.jar` — серверний мод для Mohist 71a84ff7 / Forge 47.4.23 / Minecraft 1.20.1, Supplementaries 1.20-3.1.44, Siegeworks beta.11 та Towny 0.101.2.0. Джерело територій і дозволів — Towny. На клієнт цей JAR не встановлюється й до клієнтського списку ADM не додається.

У 1.0.2 видалено обов'язкові цілі Mixin попереднього Siege Machines; класифікатор зброї розпізнає нові SiegeProjectile та AbstractSiegeEntity. Блокові операції Siegeworks/Axiomata додатково захищає інтеграція всередині виправленого Siegeworks: див. `siegeworks/README.uk.md`.

## Правила

Блоки приватів захищені від руйнування й вогню відповідних вибухів, зокрема від власних снарядів. Для Siegeworks додатково перевіряються прямі влучання, створення та приземлення уламків, а також актуальний приват у момент зміни блока. Поза приватами зберігається штатне руйнування. Недоступний або вимкнений Towny, збій API та виклик поза серверним потоком забороняють небезпечну зміну.

Спільний обробник Forge LivingAttackEvent застосовує правила Towny до розпізнаної зброї: гравці залежать від PvP у точці влучання, моби — від дозволу стрільця. Стрілець зберігається при встановленні власника снаряда; поточний пасажир гармати не підміняє автора вже випущеного пострілу. Для Supplementaries залишаються спеціальні перехоплення прямих влучань, ефектів бомб і вибухів. Перевірка нового Siegeworks зосереджена на збереженні блоків; це не загальне вимкнення бойового урону.

## Встановлення

Зупиніть сервер, приберіть старий Claim Guard та Siege Machines, встановіть узгоджений пакет із `siegeworks/`. Він містить потрібні версії Siegeworks, Axiomata, Recruits, TownyRecruits і Claim Guard та резервує старі файли. Не використовуйте `/reload` для заміни Forge-модів. Світ і старі машини автоматично не конвертуються; потрібна резервна копія світу.

## Збірка та перевірки

```
python claim-guard/build.py --server-home server
python claim-guard/test.py --classpath-dir server
python siegeworks/runtime_test.py
```

Для компіляції байткоду мода достатньо Java 17; тест рефлексії встановленого Towny потребує JDK 21. Залежності не завантажуються й не вбудовуються в Claim Guard. `test.py` перевіряє 45 сценаріїв правил і застосовує справжній Mixin до актуальних класів Supplementaries/Minecraft. `siegeworks/runtime_test.py` запускає ізольований позначений світ зі справжнім Mohist/Towny: пряме руйнування, вогонь, уламки, вибухи, зміни приватів і відмову Towny. Звіти актуального комплекту: `siegeworks/audit`.

## Кулдаун бомб

Після ручного кидка бомби Supplementaries сервер установлює спільний кулдаун 800 тіків (40 секунд) для всіх типів. Зміна стека, типу чи руки не скидає його. Повторний заблокований кидок не витрачає бомбу; індикатор Minecraft синхронізується з клієнтом. Поведінка диспенсерів і гармат зберігається.
