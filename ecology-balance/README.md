# Баланс природи та твердого снаряда

- `createbigcannons:shot` (предмет `solid_shot`): проникнення 1,1 → 2,2, маса міцності 3 → 6, міцність 2 → 2,5. Параметри заряджання, польоту, віддачі та шкоди істотам збережені. Перевизначення в `kubejs/data` підхоплює штатний завантажувач боєприпасів CBC та синхронізує серверні параметри клієнтам.
- Природне відновлення: звичайні дерева отримують 90% виборів, усі фруктові/модові разом — 10%. Порода звичайного дерева залежить від біому та клімату. Ліміт 3 дерева/саджанці на чанк, перерва 1200 тіків. Збережено перевірки Towny, вільного місця, ґрунту, сезону та завантажених чанків. Існуючі дерева не видаляються.
- Генерація нових чанків: модові деревні placed features отримують додаткову рідкість 1/8. Звичайні ванільні дерева не проріджуються. Перевизначаються тільки biome placements, що посилаються на деревні configured features; вирощування посаджених гравцем саджанців не змінюється.
- Березозіль = EARLY_SPRING. Корекція температури -0,25 → -0,05, танення снігу 6,25% → 12,5%, інтервали дощу 24000–120000 тіків. Холодні природні біоми та висотний сніг збережені. Зимові паузи між опадами 24000–96000 замість 12000–36000 тіків.
- Тварини: чинні місячні профілі збережені; у сприятливі місяці модові види отримують додаткову вагу ×1,75. Лісові, холодні, тропічні й заболочені середовища мають місцеві поправки. У спекотних тропіках комахи, рептилії й амфібії не зникають через календарну зиму. Біомні списки, природні перевірки освітлення/поверхні та ліміти популяції залишаються чинними. Наявні тварини не видаляються, розведення і яйця не обмежуються.
- Прибрано повторне зниження шансу NATURAL після зміни ваг: раніше зимовий коефіцієнт фактично застосовувався двічі. Для CHUNK_GENERATION залишається одна перевірка ймовірності.

`python3 ecology-balance/build.py` компілює лише переглянуті класи на встановленому Forge runtime, накладає їх на поточні JAR, генерує overrides і оновлює хеші/ADM. Решта байтів JAR, включно з нативним вилученням вмісту й міграціями, перевіряється через аудит. Версії імен JAR збережені; потрібна заміна файлів на обох сторонах і повний перезапуск. Додаткові моди не потрібні.

`python3 ecology-balance/test.py` перевіряє пропорції, біоми, сезони, опади, параметри снаряда та збереження решти класів/ресурсів. CI додатково виконує `native-content/test.py`, перевірку метаданих і `integration_test.py`: фактичне накладання сезонних Mixin на встановлені класи, ASM-перевірку їхнього байткоду та попередні тести календаря.
