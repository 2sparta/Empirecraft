# Рецепти Create та ресурси з китів

Зміни вносяться безпосередньо в JAR модів для Minecraft 1.20.1 / Forge 47.4.23.

## Рецепти

Скануються обидва каталоги `mods/` і `server/mods/`. Вилучаються рецепти всіх вимкнених типів Create та рецепти з вимкненими предметами на вході або виході, включно з вкладеними `forge:conditional`. Враховуються теги, які складаються тільки з вимкнених предметів, а також залежні досягнення книги рецептів. Змішані теги та робочі альтернативи не блокуються.

Нативне виправлення `CreateJEI$CategoryBuilder.build` реєструє тільки `milling`, `pressing`, `sawing`, `block_cutting`, `item_application`. Решта 18 категорій, включно з усіма чотирма способами обробки вітрогоном і механічним крафтом, не реєструються. Тому зникають і автоматично створювані записи JEI, яких немає в JSON. Пічні, коптильні та плавильні рецепти Minecraft залишаються доступними. Креслення й ручні рецепти залишаються.

## Кити

Кількість задається в `whale-loot.json`, у предметах (стак = 64). Зареєстровані габарити взяті з `WonderousseaModEntities` установленого JAR; врахована також масивність виду. Значення є ігровим балансом.

| Вид | Жир | М'ясо | Кістки | Китовий вус |
|---|---:|---:|---:|---:|
| Синій | 448–512 | 384–512 | 128–192 | 128–192 |
| Гренландський | 448–512 | 320–448 | 96–160 | 128–192 |
| Гладкий | 384–448 | 320–448 | 96–160 | 96–160 |
| Фінвал | 384–448 | 320–448 | 96–160 | 96–160 |
| Горбатий | 320–384 | 256–384 | 64–128 | 64–128 |
| Сірий | 256–320 | 256–320 | 64–96 | 64–96 |
| Малий смугач | 192–256 | 128–192 | 32–64 | 32–64 |
| Пляшконіс | 128–192 | 96–160 | 24–48 | — |
| Білуха / нарвал | 64–128 | 64–96 | 16–32 | — |

Гренландський, гладкий, горбатий і сірий кити залишають три варіанти трупів кожен. ПКМ по трупу одноразово видає всі ресурси й прибирає його. Повторні пакети та збережена NBT-позначка не дозволяють отримати лут вдруге. Розбирання замінює стару випадкову видачу по одному предмету, зокрема випадкові вибухи під час розбирання. В інших шести видів у початковому моді окремого трупа немає; ресурси випадають після смерті. Усі чотири стани дорослої білухи мають однаковий лут. Дитинчата, дельфіни та декоративні морські розплідники не змінюються.

Видаються окремі легальні стаки. Таблиці смерті використовують кілька пулів, адже `set_count` обрізає один результат до 64. Правило `doMobLoot=false` забороняє видачу.

## Відтворення

Початковий стан модів: commit `84f368498fd2c181aafa1a720bd239f61ec9ad6b`. SHA-256 двох нативних входів зафіксовані в `inputs.json`. Інші входи та вилучені рецепти записуються в аудиті; усі сторонні ресурси залишаються побайтово незмінними. Наявні несумісні з JSON рецепти сторонніх модів відмічаються в аудиті та не переписуються.

```sh
python3 recipe-whales/build.py --classpath-dir server/libraries
python3 recipe-whales/test.py
python3 -c 'import sys; sys.path.insert(0,"recipe-whales"); import build,json; build.install(json.loads((build.ROOT/"audit/build.json").read_text()))'
```

`install` оновлює JAR обох сторін, контрольні суми, `modpack-lock.json` і хеші вже наявних записів ADM; інші моди та ресурс-паки у списку ADM зберігаються. Для повторної збірки потрібні вхідні JAR з указаного початкового commit.

Додатковий `smoke.py` запускає ізольований справжній Forge-сервер із тестовим світом і перевіряє всі дорослі види й варіанти трупів, фактичні діапазони луту, розміри стаків, повторний виклик, NBT та `doMobLoot`. Потрібен підготовлений Forge runtime і named/SRG toolchain з `seasonal-leaves/`.

Готові файли встановлюються одночасно на сервері та клієнтах із видаленням старих копій змінених модів. Після оновлення потрібен повний перезапуск гри й сервера. Перевірка графічного JEI і запуск на робочому Mohist-сервері залишаються ручними.
