# Create для середньовічного Empirecraft

Версія: **Minecraft 1.20.1 / Forge 47.x / Create 6.0.8-medieval.2**.

Це змінений JAR Create та серверний скрипт KubeJS, який прибирає також сторонні рецепти забороненого обладнання після `/reload`. Початкові ідентифікатори реєстрів збережені для сумісності світів. Заборонені предмети приховані з вкладок Create, пошуку Creative та JEI; їх установлення й використання заблоковано подіями Forge. Адміністративні команди на кшталт `/setblock` не є звичайним установленням блоків.

## Виправлення запуску в medieval.2

`medieval.1` залишав клас `NozzleBlockEntity` у JAR, але замінював його `tick` і `lazyTick` порожніми. Valkyrien Skies 2.4.11 додає в ці методи `WrapOperation` для `VecHelper.getCenterOf`; після вирізання коду ін'єкція не знаходила ціль. Forge/Mohist міг показувати це як `NoClassDefFoundError`, а клієнт — як `MixinTransformerError`.

У `medieval.2` заборонена дія завершується перевіркою на початку методу. Початкові інструкції, точки ін'єкцій, локальні змінні й обробники винятків збережені; промислові механіки залишаються вимкненими. Перевірено реальні Mixin для сопла, вентилятора й будівельної гармати в SERVER та CLIENT середовищах Mixin 0.8.5. Повний запуск Minecraft ці тести не виконують.

## Що залишено

- Водяні колеса, вітряки, вітрила та ручні приводи.
- Вали, шестерні, редуктори, муфти, реверс, ланцюгові передачі й програмована передача для зупинки воріт на потрібній висоті.
- Канатні підйомники, механічні та липкі поршні, подовжувачі, каретки, підшипники, шасі, наклейки й суперклей.
- Креслення: чисте креслення, креслення з пером, стіл креслень, готове креслення та схема рецептів.
- Жорна для борошна/барвників, механічна пилка, прес, прості жолоби, лійки та ремені.
- Кам'яний декор, вікна, мідна покрівля, двері, сидіння, скатертини, ящики інструментів.
- Звичайні дротові redstone-сигнали й контакти для керування воротами.

## Що вимкнено

Паровий двигун, котельне обладнання, свистки, творчий мотор, вентилятори та їх обробка, картоплемет, будівельна гармата, світобудівник, симетрична паличка, потяги й рейки Create, електронні компоненти, бездротові контролери, дисплеї, фабрична система пакунків, роботизовані маніпулятори, автокрафт, автоматичний видобуток/врожай, дроблення руди, промислові рідини, пальники та міксери.

Промивання, обдування лавою, копчення та обробка душами вимкнені в коді вентилятора. Їх не поверне рецепт із datapack. Жорна не дають металів або досвіду. Звичайна виплавка видобутої руди в печі залишається. Це обмежує способи Create; ванільні ферми мобів і механіки інших модів потребують власних правил.

Старі заборонені блоки не видаляються зі світу автоматично. Їхні основні `tick`/`lazyTick` та джерела парової/творчої енергії вимкнені. Перед перенесенням на робочий світ необхідна перевірка копії світу; взаємодію всіх старих машин та сторонніх доповнень не перевірено в Minecraft.

## Ручні рецепти

Для воріт не потрібні електронні лампи, точні механізми або нагрітий міксер:

- 3 мідні злитки + 1 цинковий → 4 латунні злитки.
- Колода + андезитовий сплав → андезитовий корпус.
- 2 злитки одного металу → 1 лист відповідного металу (залізо, мідь, золото, латунь). Прес зберігає ефективніший звичайний рецепт.
- Латунний злиток, оточений 8 дошками → латунний корпус.
- Програмована передача: ` C /GBG/ R `, де C — годинник, G — мала шестерня, B — латунний корпус, R — redstone.
- Ланцюгова передача: `CCC/SAS` → 2; C — ланцюг, S — вал, A — андезитовий корпус.
- Регульована ланцюгова передача: ` G /CRC/ A `; G — шестерня, C — ланцюг, R — redstone, A — андезитовий корпус.
- Блок керування конструкцією: ` L /CAC/ R `; L — важіль, C — шестерня, A — андезитовий корпус, R — redstone.
- 2 redstone-контакти: `IQR/AAA`; I — залізний злиток, Q — кварц, R — redstone, A — андезитовий сплав.

## Встановлення

1. Зупини сервер і зроби резервну копію. Почни з окремої копії світу.
2. У клієнтській і серверній папках `mods` заміни будь-який старий `create-*.jar` на **один** `create-1.20.1-6.0.8-medieval.2.jar` з архіву. Не залишай другу копію Create. У папці `mods` також має залишитися лише один Sails — `vs_sails-1.20.1-0.3.2-empirecraft.1-forge.jar`; старий `vs_sails-1.20.1-0.3.2-forge.jar` вилучено з клієнтської збірки. Flywheel, Ponder і Registrate вже вбудовані в цей JAR, як у початковому 6.0.8.
3. На сервер перенеси `kubejs/server_scripts/zz_medieval_create.js` з архіву. KubeJS, Rhino й Architectury уже є у збірці Empirecraft.
4. Онови чинний ADM ID-файл через `python medieval-create/update_adm.py --id-file <шлях-до-списку> --jar <новий-JAR>` з репозиторію. Скрипт перевіряє вихідний integrity hash та не вимикає перевірки. Усі гравці повинні мати однаковий новий JAR.
5. Перезапусти сервер і клієнт. Перевір вхід, рецепти, приховані предмети, креслення, ворота, рухомий міст і відсутність промивання. Одного `/reload` недостатньо для заміни JAR.

Репозиторій містить файли серверної збірки, але доступу до процесу працюючого сервера ця зміна не надає. Архів потрібно встановити на хості окремо.

## Відтворювана збірка

Потрібні Python 3.10+ та JDK 17+ з модулями `jdk.compiler`, `jdk.jdeps` і вбудованим ASM. Основна збірка й `test.py` не потребують Gradle або зовнішніх бібліотек. Для `compat_test.py` потрібна встановлена папка `server/libraries` з Mohist/Forge/Mixin 0.8.5 та актуальний JAR Valkyrien Skies. Вбудовані залежності Create/VS тест витягує автоматично.

```bash
python medieval-create/build.py /path/to/create-1.20.1-6.0.8.jar
python medieval-create/test.py /path/to/create-1.20.1-6.0.8.jar
python medieval-create/compat_test.py --runtime server --vs mods/valkyrienskies-120-2.4.11-empirecraft.1.jar --create medieval-create/dist/create-1.20.1-6.0.8-medieval.2.jar
```

Скрипт приймає лише початковий JAR із SHA-256 `6fbb910c367dbce8e4fc7e5bf64b6edd4de980906ed00af8e47e4af843c0d9b0`. Результати записуються в `medieval-create/dist/`. Розповсюджується зі збереженою ліцензією MIT оригінального Create; код профілю — MIT.

## Межі перевірки

Перевірено компіляцію Java 17, структуру й CRC JAR, стекові операції змінених методів через ASM BasicVerifier, політику всіх вбудованих рецептів, доступність основних механізмів і креслень, збереження вбудованих залежностей та сценарії скрипта KubeJS. Додатково перевірені збереження початкового коду 131 захищеного методу, виконання захисту з JVM `-Xverify:all` і реальна трансформація трьох класів через Mixin Valkyrien Skies в обох середовищах. Це не замінює запуск Mohist/Forge і графічного клієнта. Вони в цьому середовищі не запускалися. Звіт `validation.json` містить точний перелік змінених методів і рецептів.
