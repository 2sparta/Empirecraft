# Одноразова сірка та цинк для імпортованої мапи

Додано оригінальний `sulfur_gunpowder-1.0.0-forge-1.20.1.jar` із вкладення без змін у `mods/` і `server/mods/`. Його SHA-256: `dc9382efc0e71d3535158ede0a89b1341fab330703a25b488529b4d05a7493f4` (актуальна контрольна сума також у `.jar.sha256`). Мод потрібний серверу й усім клієнтам. Для ADM підготовлено мінімальний `ore-retrogen/adm-entry.json` і локальний скрипт оновлення. Записи двох нових модів містяться в `ore-retrogen/modpack-entries.json`; повний перелік збірки не включений до цього оновлення. Скрипт зберігає всі інші записи й перераховує `integrityHash`; повний файл із відомостями комп’ютера не включений до цього оновлення.

`server/mods/empirecraft-ore-retrogen-1.0.0.jar` — окремий **серверний** Forge-мод; клієнтам він не потрібний. Потрібні Minecraft 1.20.1, Forge 47.4.23+ у межах 47.x, Create 6.0.8+ і завантажений мод сірки. Поточний Create `6.0.8-medieval.2` не змінено.

## Як з'являється руда

- Під час завантаження чанків у `minecraft:world_europe` та `minecraft:overworld` чанк потрапляє в чергу. За замовчуванням обробляється **один чанк кожні 5 тіків** сумарно на весь сервер. Мод не примушує завантажувати сусідні чанки, не запускає новий генератор рельєфу й не проходить усю карту під час старту.
- Ціль — **30 блоків сірної руди й 30 блоків цинкової руди на чанк** у висотному діапазоні Y −64…64. Наявна руда в цьому діапазоні враховується: якщо є 5 блоків сірки, додаються ще 25. Вже наявний надлишок не видаляється. Нові процедурні чанки, якщо вони колись з'являться, також лише доповнюються до цілі.
- Руда з'являється невеликими жилами по 4–8 блоків; залишкова жила може бути меншою. Вона замінює лише stone, granite, diorite, andesite, deepslate та tuff. У deepslate/tuff використовується `create:deepslate_zinc_ore`, в інших породах — `create:zinc_ore`. Для сірки використовується єдиний блок моду `sulfur_gunpowder:sulfurore`.
- Залишається не менше 8 блоків до поверхні/морського дна. Повітря, вода, ґрунт, скрині, інші руди й блоки поза списком порід не замінюються. Чанк без достатньої кількості придатної породи отримує менше руди, аж до нуля.
- Після завершення в **ForgeCaps самого чанка** записується `empirecraft_ore_retrogen:one_time_ores` → `Complete=true`. Блоки й позначка зберігаються в одному записі чанка. Видобуток, перезаходи, перезапуски та зміни квот у конфігурації **не запускають повторну генерацію**. Навіть порожній чанк позначається завершеним. Не видаляйте цю позначку й не відновлюйте стару версію світу, якщо бажаєте зберегти одноразовість.

Розміщений гравцем звичайний камінь неможливо відрізнити від природного за станом блока. Підземні споруди саме з перелічених порід у зоні генерації теж можуть отримати руду; Towny-привати не виключаються. Перед першим увімкненням збережіть резервну копію мапи. Повного автоматичного відкату немає.

## Установлення

1. Зупиніть сервер. Скопіюйте серверні JAR та `.sha256` із цього оновлення в його `mods/`: `sulfur_gunpowder-1.0.0-forge-1.20.1.jar` і `empirecraft-ore-retrogen-1.0.0.jar`.
2. Скопіюйте `server/config/empirecraft_ore_retrogen-common.toml` у серверний `config/`. Перед запуском виконайте з кореня репозиторію `python ore-retrogen/pin.py --apply-adm --apply-lock --server-home /шлях/до/сервера` (для папки `server` у репозиторії достатньо `python ore-retrogen/pin.py --apply-adm --apply-lock`). Потрібен Python 3.10+. Скрипт доповнить локальний modpack lock лише двома новими записами, змінить наявний ADM-файл локально та створить поруч резервну копію `.json.before-sulfur`. Не додавайте цю копію до GitHub. Інші конфіги й файли регіонів замінювати не потрібно.
3. Установіть **тільки мод сірки** з `mods/` усім гравцям. Серверний retrogen у клієнтську збірку не копіюйте.
4. Повністю запустіть сервер. У відвідуваних частинах карти руда додасться автоматично; віддалені незавантажені чанки обробляться під час наступного відвідування. `/reload` не встановлює Forge-моди.

Конфігурація: `config/empirecraft_ore_retrogen-common.toml`. `dimensions` містить **ID вимірів**, а не довільні назви папок. У поточній збірці мапа Europe має ID `minecraft:world_europe`. Інші світи, Nether та End не обробляються. Чанки за чинним world border також пропускаються; це виключає віддалений технічний shipyard VS у звичайному вимірі.

Параметри: `enabled`, `dimensions`, `sulfurPerChunk`, `zincPerChunk`, `minY`, `maxY`, `surfaceClearance`, `intervalTicks`, `chunksPerInterval`. Зміни застосовуйте після перезапуску. Вимкнення/підняття квот не скидає завершені чанки. Серверному оператору доступні `/empireores status` (черга й налаштування) та `/empireores here` (стан поточного чанка та число доданих блоків).

## Збірка та перевірки

```sh
# Готовий named/SRG toolchain готується на базі pinned inputs наявного sails/build.py.
python ore-retrogen/build.py --server-home server
python ore-retrogen/test.py
python ore-retrogen/pin.py --check
# На зупиненому робочому сервері, перед першим запуском:
python ore-retrogen/pin.py --apply-adm --apply-lock
# Із установленими стандартними бібліотеками Forge 47.4.23:
python ore-retrogen/smoke.py --server-home /path/to/forge-runtime --toolchain sails/build
```

Для кешованого toolchain можна передати `--toolchain /path/to/sails/build`. Збирання використовує Java 17 bytecode й детермінований ZIP. `sails/build.py` за потреби готує загальні мапінги та компіляційні бібліотеки; не включайте його сторонні результати в це оновлення.

`test.py` перевіряє межі чанка/висоти, точні квоти, детерміновані жили, наявну руду, відсутність субстрату, відмови розміщення та вибір deepslate-варіанта. `smoke.py` створює **тимчасовий** сервер із реальними sulfur/Create JAR і проходить три окремі запуски: збереження старих чанків без руди; одноразове доповнення; перезапуск після повного видобутку. Окремо перевіряються ForgeCaps, порожній чанк, скриня, стороння руда й заборонений вимір. Тестовий `empirecraft-ores-test.jar` ніколи не встановлюйте на робочий сервер.

Тест Forge не є запуском усієї робочої збірки Mohist/Towny. Фактичний хостинг не перезапускається засобами цього репозиторію; зміни активуються після встановлення й повного перезапуску сервера.
