# Одноразова сірка, цинк і кварц для імпортованої мапи

Серверний Forge-мод `empirecraft-ore-retrogen-1.1.0.jar` додає **15 кварцових блоків** (`minecraft:quartz_block`), 30 блоків сірної та 30 блоків цинкової руди на чанк. Це цілі з урахуванням уже наявних відповідних блоків у діапазоні Y −64…64; надлишок не видаляється. За нестачі придатної породи блоків буде менше.

## Правила розміщення

- Виміри: `minecraft:world_europe` і `minecraft:overworld`. Nether, End, інші виміри та чанки за world border пропускаються.
- Під час завантаження чанк потрапляє в чергу; глобально обробляється один чанк кожні 5 тіків. Примусового завантаження чанків або обходу всієї карти немає.
- Невеликі жили по 4–8 блоків замінюють тільки stone, granite, diorite, andesite, deepslate і tuff. Залишається щонайменше 8 блоків до поверхні/морського дна. Повітря, вода, скрині та інші руди не замінюються.
- Кварц завжди є звичайним кварцовим блоком. У deepslate/tuff цинк використовує `create:deepslate_zinc_ore`; в іншій породі — `create:zinc_ore`. Сірка — `sulfur_gunpowder:sulfurore`.

## Одноразовість і оновлення з 1.0.0

Стан зберігається разом із блоками в ForgeCaps чанка під ключем `empirecraft_ore_retrogen:one_time_ores`. Стара позначка `Complete` і лічильники сірки/цинку зберігаються; кварц отримав окремі `QuartzComplete` і `QuartzAdded`, формат `Version=2`.

**Уже оброблені версією 1.0.0 чанки отримають кварц, але видобуті сірка й цинк не відновляться.** Після завершення кварцового проходу видобуток, повторне завантаження, перезапуск або зміна квот не запускають його знову. Навіть порожній чанк позначається завершеним. Не видаляйте позначки завершення, якщо хочете зберегти одноразовість.

Звичайний камінь, установлений гравцями, неможливо відрізнити від природного за станом блока: споруди з перелічених порід теж можуть отримати вкраплення. Towny-привати не виключаються. Повного автоматичного відкату немає.

## Установлення

1. Зупиніть сервер і збережіть резервну копію світу.
2. Видаліть старий `empirecraft-ore-retrogen-1.0.0.jar` та його `.sha256`; встановіть `server/mods/empirecraft-ore-retrogen-1.1.0.jar` із контрольною сумою. Дві версії одночасно не залишайте.
3. Додайте `quartzPerChunk = 15` до свого `config/empirecraft_ore_retrogen-common.toml` або використайте конфіг з архіву. Власні налаштування інших параметрів можна зберегти.
4. Повністю запустіть сервер. Клієнтам це оновлення не потрібне; оригінальні Create та мод сірки залишаються потрібними обом сторонам.

Готовий серверний архів: `ore-retrogen/dist/Empirecraft-Quartz-1.1.0.zip`. Зміни активуються після встановлення й повного перезапуску сервера; `/reload` не встановлює Forge-моди.

Потрібні Minecraft 1.20.1, Forge 47.4.23+ у межах 47.x, Create 6.0.8+ і sulfur_gunpowder 1.0.0+. Конфіг: `enabled`, `dimensions`, `sulfurPerChunk`, `zincPerChunk`, **`quartzPerChunk`**, `minY`, `maxY`, `surfaceClearance`, `intervalTicks`, `chunksPerInterval`. `dimensions` містить ID вимірів, а не назви папок. Команди оператора: `/empireores status`, `/empireores here`; обидві показують також кварц.

## Збирання та перевірки

```sh
python ore-retrogen/test.py
python ore-retrogen/build.py --server-home server
python ore-retrogen/build.py --fixture --server-home server
python ore-retrogen/state_test.py
python ore-retrogen/pin.py --apply-lock
python ore-retrogen/pin.py --check
python ore-retrogen/package.py
```

`toolchain.py` готує ізольовані named/SRG бібліотеки із встановленого runtime та перевірених SHA-256 входів `sails/build-inputs.json`; сторонні моди кораблів не перебудовуються. Потрібні Java 17 і Python 3.10+. Можна передати `--toolchain /path/to/cache`.

`test.py` перевіряє квоти, детермінованість, межі, поверхню, наявний кварц і міграцію без відновлення старих руд. `state_test.py` перевіряє справжній серіалізатор Forge capability: старий NBT, незалежні позначки й запис/читання стисненого NBT з диска. `pin.py` оновлює записи руд у modpack lock; ADM містить лише незмінений клієнтський мод сірки.

Для встановленого стандартного Forge runtime доступний окремий інтеграційний тест трьох запусків:

```sh
python ore-retrogen/smoke.py --server-home /path/to/forge-runtime
```

Він використовує тимчасовий світ та тестовий `empirecraft-ores-test.jar`, який не можна встановлювати на робочий сервер. Звичайна CI-перевірка компілює цю фікстуру, але не запускає повну робочу збірку Mohist/Towny.
