# KnockedBack для Empirecraft

Парний мод `knockedback-1.6.2-empirecraft.1.jar` потрібен на клієнті та сервері. Залежність Player Animator вже є у збірці; інсталятор також містить її точну версію.

Після смертельного удару гравець лежить із 1 HP. Час до смерті випадково визначається один раз: 1000–2400 серверних тіків (50–120 секунд за 20 TPS). Після завершення часу він помирає, а не одужує. Перетягування, утримування, початок підняття або наступні удари не зупиняють і не скидають відлік. Лише завершений порятунок прибирає стан і таймер. Звичайні механіки добивання, обхідні типи пошкодження та порятунок модом збережено. Вихід із сервера в лежачому стані, як у вихідному моді, спричиняє смерть; перезаходом відлік скинути не можна.

Ефекти відчуває лише потерпілий: за 15 секунд починається серцебиття, за 10 секунд — затемнення, останні 8 секунд зображення світу повністю чорне. Після порятунку або смерті ефекти прибираються. Звук поважає гучність клієнта. Власний звук створено локально.

У лаунчері 0.1.3 перед запуском є окремий прапорець «Ефекти перед смертю: серцебиття й затемнення». Він незалежний від Potato/Balanced/High і ефектів LSO. Вимкнення прибирає обидва ефекти, але не змінює смерть, таймер чи можливість порятунку. Налаштування зберігається для кожного профілю. Без лаунчера можна додати `"deathEffects": false` у `config/empirecraft-launcher-profile.json`, зберігши існуюче поле `profile`, і перезапустити гру. За відсутності налаштування ефекти увімкнені.

Керування: утримуйте `H` біля потерпілого для підняття, правий `Ctrl` — перенесення в лаунчері. Старе власне призначення клавіші зберігається. У вихідному моді для перенесення стоїть `V`, тому без лаунчера змініть її в налаштуваннях керування, щоб не конфліктувала з TFC. Добивання — `B`. Усі ці клавіші можна переназначити.

## Встановлення

Зупиніть гру та сервер. Розпакуйте парний архів в окрему папку. Для перевірки запланованих дій:

```
python install.py --client "шлях/до/клієнта" --server "шлях/до/сервера"
```

Додайте `--apply`, щоб встановити. Інсталятор перевіряє хеші, робить резервні копії замінених JAR/ADM і зберігає інші записи ADM. Файли світів не змінюються. Невідому сторонню версію цього моду не замінює автоматично.

Для нового прапорця потрібен оновлений застосунок лаунчера; «Перевірити збірку» оновлює ігрові файли, а не код уже встановленого застосунку.

## Збірка та перевірки

`python knockedback/build.py` перевіряє закріплений оригінальний JAR, змінює чотири точно визначені ділянки KnockedManager, додає три допоміжні класи й локалізацію/звук. Усі інші початкові класи збережено побайтово. `python knockedback/runtime_test.py` працює лише в окремому позначеному тестовому світі. Результати — у `audit/`.
