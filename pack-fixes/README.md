# Empirecraft Pack Fixes 1.0.0

Один Forge-мод для клієнта й сервера Minecraft 1.20.1 разом з виправленими тегами збірки.

- Під час використання кісткового борошна сторонній обробник взаємодії не може створити поруч предмет `overgeared:steel_arrow`. Обробляються обидві руки, блоки, скрині та використання в повітрі. Контекст закривається також після винятку; звичайні стріли, насіння й інший дроп поза цим випадком збережені.
- Обов’язкові посилання на вирізані модові блоки більше не відхиляють цілі ванільні теги. Виправлено всі згенеровані ванільні накладки тегів, зокрема добування кіркою й сокирою, сходинки, плити, стіни та рибу; клієнтські й серверні дані однакові.
- Морський прапор Engagement плавно повертається за тим самим вітром Sails, що й вітровказівник. Враховуються від’ємна сила вітру, світові координати та поворот/нахил фізичного корабля. Закрите після повороту полотно не надає захисту.
- Українські й російські переклади автоматично завантажуються з цього JAR. Окремо скачувати або вмикати ресурс-пак перекладів не потрібно. Доповнено вбудовані локалізації Overgeared, Sails, Betsy Ross та Engagement; повідомлення й ліцензії перекладачів збережено всередині моду. Оригінальні JAR цих модів не перепаковуються.

## Установлення

Зупиніть гру й сервер. Розпакуйте ZIP оновлення: `client/` — у папку клієнта, `server/` — у папку сервера. На обох сторонах має бути один і той самий `empirecraft-pack-fixes-1.0.0.jar`; скопіюйте також відповідні папки `kubejs/` та актуальний ADM. Попередні версії цього моду видаліть разом з їхніми `.sha256`. Збереження й конфіги не видаляйте. Потрібен повний перезапуск.

Повний ADM у пакеті відповідає складу цієї гілки Empirecraft. Для власного складу змініть лише запис `empirecraft_pack_fixes`, а старий запис `Empirecraft-Translations-uk-ru-1.1.0.zip` більше не потрібен. Інші ресурс-паки залишаються як були.

У грі виберіть українську мову. Мова міських команд і меню Towny має окреме персональне налаштування: `/language uk`. Відкритий старий екран закрийте й відкрийте знову.

## Відтворення й перевірки

У відповідному checkout Empirecraft потрібні JDK 17, підготовлений SDK `sails/build/` та зафіксований `pack-fixes/inputs/Empirecraft-Translations-uk-ru-1.1.0.zip`.

```sh
python pack-fixes/repair_tags.py
python pack-fixes/build.py
python pack-fixes/test.py
python pack-fixes/native.py --profile server --with-addon --java /path/to/java21
python pack-fixes/native.py --profile client --with-addon --java /path/to/java21
python pack-fixes/release.py --install
```

Два нативні профілі запускають тимчасові світи з відповідними серверними або клієнтськими KubeJS-даними. Клієнтський рендер перевіряється на справжньому байткоді та властивостях напрямку; це не запуск графічного Minecraft. Робочий світ не змінюється. Звіт містить точний SHA-256 перевіреного JAR і межі перевірки.
