# Виправлення вильотів і навантаження — пакет 1

Пакет містить Pack Fixes 1.0.2 для обох сторін, серверний EmpirecraftChat 1.1.1 та вже перевірене виправлення довідника 1.0.3 з рецептами паперу й книг.

Закрий клієнт і зупини сервер. Розпакуй архів і запусти з цієї папки:

```sh
python runtime_installation.py --client "/шлях/до/клієнта" --server "/шлях/до/сервера"
```

Потрібний Python 3.11 або новіший. Можна вказати тільки одну сторону; для одиночної гри достатньо `--client`. Інсталятор перевіряє обидві сторони до запису, робить резервні копії в `.empirecraft-backups/runtime-1`, узгоджує хеші двох модів у серверному ADM і зберігає інші записи та налаштування. Перезапусти гру й сервер після оновлення.

Зміни:

- Палітра блоків під час збереження чанка перебирає зайняті ID без проходу через невикористані позиції масиву. Порядок ID і формат збереження залишаються такими самими. Для нестандартної розрідженої палітри виконується початковий алгоритм.
- Ponder не реєструє сцени для прибраного вмісту або схеми з недоступними блоками й істотами. Перевірено всі 178 схем Create, включно зі сценою порожнього пальника, яка спричиняла виліт. Для недоступних предметів та описів про Ад вимкнено також текстові підказки Create.
- JEI не отримує порожній список видалення інгредієнтів від фільтра Create. Фільтрація непорожніх списків працює як раніше.
- Читання сили стрибка через Bukkit/CoreProtect повертає стандартне значення атрибута для модових верхових істот без ванільного атрибута. Наявні значення сили стрибка збережені.
- Чат завантажується з поточним каталогом усіх 137 титулів. Для 39 наявних зображень збережені початкові піктограми; решта 98 титулів відображаються текстовими назвами.
- Якщо після початку гри головний потік сервера не завершує тік понад 30 секунд, у лог один раз записується його стек. Це допомагає знайти причину зависання при вимкненому штатному watchdog.
- Серверна симуляція встановлюється на 8 чанків відповідно до налаштування збірки. У наданому профілі вона була 16: це збільшує область оновлення істот і світу. Дальність огляду та інші параметри сервера інсталятор зберігає.

Рецепти книги й паперу та команда отримання довідника описані в `HANDBOOK-INSTALL-UA.md`.

Щодо продуктивності: наданий профіль містить тільки потік сервера й закінчується до зафіксованого зависання. Під час цього профілю сервер тримав приблизно 20 TPS; головне виміряне вузьке місце — серіалізація чанків. Результат прискорення перебору палітри наведений у `verification.json` як окремий тест операції, а не як прискорення всієї гри.

Для вимірювання саме клієнта натисни **F3+L** під час повільного завантаження чанків. Minecraft запише приблизно 10 секунд і повідомить шлях до ZIP у папці `debug/profiling`. Цей звіт покаже роботу клієнта без додавання модів і зміни ADM. Якщо сервер знову зависне, збережи лог із повідомленням `Empirecraft tick diagnostic`.
