# Empirecraft — українська та російська локалізації

Ресурс-пак для поточної збірки Minecraft Java 1.20.1 / Forge. Обидві мови містяться в одному ZIP. Він доповнює вбудовані переклади встановлених модів, зокрема вкладених бібліотек, і перекладає довідники Patchouli.

## Установлення

1. Скопіюйте `Empirecraft-Translations-uk-ru-1.0.0.zip` у папку `resourcepacks` **кожного клієнта**. Не розпаковуйте ZIP.
2. У грі відкрийте «Налаштування → Набори ресурсів», увімкніть цей пак і поставте його вище за інші перекладацькі паки.
3. У «Мова» оберіть **Українська (Україна)** або **Русский (Россия)**.
4. Перезапустіть клієнт, щоб оновити тексти, які моди кешують під час запуску.

Для російської: скопируйте ZIP в `resourcepacks`, включите набор выше остальных переводов, выберите «Русский (Россия)» и перезапустите клиент.

Серверні JAR, ADM, конфіги, рецепти та світи не змінюються. Додаткові моди або інтернет під час гри не потрібні. Вимкнення паку повертає початкові мовні ресурси.

## Що перевірено

`coverage.json` містить точний перелік просторів назв і покриття англійських ключів для обох мов. Перевірки звіряють результат з мовними файлами встановлених JAR, контролюють JSON, підстановки `%s` / `%d` / `%1$s`, форматування й посилання в книгах. Метадані та рецепти книг залишаються незмінними.

Давні назви місяців Empirecraft збережено; російською використано відповідні форми, а не звичайні назви місяців. Для ковальства, стрільництва й судноплавства додано редакторський словник.

## Межі перевірки

Для відсутніх текстів використано автоматичні чернетки; ключову ігрову термінологію та технічне форматування перевірено окремо. Повну ручну вичитку кожного речення і запуск графічного клієнта не виконано. Імена авторів, назви модів, команди, технічні позначення та деякі власні назви можуть залишатися латинкою.

Ресурс-пак перекладає текст, доступний через мовні ключі та файли Patchouli. Жорстко задані в коді повідомлення, серверний чат плагінів і написи всередині текстур потребують окремих змін відповідних модів або плагінів.

## Відтворення

`python3 translations/scan.py` оновлює аудит зі встановлених `mods/` і `server/mods/`. `python3 translations/review.py` застосовує термінологічні правки. `python3 translations/build.py` без мережі перевіряє тексти та відтворює ZIP і SHA256.

`bootstrap.py` — одноразовий інструмент отримання чернеток, не частина гри або фінальної збірки. Джерела й авторство наведено в `CREDITS.md` та `community-sources.json`.
