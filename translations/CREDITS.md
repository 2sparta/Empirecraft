# Джерела перекладів

- Вбудовані локалізації — автори та перекладачі відповідних модів. Початкові JAR залишаються незмінними; у готовий ZIP потрапляють лише доповнені або змінені мовні рядки.
- **Starman / StarmanMine142** — [Ukrainian Mods Translate](https://github.com/StarmanMine142/ukrainian-mods-translate), MIT. Точна редакція зафіксована в `community-sources.json`.
- **Tenwoc та учасники** — [Mods Ukrainian Translate Pack](https://github.com/Tenwoc/Mods-Ukrainian-Translate-Pack), MIT згідно зі [сторінкою автора](https://modrinth.com/resourcepack/ukrainian-translate-pack). Частина рядків походить від первісних перекладачів модів, як зазначено автором паку.
- **Rushan Mukhutdinov / Deflecta / RushanM та учасники** — [Modded Minecraft Localization Resource Pack](https://github.com/RushanM/Modded-MC-L10n-Resource-Pack), MIT.
- **Russian Translations and Fixes та учасники** — [RTF](https://github.com/Russian-Translations-and-Fixes/RTF), MIT.
- Відсутні переклади підготовлено як автоматичні чернетки Google Translate з подальшими редакторськими термінологічними правками для Empirecraft. Це не означає повної ручної вичитки всіх текстів.

Ліцензійні повідомлення використаних відкритих проєктів збережено в `licenses/`. Дані про джерела окремих імпортованих ключів зберігаються в `community-provenance.json` у репозиторії. Назви модів належать їхнім авторам.
