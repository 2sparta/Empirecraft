# Sails 14 та Ship Physics 1.2.2 — хвилі, осадка й сухі відсіки

Корабель слабо хитається за ясної погоди, сильніше під дощем і ще сильніше
під час грози. Рух складається з кількох плавних коливань крену й диференту;
великі корпуси хитаються слабше. Хвилі діють лише при контакті з водою,
не змінюють курс і не перевертають перекинутий корабель. Опущений якір
зберігає попереднє гальмування та повну фіксацію.

Додано оригінальні звуки скрипу корпусу й хлюпоту води, із субтитрами.
Під час ударних пошкоджень чути удари й ламання відповідного матеріалу.
Звуки прив'язані до реального положення корабля або місця контакту;
кількість звуків обмежена для кожного корабля. Скасоване захистом
пошкодження не запускає ударний звук.

Корпуси з буями більше не тримаються майже над водою: мінімальна занурена
частка їхнього об'єму витіснення — 35% замість 3%. Маса може збільшувати
осадку понад цей мінімум. Звичайні корпуси зберігають рідну плавучість VS.
Це не фіксована висота корабля: підтримка залежить від води та навантаження.

## Палуби нижче ватерлінії

Увімкнено рідні повітряні кишені Valkyrien Skies на сервері та їхні клієнтські
ефекти. Повністю замкнений відсік із суцільними стінами, дном і стелею
залишається сухим під водою; океан не повинен спричиняти плавання, течію
чи підводний туман усередині. Розбитий борт або відкритий прохід до зовнішнього
повітря порушує герметичність; ремонт її відновлює. Щоб трюм залишався сухим,
закривайте його проходи. Відкритий згори корпус або сходи до відкритої палуби
не є замкненим відсіком для цього механізму. Герметичність часткових блоків і дверей
визначається формами їхніх зіткнень; для надійного корпусу використовуйте
суцільні блоки. Автоматичний поділ кораблів залишається вимкненим.

Виправлено також застарілий стан пасажира після пробоїни: герметичність
перевіряється повторно кожні п'ять тактів, навіть якщо пасажир не рухається
відносно корпусу. Оскільки VS 2.4.11 може зберігати ознаку замкненості навіть
після відкриття борту, її запити для пасажирів, камери й водяних частинок
підтверджуються обходом повітряного відсіку за формами зіткнень блоків.
Результат спільний для пасажирів; редагування корпусу скидає кеш. Обхід не
завантажує чанки та перевіряє до 65536 клітинок. Для більшого відсіку або
недоступних чанків герметичність не вважається доведеною; великі трюми можна
розділити перегородками. Затоплення тут означає втрату захисту від зовнішньої води;
система не створює водяних блоків у кораблі й не осушує воду, вилиту гравцем.

## Налаштування

У `server/config/vs_sails/config.cfg`:

```ini
water-stability-strength = 8.0
wave-strength = 1.0
minimum-hull-immersion = 0.35
ship-sounds = true
```

`wave-strength`: 0..2, нуль вимикає хитавицю. `minimum-hull-immersion`:
0.03..0.8, мінімальна занурена частка для корпусів із буями.
`ship-sounds = false` вимикає фонові звуки; звичайні звуки пошкоджень
Ship Physics і далі залежать від фактичних зіткнень.

## Установлення

Готовий спільний пакет: `ship-physics/dist/Empirecraft-Ship-Safety-14.zip`.
Зупиніть клієнт і сервер перед заміною файлів.

1. Замініть попередні Sails і Ship Physics в обох папках модів на
   `vs_sails-1.20.1-0.3.2-empirecraft.14-forge.jar` та
   `empirecraft-ship-physics-1.2.2.jar`. Видаліть старі версії цих двох модів.
2. Перенесіть ADM ID-файл і налаштування Sails із пакета.
3. На кожному клієнті перенесіть
   `config/valkyrienskies/valkyrienskies-client.toml` (`Connectivity.enableClientConnectivity = true`).
4. Для вже наявного світу сервера змініть лише `enableConnectivity = true`
   у його `serverconfig/valkyrienskies/vs-core-server.toml`, у секції
   `"Connectivity Settings (Experimental)"`. Залиште `enableSplitting = false`
   та інші власні параметри. У репозиторії налаштовано світ `server/world`.
5. Файли `defaultconfigs/valkyrienskies/vs-core-server.toml` в обох частинах
   пакета застосують ті самі параметри до нових світів. Для наявного
   одиночного світу потрібна також зміна його `serverconfig`, як у пункті 4.

Після перезапуску перевірте замкнений нижній відсік, пробоїну й ремонт.
Незмінений VS JAR `valkyrienskies-120-2.4.11-empirecraft.1.jar` зберігається.

## Перевірки

```sh
python sails/build_offline.py
python ship-physics/build.py
python sails/test.py --prepare-sea-fixture
python ship-physics/test.py
python sails/sea_smoke.py
python ship-physics/smoke.py
python sails/test.py --prepare-safety-fixture
python sails/safety_smoke.py
python ship-physics/release.py --apply
python ship-physics/release.py --check
python sails/test_release_smooth.py
```

Компіляція використовує JDK 17, а Mohist/Towny запускається на Java 21.
Серверні перевірки створюють лише одноразові тестові світи. Візуальна
перевірка в графічному клієнті та прослуховування у грі потребують окремого
ігрового проходу. Фактичні результати записані у
`validation/ship-sea-motion-14.json`.
