# Empirecraft — виправлення запуску 1.0.1

Цей hotfix призначено для вже встановленої інтеграції Overgeared / Create / Epic Knights. Він замінює тільки чотири серверні KubeJS-скрипти.

1. Повністю зупиніть сервер.
2. Збережіть копії чотирьох власних файлів, якщо редагували їх вручну:
   - `kubejs/server_scripts/empirecraft_plate_compat.js`
   - `kubejs/startup_scripts/empirecraft_steel_trades.js`
   - `kubejs/server_scripts/zzzz_empirecraft_smithing.js`
   - `kubejs/server_scripts/4_tables.js`
3. Скопіюйте **вміст каталогу `server/`** з цього ZIP у корінь вашого сервера, погодившись на заміну цих чотирьох файлів. Для шляху з журналу це `D:\project\Empirecraft\server\`; результатом має бути `D:\project\Empirecraft\server\kubejs\...`, без зайвого вкладеного `server\server\`.
4. Запустіть сервер повністю. Одного `/reload` недостатньо, оскільки обробник торгівлі належить до startup scripts.

Виправлення:

- Усунено фатальне `String cannot be cast to Integer` у мапі професійних рівнів торгівлі. Сталь Overgeared прибирається з рівнів 1–5; інші фабрики пропозицій зберігаються.
- Усунено `redeclaration of var result` та `redeclaration of var type` у Rhino при перетворенні рецептів. Єдиною новою сталлю залишається Overgeared через його Alloy Furnace; ковадло й дозволені рецепти Create збережено.
- Відновлено заміну старих металів у всіх слотах інвентарю, навіть якщо перший слот порожній. Кількість і NBT зберігаються.
- Відсутні столи Valhelsia пропускаються до видалення/додавання рецептів, що прибирає дев'ять помилок порожнього результату.

Клієнт, JAR модів, список ADM, налаштування календаря/провізії, світ і бази даних оновлювати цим hotfix не потрібно.

Обидві початкові помилки відтворено на Rhino `2001.2.3-build.10` і Fastutil `8.5.12`. Виправлені скрипти перевіряються тим самим рушієм; усі кінцеві рецепти порівнюються з незалежною Node-моделлю. Звіт — `audit/compatibility.json`. Повний запуск світу Mohist тут не виконувався.

Після запуску перевірте відсутність зазначених помилок і повідомлення `Empirecraft smithing: … forging recipes; … alternate steel sources blocked`. В аудиторських fixtures отримано 704 перетворення й 22 заборони; число активних рецептів у світі може відрізнятися. Інші попередження з журналу цей hotfix не приховує.
