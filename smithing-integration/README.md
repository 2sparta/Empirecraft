# Empirecraft: Overgeared + Create + Epic Knights

Версія інтеграції: **1.0.0**. Основа: `main` після виправлення Create `6.0.8-medieval.2`.

У збірці залишається одна сталь: злиток, самородок, пластина та блок **Overgeared**. Металеві рецепти Epic Knights і встановлених адонів працюють через ковадло Overgeared, а дозволені механізми Create використовують спільні матеріали.

## Отримання сталі

Нову сталь можна отримати через рідний ланцюжок Overgeared:

1. Alloy Furnace або його Nether-варіант: залізо + вугілля → crude steel. Рідні пропорції рецепта збережено.
2. Нагрівання crude steel → кування → охолодження → сталевий злиток.

Обидва рецепти Epic Knights «залізний злиток → сталь у плавильній печі» видалено. Також заблоковано інші рецепти отримання сирої сталі, зокрема переплавлення спорядження в сталеві самородки, 14 рідних джерел сталевих злитків у здобичі Overgeared та його торгівлю сталлю. Старі збережені пропозиції продажу сталі очищаються перед відкриттям торгівлі.

Нагрівання **вже виготовленої** сталі, охолодження та перетворення злитків у блоки/самородки залишено: вони не створюють сталь із заліза. Старі запаси сталі зберігаються.

## Сумісність

| Мод у встановленому all-in-one JAR | Версія |
| --- | --- |
| Epic Knights (`magistuarmory`) | 10.10 |
| Epic Knights Addon (`magistuarmoryaddon`) | 2.6 |
| Antique Legacy | 1.13 |
| Dark Ages Armory | 1.1 |
| Slavic Armory | 2.1 |
| Japanese Armory | 1.6.2 |

- Металеві shaped-рецепти цих шести просторів імен переносяться на ковадло Overgeared зі збереженням малюнка, кількості матеріалів і результату. Для зброї, щитів та обладунків увімкнено рідну якість і мінігру; злитки заліза, міді та сталі потребують нагрівання. Загартування потрібне там, де рецепт використовує гарячий метал.
- Перероблення наявного спорядження в інший вигляд теж використовує ковадло та переносить NBT базового предмета. Воно не генерує нову якість повторно. Додано типи креслень `armor` та `shield` і їхні назви українською й англійською.
- Оброблення геральдики й неметалеві рецепти залишаються рідними. Характеристики зброї, анімації та бойові моди не змінюються.
- Дозволені металеві деталі Create можна кувати без якості спорядження. Попередні обмеження середньовічного Create збережено: скрипт інтеграції запускається після них і не повертає вимкнені рецепти.
- Прес Create: 1 сталевий злиток → 1 пластина; 1 сталевий самородок → 2 кільця Epic Knights. Пилка: 1 сталева пластина → 12 малих пластин Epic Knights. Витрати відповідають рідним пропорціям кілець і малих пластин.
- Залізні й мідні пластини об'єднано з листами Create. Бронза та латунь залишаються різними металами.
- Старі злитки, самородки й пластини Epic Knights та дублікати залізних/мідних пластин автоматично замінюються, коли потрапляють до інвентарю гравця. Кількість, слот і NBT зберігаються. Предмети в ще не відкритих сховищах не видаляються. Дублікати приховано в JEI; їхні реєстрові ID збережено для сумісності світів.

## Установлення

Зупиніть сервер і клієнт. Із готового ZIP:

1. Вміст `server/` скопіюйте в корінь сервера, погодившись на заміну `kubejs/server_scripts/1_steel.js` і `config/overgeared-common.toml`.
2. Вміст `client/` скопіюйте в корінь кожної клієнтської збірки.
3. Повністю перезапустіть сервер і клієнти. Одного `/reload` недостатньо: очищення фабрик торгівлі реєструється у startup-скрипті, а типи креслень читаються з common-конфігурації.

У репозиторії серверні файли лежать у `server/`, клієнтські — у кореневих `config/` і `kubejs/`. На сервері вже має бути чинний `zz_medieval_create.js`; ZIP містить тільки файли цієї зміни. Якщо Overgeared налаштовано вручну, перенесіть до власного common-конфіга додані значення `armor`, `shield` у `availableToolTypes`, зберігши інші свої параметри.

JAR-файли модів не змінюються. Хеші ADM оновлювати не потрібно.

## Перевірка

Потрібні Python 3.11+ та Node.js 18+. Із кореня репозиторію:

```sh
python3 smithing-integration/test.py
python3 smithing-integration/package.py
```

Тести читають JSON саме встановлених JAR Create, Overgeared, Epic Knights all-in-one і Locks. Вони виконують чинний скрипт обмежень Create та нові скрипти в моделі контрактів KubeJS/Forge. Перевіряються охоплення всіх адонів, схема кування, заборона альтернативної сталі, теги, NBT і слоти міграції, торгівля, конфіги та 14 loot modifiers. Останній результат і SHA-256 JAR містить `audit/compatibility.json`.

На цих даних перетворено **704 рецепти**, заблоковано **22 альтернативні рецепти сталі**. Це перевірка рецептів і контрактів подій; повний запуск Mohist та клієнта Minecraft у цій перевірці не виконувався. У встановлених JAR уже є два некоректні JSON (`sai_2.json` японського адона і `silver_ingot_from_cooling_3.json` Overgeared); вони записані в аудиті й не змінені цією інтеграцією.

Після встановлення перевірте у грі: відсутність залізо → сталь у JEI, повний ланцюжок Alloy Furnace → сталь, кування одного сталевого меча й обладунку, перенесення старого злитка зі скрині, прес/пилку Create та торгівлю старого коваля.
