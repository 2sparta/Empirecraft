# Титули Empirecraft — 1.0.0

39 косметичних титулів із наданого `Titles.rar`: 28 у магазині, 9 за здачу ресурсів, 2 сезонні. Меню та повідомлення українською. Оригінальні градієнти й усі 115 наявних PNG збережено. Політична команда `/title` із EmpirecraftFeudal працює окремо.

## Установлення

1. Зупиніть сервер і скопіюйте змінені файли з `server/`, зокрема `plugins/empirecraft-titles-1.0.0.jar`, чотири меню DeluxeMenus та ресурсний JAR у `server/mods/`.
2. Додайте `mods/empirecraft-titles-resources-1.0.0.jar` у `mods` **кожного клієнта** та перезапустіть клієнт. Ресурси входять у стандартний набір ресурсів модів Forge, окреме ввімкнення не потрібне. Сам сервер не може передати клієнтові мод.
3. Із кореня збірки виконайте `python titles/pin.py`, потім `python titles/pin.py --check`. Це локально додає лише новий мод у список ADM і перераховує його контрольну суму. Запис нового моду окремо наведено в `titles/adm-pin.json`; повний ADM-маніфест у цій зміні не публікується.
4. Запустіть сервер. Перевірте в логах `EmpirecraftTitles: Loaded 39 cosmetic titles`, відкрийте `/titles` звичайним гравцем.

Наявний `server/plugins/DeluxeMenus/config.yml` уже реєструє всі чотири меню. Наявний TAB читає суфікси LuckPerms через `%luckperms-suffix%`. ItemsAdder, CoinsEngine, Player expansion PlaceholderAPI та платні плагіни не потрібні. Приватний GitHub не використовується як URL ресурспаку.

Для клієнта без ресурсного JAR є рівнозначний ZIP `titles/dist/Empirecraft-Titles-1.0.0.zip`: його треба покласти у `resourcepacks` і ввімкнути вручну. **Оберіть один спосіб**. ZIP не внесено до ADM; на сервері з перевіркою точного списку модів використовуйте рекомендований JAR. Без клієнтських ресурсів замість іконок будуть відсутні символи.

## Команди й доступ

- `/titles` — основне меню; `/tituls_plat`, `/tituls_znamenat`, `/tituls_season` — категорії.
- `/etitle choose shop_1`, `/etitle choose achievement_1`, `/etitle choose season_1` — обрати вже отриманий титул. Повторно права перевіряє сервер.
- `/etitle unlock shop_1` або `/etitle unlock achievement_1` — отримати титул із перевіркою оплати. Команда доступна гравцеві без прав адміністратора.
- `/etitle clear` — зняти свій титул, зберігши права на нього.
- Видача сезонного титулу адміністратором: `lp user ІМ’Я permission set tituls.3_1 true` або `tituls.3_2 true`. Події й квести з архіву за травень 2025 року не встановлюються автоматично; сезонні титули залишаються нагородами адміністрації.

Збережено вузли доступу з архіву: `titul.1`…`titul.28`, `title.1`…`title.9`, `tituls.3_1`, `tituls.3_2`. Для нових гравців вони мають `default: false`; `empirecraft.titles.use` має `default: true`. OP не означає автоматичного володіння всіма титулами.

Магазин використовує **30 монет наявної економіки Vault / Essentials**, замість невстановленого CoinsEngine `stones`. Оплата й видача виконуються одним обробником на головному потоці: якщо `withdrawPlayer` повернув помилку, титул не видається. Уже отримані титули обираються без оплати навіть через старе меню або пряму команду. Ціна в `plugins/EmpirecraftTitles/config.yml`, ключ `shop-price`; при її зміні оновіть також підписи ціни в `tituls_plat.yml` та перезапустіть сервер. Нульова, від’ємна й нескінченна ціна блокують покупку.

Перевіряються інвентар і друга рука. Предмети з метаданими не приймаються, щоб не витрачати іменні речі або монети модів. При нестачі жоден стек не змінюється. Непотрібної команди `item take` більше немає.

Суфікси записуються через LuckPerms API із пріоритетом 100. Зміна або зняття прибирає лише відомі суфікси цього каталогу з цим пріоритетом. Префікси, групи, сторонні метадані та суфікси інших пріоритетів зберігаються. Якщо у гравця є сторонній суфікс із вищим пріоритетом, відображення визначає налаштування стеку LuckPerms. Старі суфікси пріоритету 1 з попередніх меню автоматично не видаляються.

## Джерела, відтворення й перевірка

`source.zip` містить незмінені вихідні YAML та PNG з наданого користувачем архіву. Ліцензію зображень не вигадано; поширення в інших збірках потребує прав на оригінал. В архіві немає PNG `tit39`, `tit91`, `tit117`; жоден із 39 активних титулів їх не використовує. `dune.png`, не описаний у вихідному YAML, також включено. Діапазон шрифту — U+E800…U+E874 і U+E880; `glyphs.json` фіксує відповідність. Звичайні шрифти Minecraft не замінюються: додаються лише bitmap-провайдери цих символів.

```sh
python -m pip install -r titles/requirements.txt
python titles/build.py
python titles/test.py --require-plugin
python titles/pin.py
python titles/pin.py --check
```

Потрібен JDK 17+. Єдина залежність для завантаження — Spigot API з фіксованим SHA-256 (той самий, що в `feudal/build.py`). LuckPerms і Vault беруться з уже встановлених серверних JAR; їхні класи не вбудовуються в результат. Готові ZIP/JAR відтворюються з фіксованими часовими мітками.

GitHub Actions з правами лише на читання збирає серверний плагін проти цих справжніх API, запускає тести, перевіряє піни ADM та видає готові файли як артефакт збірки. Локальні тести охоплюють успішну/невдалу оплату, повторні покупки, відсутність ресурсів, відкат при помилці видачі прав, сезонний доступ і відкликані права. Інтеграційні перевірки контролюють усі слоти, графіку, дозволи та відсутні залежності.

Живий Mohist-сервер і графічний клієнт у цьому середовищі не запускалися. Після встановлення потрібна ігрова перевірка звичайним гравцем: покупка за 30 монет, повторне безкоштовне обрання, здача розділених стеків, відмова при нестачі, зняття без втрати рангу й вигляд іконки в TAB. Стан офлайн-сховища LuckPerms визначається його власною системою збереження; помилки збереження журналюються сервером.
