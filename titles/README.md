# Титули Empirecraft — 1.1.0

**137 косметичних титулів**: 135 за прогрес у грі та 2 пам’ятні нагороди за серверні події. У меню доступні **всі 115 PNG** з наданого `Titles.rar`; додано 98 раніше недоступних графічних варіантів. Архів побайтово відповідає вже збереженому `source.zip`: інших файлів або прихованих меню в ньому немає. Вихідні YAML розглядаються як джерело оформлення, старі команди оплати та видачі не виконуються.

Повні умови кожного титулу: [CATALOGUE.uk.md](CATALOGUE.uk.md). Дані для редагування: `acquisition.json`; `catalog.json`, меню й довідник генеруються `build.py`.

## Отримання

- **Overgeared:** оббивання каменю, ливарна форма, ковальський молот і ковадло, креслення, сталева кірка та максимальний рівень креслення.
- **Farmer’s Delight:** насіння, рис, солома, грибна колонія, родючий ґрунт, багаття, казан, сковорода, поживна їжа, святковий стіл і досягнення кухаря.
- **Середньовічний Create:** тільки дозволені водяне колесо, вітряк, прес, жорна, пилка та андезитовий сплав. Вимкнених промислових механізмів серед умов немає.
- **Towny:** громадянство, місто у складі держави, посада мера; у складніших нагородах вони поєднані з часом гри. Це пам’ятні косметичні нагороди: отриманий титул залишається після зміни міста чи посади. Політичні `/title` і Feudal працюють окремо.
- **Ігрова статистика:** видобування руди, лісозаготівля, риболовля, човни, верхова їзда, подорожі, захист щитом, бої, тваринництво та ремесла. Враховується вся збережена історія гравця. Руди підсумовуються для звичайної та глибинної форми; колоди — для восьми порід Верхнього світу.

Початковий «Великий визволитель» тепер потребує досягнення «Герой села», «Мисливець на скелетів» — 100 убитих скелетів, а магнати — видобутої руди. Яйце дракона, черепи скелетів, Енд, Незер, зачарування, промислові машини та інші недоступні на сервері механіки не потрібні. Колишній магазин став розділом класичних титулів із досягненнями.

Звичайні човни враховуються через `BOAT_ONE_CM`: це **не** пробіг кораблів Sails. `FISH_CAUGHT` — ванільна статистика звичайної вудки; окремі турнірні улови Starcatcher не оголошуються зарахованими. Час гри включає простій онлайн. Подорожі рахуються за збереженою статистикою відповідного способу руху, а не за унікальними маршрутами. Ванільні статистики самі по собі не відрізняють поставлену гравцем руду чи повторне відкривання інтерфейсів. Каталог не видає за ці лічильники економічних нагород.

Титули надаються автоматично після входу, виконання досягнення й раз на 60 секунд; клік у меню також одразу перевіряє умови. **Автоматичне отримання не змінює обраний титул.** Усі умови одного титулу мають бути виконані разом. Прогрес, гроші й предмети не списуються. Якщо досягнення або Towny API недоступні, пов’язаний титул не видається; джерело один раз записується у журнал.

## Команди й сумісність

- `/titles` — розділи каталогу; `/tituls_znamenat` — перша з трьох сторінок нових нагород; `/tituls_plat` — класичні титули; `/tituls_season` — пам’ятні.
- `/etitle progress <ID>` — умови й відсоток виконання кожної; ID доступні через Tab.
- `/etitle unlock <ID>` — перевірити умови, отримати й обрати титул.
- `/etitle choose <ID>` — обрати вже отриманий титул.
- `/etitle clear` — зняти косметичний титул без втрати прав.

Збережені всі 39 старих ID, дозволів і суфіксів: `titul.1`…`titul.28`, `title.1`…`title.9`, `tituls.3_1`, `tituls.3_2`. Уже куплені й видані титули залишаються доступними без повторного проходження умов. Нові права — `empirecraft.titles.art.titN` і `empirecraft.titles.art.dune`. Для всіх титулів `default: false`; загальний доступ `empirecraft.titles.use` має `default: true`. OP сам по собі не є підтвердженням отримання.

Два пам’ятні титули з історичних подій травня 2025 року залишаються під контролем адміністрації: `lp user ІМ’Я permission set tituls.3_1 true` / `tituls.3_2 true`. За звичайну активність вони автоматично не видаються.

Суфікси LuckPerms мають пріоритет 100. Зняття або зміна прибирає лише відомі суфікси цього каталогу з цим пріоритетом; групи, префікси й сторонні суфікси зберігаються. Старі суфікси пріоритету 1 автоматично не видаляються. TAB читає наявний `%luckperms-suffix%`. Обов’язковий лише LuckPerms; Vault, CoinsEngine, ItemsAdder і платні плагіни для титулів не потрібні. Для графічного меню залишається встановлений DeluxeMenus.

## Установлення

1. Зупиніть сервер. Видаліть `plugins/empirecraft-titles-1.0.0.jar` і його `.sha256`, установіть `plugins/empirecraft-titles-1.1.0.jar` із `titles/dist/Empirecraft-Titles-1.1.0.zip`.
2. Скопіюйте шість меню з комплектного `server/plugins/DeluxeMenus/gui_menus/`. У `plugins/DeluxeMenus/config.yml` додайте реєстрації `tituls_znamenat_2` → `tituls_znamenat_2.yml`, `tituls_znamenat_3` → `tituls_znamenat_3.yml`; початкові чотири реєстрації збережіть. Комплектний конфіг підходить для незміненої збірки; на сервері з іншими меню додайте лише ці два записи.
3. Налаштування `plugins/EmpirecraftTitles/config.yml`: `check-interval-seconds: 60` (межі 10…3600 с). Старий `shop-price` більше не використовується; власний конфіг можна залишити — значення інтервалу за замовчуванням 60.
4. Перезапустіть сервер і перевірте `Loaded 137 cosmetic titles`, `/titles` та `/etitle progress achievement_3` звичайним гравцем.

**Клієнтський ресурсний мод 1.0.0 не змінився:** SHA-256 `01a95c3182872e92d89fb46f2f84253aad1991ea7fab4b9be89c6d65fa1ac904`. Він уже містив усі 115 зображень. Для чинної установки оновлення клієнтів та ADM не потрібне. Для першої установки додайте `mods/empirecraft-titles-resources-1.0.0.jar` на клієнти та сервер; виконайте `python titles/pin.py` і `python titles/pin.py --check`. Нові клієнти повинні мати цей ресурсний мод.

## Відтворення й перевірки

```sh
python -m pip install -r titles/requirements.txt
python titles/build.py
python titles/test.py --require-plugin
python titles/pin.py --check
```

Потрібен повний JDK 17+. Spigot API завантажується з фіксованим SHA-256; LuckPerms API береться зі встановленого серверного JAR. Часові мітки ZIP/JAR фіксовані. GitHub Actions перевіряє весь каталог, відповідність досягнень фактично встановленим модам, всі меню й переходи, збереження старих дозволів та суфіксів, незмінність PNG, пороги й поєднання умов, автоматичну видачу без зміни обраного титулу, повторні запити та відсутні джерела прогресу. Адаптер статистик перевіряється зі справжнім Bukkit API, включно з підсумовуванням руд і великими лічильниками.

Надані зображення та незмінені вихідні YAML зберігаються у `source.zip`; права на оригінальні зображення не змінюються. В архіві немає PNG `tit39`, `tit91`, `tit117`; відсутні зображення не підставляються замість існуючих. `dune.png` включено в каталог.

Живий Mohist і графічний клієнт для цієї зміни не запускалися. Після встановлення перевірте звичайним гравцем старий титул, усі три сторінки, одну нагороду Overgeared, одну Farmer’s Delight, водяне колесо Create, громадянство Towny, автоматичну видачу без зміни поточного титулу, зняття без втрати рангу та вигляд PNG у TAB. Видача через LuckPerms спочатку змінює його пам’ять, збереження виконується API асинхронно; помилки сховища журналюються.
