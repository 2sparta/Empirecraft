# Бойовий баланс і поява рекрутів

## Фламберг

Рвана рана Epic Knights (`magistuarmory:laceration`) більше не накладається
зброєю, командами чи іншими джерелами. Старий ефект та його залишковий
штраф до максимального здоров'я очищуються під час завантаження істоти.
ID ефекту збережено для читання наявних світів. Параметр `disableLaceration`
також увімкнено на сервері та клієнті, щоб підказки зброї відповідали правилам.
Інші ефекти та звичайна шкода фламберга збережені.

## Захист броні

Базовий захист визначається за нагрудником матеріалу, до якості кування.
Бонус додається **кожній частині** відповідного комплекту:

| Початковий захист нагрудника | Додаток до кожної частини |
| --- | ---: |
| 9 і вище | +4 |
| 8 | +2 |
| 7 | +1,5 |
| Інші обладунки | +1 |

Наприклад, максиміліанівський комплект: шолом 4 → 8, нагрудник 9 → 13,
поножі 6 → 10, чоботи 3 → 7. У XIV-столітнього комплекту нагрудник
7 → 8,5. Якість кування додає свою попередню поправку окремо.

Epic Knights реєструє частину шоломів як самостійні матеріали з нульовим
показником нагрудника. Максиміліанівські й турнірні шоломи віднесено до +9,
армети, салади та великі бацинети — до +8, інші бацинети — до +7.
Звичайні матеріали використовують власний нагрудник. Речі без початкового
захисту не перетворюються на обладунки. Поза належним слотом бонусу немає.

Бонус працює для наявного спорядження та рекрутів. Він не переписує NBT,
не додає зачарувань і не змінює початковий рівень складності кування.
Стандартна формула поглинання Minecraft та її межі залишаються чинними.

## PvP поза містами

У репозиторії Minecraft мав `pvp=true`, але Towny зберігав `pvp=false`
для `world` і `world_europe`. Towny блокує шкоду між гравцями в такому
світі незалежно від загального прапорця Minecraft. Відновлено дозволений
PvP у пустці; правила міст, ділянок та дружнього вогню збережені.

World Rules один раз виправляє прапорці наявних налаштованих світів через
API Towny. Позначка міграції зберігається у світовому SavedData.
Подальші явні зміни адміністратора не переписуються при наступному
перезапуску. Власні файли міст і жителів замінювати не потрібно.

## Яйця рекрутів

Оригінальний Recruits приймав **будь-який непорожній NBT** за збереженого
солдата. Для перейменованого яйця або стороннього тегу даних солдата немає,
тому оригінальний код додавав істоту в `0, 0, 0`. Це відтворено для всіх
семи видів яєць у повній серверній збірці.

Звичайні, перейменовані яйця, теги якості та стандартний `EntityTag` тепер
проходять штатну ініціалізацію Minecraft і створюють рекрута в місці
натискання. Повні яйця збереженого рекрута зберігають рідний шлях відновлення.
Ліміти найму та правила власності полків не змінюються.

## Встановлення

Зупиніть клієнт і сервер. Розпакуйте `dist/Empirecraft-Combat-Fixes-1.zip`:
`client/` — у клієнт, `server/` — у сервер, із заміною файлів.
World Rules потрібен тільки серверу; Forging і TownyRecruits повинні мати
однакові актуальні JAR на клієнті й сервері. Комплектний ADM установлюється
разом із цими файлами. Пакет включає поточний Locks і пакет перекладів,
щоб вони відповідали списку ADM після попередніх оновлень.

Якщо попереднє оновлення Locks ще не встановлене, видаліть старий
`Locks-SteelOnly-forge-1_20_1-1_2_4_nogen (1).jar` та його контрольну суму
з обох каталогів `mods/`, залишивши комплектний `locks-steel-only`.
Світ і жителів видаляти не потрібно. Це готовий пакет; на виробничий
сервер його автоматично не встановлювали.

## Перевірка

`native.py` використовує тимчасовий світ, повний набір серверних модів,
Towny, Feudal і Essentials. Перевіряються справжні `ServerPlayer`, шкода,
п'ять смертей/відроджень у кожному запуску, перезапуск світу, незалежність
прапорця міста, усі сім яєць зі стандартними й додатковими тегами, збережені
рекрути, `summon`, захист броні та очищення старої рани.
Графічний клієнт і виробничий світ не використовуються.

```sh
python3 forging-balance/build.py
python3 world-rules/build.py
python3 towny-recruits/build.py --classpath-dir server --classpath-dir /path/to/client-srg
python3 towny-recruits/release.py --install
python3 combat-fixes/native.py --java /path/to/java21
python3 trader-fix/native.py --java /path/to/java21
python3 combat-fixes/release.py --check
```

Компіляція потребує JDK 17 у `JAVA_HOME` і `PATH`, підготовленого SDK
`sails/build/` та справжніх клієнтських залежностей для TownyRecruits.
Точні результати й хеші містяться у `validation/combat-armor-recruits.json`.
