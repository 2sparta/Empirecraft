# Виправлення TFC: 3.2.30 проти 0.0NONE

Симптом: Forge відхиляє підключення через канал `tfc:network`, показуючи клієнту 3.2.30, а серверу 0.0NONE. Це службове значення версії файла; воно не має бути версією мережевого протоколу TFC.

Цей пакет зберігає поточний TFC 3.2.30 Empirecraft.2 і змінює лише два записи JAR: метадані `META-INF/mods.toml` явно вказують 3.2.30, а `PacketHandler` використовує явний протокол 3.2.30, який відповідає зафіксованому вихідному коду цієї версії TFC. Протокол більше не залежить від способу читання метаданих загрузчиком. Рівність мережевих версій на обох боках зберігається. Пакети, їхні ID й структура, рецепти та світові дані не змінені.

Зупини гру й сервер. Розпакуй інсталяційний ZIP та виконай:

```
python update_installation.py --server /шлях/до/сервера --client /шлях/до/клієнта
```

Можна вказати лише один бік. Інсталятор перевіряє контрольні суми до запису, прибирає попередній TFC із резервною копією та оновлює його єдиний запис у наявному серверному ADM. Решта модів, записів ADM, налаштувань, світів і гравців не змінюється. Готовий файл — `TerraFirmaCraft-Forge-1.20.1-3.2.30-empirecraft.3.jar`; не залишай поруч попередній TFC JAR.

На хостинг інсталятор можна завантажити разом з архівом і запустити в консолі, або встановити перевірені серверні файли вручну разом з оновленим ADM. Якщо клієнтом керує лаунчер, він має отримати відповідний підписаний канал після встановлення серверного виправлення.

Регресійний тест використовує справжній Forge/Mohist і тестовий загрузчик, у якому інформація про файл навмисно повертає 0.0NONE. Вихідний TFC відтворює невідповідність, виправлений повідомляє 3.2.30 та відхиляє інші версії. Тестовий загрузчик і аддон не входять до пакета. Виробничий світ тестами не відкривається.

Збірка: `python tfc-network-fix/build.py`; тест: `python tfc-network-fix/runtime_test.py`. Після повторного збирання старого кухонного пакета цей hotfix застосовують останнім; старі архіви є історичними.
