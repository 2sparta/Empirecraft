# Вилучення вмісту з Overgeared

Нативний патч для встановленого Forge 1.20.1 / Overgeared 1.6.36. Прибирає
реєстрацію восьми предметів (включно з двома BlockItem), двох блоків,
двох блокових сутностей і двох меню. Додатковий мод або приховування через
KubeJS не потрібні. Нагрітий нетеритовий сплав вилучено разом зі звичайним.

| Назва | ID |
|---|---|
| Незерська піч для сплавів | `overgeared:nether_alloy_furnace` |
| Шаблон «Алмазне оновлення» | `overgeared:diamond_upgrade_smithing_template` |
| Нетеритовий сплав | `overgeared:netherite_alloy` |
| Нагрітий нетеритовий сплав | `overgeared:heated_netherite_alloy` |
| Алмазна стріла | `overgeared:diamond_arrow` |
| Алмазний осколок | `overgeared:diamond_shard` |
| Незерська форма для інструмента | `overgeared:nether_tool_cast` |
| Ливарна піч | `overgeared:casting_furnace` |

Збережено звичайну піч для сплавів, глиняні форми, плавлення форм у звичайних
печах, сталеві матеріали та інструменти, залізні й сталеві стріли. Прибрано
залежні рецепти, отримання шаблона зі скринь, теги, моделі, текстури, вкладки
та записи JEI вилучених машин. Вбудований у цей самий JAR фільтр до
десеріалізації рецептів обробляє також посилання з інших модів і датапаків.

## Встановлення

1. Повністю закрити гру та сервер.
2. Видалити `overgeared-forge-1.20.1-1.6.36.jar` із `mods` обох сторін.
3. Скопіювати `client/` із пакета до клієнта, `server/` — у корінь сервера.
   Новий файл: `overgeared-forge-1.20.1-1.6.36-empirecraft.1.jar`.
4. Серверна частина містить відповідний ADM. Запустити гру й сервер.

У збережених світах вилучені предмети й обидві печі стають повітрям. Інші
збережені предмети та блоки залишаються. Ремапінг вбудовано в цей самий JAR.

Початкову внутрішню версію моду збережено для сумісності з уже встановленими
залежностями. Нова назва файла та контрольні суми відрізняють патч.

## Відтворення та перевірки

Початковий JAR і SHA-256 зафіксовано в `policy.json`; джерело — commit
`4d0c301fed5fa898eb12bf3c579a32b74f5d001f`. Команди повної збірки є у
`.github/workflows/overgeared-trim.yml`. ASM перевіряє стек змінених класів,
окремий аудит — відсутність звернень до вилучених реєстрацій. Python
перевіряє ресурси, контрольні суми та побайтове збереження інших файлів.
Java-тести перевіряють фільтр зовнішніх рецептів, вкладені посилання й
змішані альтернативи. Ізольовані запуски оригінального й зміненого моду на
справжньому Forge перевіряють реєстри, творчі вкладки, зовнішні рецепти та
збереження глиняних форм, а також перезапуск старого тестового світу з
вилученими предметами в скрині й установленими печами. Графічний клієнт і робочий Mohist-сервер окремо
не запускаються; їх не слід вважати перевіреними цим тестом.
