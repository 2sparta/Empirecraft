# Empirecraft Towny → JourneyMap

Попередня версія **1.10.0** для Feudal **1.18.0** додає читання оголошень і міських подій, оновлення таблиці рибальського турніру та перегортання списків. [Дошка, нагороди й вступні внески](../feudal/CIVIC-EVENTS.md). Однаковий Bridge 1.10.0 установлюється на клієнті та сервері.

Міст **1.9.0** для Feudal **1.14.0** додав [міський флот](../naval/README.md): вибір власника корабля, капітанів і команду, продаж та аукціони, мітки побачених союзних кораблів і кнопку «Подивитися». Збережено особисту історію територій, міські ринки, валютні форми та інтерактивні компоненти ChatPlus. Однаковий JAR потрібен на клієнті й сервері. [Встановлення та команди ринків](../feudal/CITY-MARKETS.md), [локалізація](../feudal/LOCALIZATION.md).

**Привати відкриваються лише у чанках, які гравець відвідав.** Зміни віддалених держав не оновлюють його мапу до повторного візиту. Пам’ять окрема для кожного UUID, зберігається у світі сервера та працює в усіх режимах. [Повні правила, збереження та перевірка](MAP-HISTORY.md).

Міст працює на Mohist 71a84ff7 / Forge 47.4.23 / Minecraft 1.20.1, Java 21, Towny 0.101.2.0 та JourneyMap 1.20.1-6.0.7. JourneyMap API не потрібно встановлювати окремо. JAR моста встановлюється в `mods`, а не `plugins`.

Контури об’єднують лише фактично відомі привати, зберігаючи отвори, анклави та острови. Виміри визначаються через реальні Bukkit-world → Mohist ServerLevel. Маркери й полігони обрізаються до відвіданих чанків перед відправленням. Shift-клік читає збережені відомості. Колір, назва та підказка зберігаються в тому вигляді, у якому гравець їх спостерігав.

## Налаштування

`config/empirecraft_townymap-common.toml`, після редагування перезапустіть сервер:

| Параметр | Типово | Призначення |
|---|---:|---|
| `updateIntervalSeconds` | `5` | Період перевірки поточного стану Towny, 1–300 секунд; спогади оновлюються лише на поточному чанку гравця |
| `showIndependentTowns` | `false` | Також відкривати відвідані незалежні міста |
| `fillOpacity` | `0.18` | Прозорість заливки, 0–1 |
| `borderWidth` | `2.0` | Товщина меж, 0–10 |

Міст сам очікує готовності Bukkit і Towny, перевіряючи запуск щосекунди. Під час недоступності Towny нові спостереження призупиняються, попередні спогади залишаються. Порядок завантаження вручну змінювати не потрібно. Помилки сумісності API виводяться в журнал.

## Збірка

На JDK 17: `bash gradlew test build --no-daemon` із цього каталогу. Результат: `build/libs/empirecraft-towny-journeymap-1.12.0.jar`, після `reobfJar`. Звичайний JAR з IDE не підходить для Forge runtime. [Збірка проти встановлених API та перевірка розбійників](BANDITS.md#збірка-й-перевірка).

Towny читається лише у серверному потоці. Індекс та геометрія будуються з незмінних знімків у робочому потоці. Окремий робочий потік записує особисту пам’ять. JourneyMap отримує різницю особистих полігонів з обмеженням пакетів за такт. Великі набори островів діляться на сторінки до 8192 вершин і 64 фігур.

Тести перевіряють геометрію, отвори, анклави, нестандартні розміри, 10 000 приватів, ліміт відправлень, повторну синхронізацію, життєвий цикл Towny, особисту історію та перезапуск. Тести життєвого циклу використовують наявні тестові Bukkit/Towny-класи; Minecraft і Forge під час збирання використовуються справжні. Результати релізу: [звіт](../validation/city-markets-1.13.1.md).

[Окрема тема JourneyMap](../journeymap-theme/README.md), [офіційний серверний API JourneyMap](https://github.com/TeamJM/journeymap-api/tree/1.20.1_2.0/common/src/main/java/journeymap/api/v2/server/overlay).
