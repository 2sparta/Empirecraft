# Towny → JourneyMap для EmpireCraft

Середньовічне оформлення: [«Імперський атлас»](../medieval-atlas/README.md) — пергаментні панелі, бронзовий компас, топографічна палітра та позначки замків і портів. Це окрема клієнтська тема; JAR моста та відбитки ADM не змінюються.

Оновлення: [торгівля, дипломатія, замовлення, династії та мапа](../feudal/REALMS-AND-TRADE.md). Це історичний опис політичних функцій; для актуального пакета використовуйте посібник City Markets вище.

Серверний Forge-мод показує території держав Towny у JourneyMap: кольорову прозору заливку, зовнішні кордони, назви та підказку з кількістю ділянок. Сусідні привати міст однієї держави об’єднуються без внутрішньої сітки. Анклави, окремі острови й незайняті ділянки всередині держав зберігаються.

## Встановлення

1. Зупини сервер.
2. Скопіюй `empirecraft-towny-journeymap-1.6.0.jar` із готового пакета в клієнтський і серверний `mods/`. Видали попередні JAR цього мода та їхні суми; залиш одну версію на кожній стороні. Онови клієнтський запис ADM разом із JAR.
3. Скопіюй `server/config/empirecraft_townymap-common.toml` у серверну папку `config/` або дозволь моду створити її при першому запуску.
4. Запусти сервер на наявному **Mohist 71a84ff7 / Forge 47.4.23 / Minecraft 1.20.1**, **Java 21**, із **Towny 0.101.2.0** та **JourneyMap 1.20.1-6.0.7**. У журналі має з’явитися `Towny JourneyMap server overlay bridge initialized`.
5. Увійди зі своєю звичайною збіркою та відкрий JourneyMap клавішею `J`. Після входу синхронізація починається приблизно через 5 секунд. Зміни приватів, складу держав, назв і кольорів підтягуються за наступний цикл перевірки.

**Мод потрібен обом сторонам** для нативних екранів. JourneyMap **6.0.7** лишається в клієнтській збірці; окремий API-JAR гравцям не потрібен. JourneyMap 5.10 не підтримує цей протокол. Серверний JAR розміщується в `mods/`, а не `plugins/`.

Міст використовує серверний API полігонів JourneyMap. Додатковий HTTP-сервер, порт, Dynmap або копіювання бази Towny не потрібні. Dynmap-Towny може продовжувати працювати незалежно.

## Запуск раніше за Towny

Це серверне виправлення: клієнтський міст 1.1.0 залишається сумісним, його та список ADM оновлювати не потрібно. Скрипт `bridge/update_adm.py` бере контрольну суму клієнтського JAR із кореневої `mods/`, а не із серверної `server/mods/`.

Починаючи з 1.1.1, міст очікує створення Bukkit, реєстрації та ввімкнення Towny й готовності його API. Перевірка повторюється кожні 20 серверних тактів (приблизно щосекунди), незалежно від `updateIntervalSeconds`. Порядок завантаження Forge-модів і Bukkit-плагінів вручну змінювати не потрібно.

Під час очікування журнал містить `Towny bridge waiting: ...` без стека помилки. Після готовності — `Towny is ready; JourneyMap bridge connected`. Якщо Towny залишається недоступним, раз на хвилину з'являється коротке попередження з причиною. Тоді перевір ранні повідомлення самого Towny в актуальному `logs/latest.log`: міст не може виправити помилку запуску або примусово ввімкнути вимкнений плагін. Помилки сумісності API й надалі виводяться зі стеком.

Після вимкнення Towny застарілі кордони прибираються; після ввімкнення міст підключається знову. При заміні екземпляра плагіна попередній API відкидається.

## Як визначається територія

- Територія держави — точне об’єднання **приватів усіх міст цієї держави**. Незайнята земля між містами не зафарбовується автоматично.
- Колір береться з `Nation.getMapColorHexCode()`; для держав без налаштованого кольору генерується стабільний колір за UUID.
- Кожен світ має окремі полігони. Вимір визначається через реальний Bukkit-world → Mohist `ServerLevel`, зокрема для Multiverse; назви світів не підставляються замість ID вимірів.
- Незалежні міста приховані. Їх можна додати параметром `showIndependentTowns = true`.
- Відображення доступне на повній карті й мінікарті. Сервер надсилає всім гравцям усі привати держав, включно з ще не дослідженими ними територіями.

## Налаштування

Файл: `config/empirecraft_townymap-common.toml`. Після редагування перезапусти сервер.

| Параметр | Початкове значення | Призначення |
|---|---:|---|
| `updateIntervalSeconds` | `5` | Період читання Towny, 1–300 секунд |
| `showIndependentTowns` | `false` | Також відображати міста поза державами |
| `fillOpacity` | `0.18` | Прозорість заливки: 0–1 |
| `borderWidth` | `2.0` | Товщина кордонів: 0–10 |

## Реалізація та збірка

Towny читається тільки в головному потоці сервера через його власний classloader. На геометричний робочий потік передається незмінний знімок координат; до Towny або Bukkit він не звертається. Контури будуються лише для змінених територій. JourneyMap отримує різницю, включно з видаленнями застарілих полігонів; великі набори островів передаються сторінками з обмеженням кількості відправлень за такт. Раз на хвилину дані повторно надсилаються для відновлення після затримки клієнтської ініціалізації.

Надзвичайно складні території (понад 512 отворів або 8192 вершини в одному полігоні) діляться на точні частини, щоб не перевищувати ліміти мережевого протоколу JourneyMap. У такому випадку можуть бути видимі лінії між частинами; площа приватів не змінюється.

Потрібен JDK 17. Із цієї папки:

```sh
./gradlew clean test build
```

Windows:

```bat
gradlew.bat clean test build
```

Результат: `build/libs/empirecraft-towny-journeymap-1.1.1.jar`. Завжди використовуй результат Gradle після `reobfJar`; звичайний JAR з IDE має неправильні назви методів Minecraft для Forge runtime. API JourneyMap є лише залежністю компіляції та не включається до JAR моста.

Тести життєвого циклу з тестовими Bukkit/Towny-класами перевіряють затриманий запуск, відсутній API, вимкнення, видалення та заміну екземпляра Towny. Вони не замінюють перевірку на живому Mohist-сервері.

Автоматичні тести перевіряють точність геометрії, отвори, анклави, від’ємні координати, нестандартний розмір ділянки, 10 000 приватів, зміну й видалення територій, ліміт відправлень і повторну синхронізацію. Результати перевірки конкретного JAR та межі перевірки записані в `validation/towny-journeymap-bridge.json` у корені репозиторію.

Офіційні API: [JourneyMap server overlays](https://github.com/TeamJM/journeymap-api/tree/1.20.1_2.0/common/src/main/java/journeymap/api/v2/server/overlay), [Towny 0.101.2.0](https://github.com/TownyAdvanced/Towny/tree/0.101.2.0).
