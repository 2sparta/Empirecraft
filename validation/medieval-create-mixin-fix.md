# Виправлення Create medieval.2 — 24.10.2026

Перевірена база: останній `main` Empirecraft `6a06f87ae95e7c03fb474c7c2c3519c8ba667b6c`, Minecraft 1.20.1, Mohist 71a84ff7 / Forge 47.4.23, Valkyrien Skies 2.4.11-empirecraft.1.

## Причина

У наданому серверному логу Create medieval.1 падає в `AllBlockEntityTypes` з `NoClassDefFoundError: NozzleBlockEntity`; клієнт показує `MixinTransformerError`. Клас існує в JAR. Справжня регресія відтворена офлайн: Mixin Valkyrien Skies `MixinNozzleBlockEntity#getCenterInWorld` не може виконати WrapOperation (0/1), бо середньовічний патч замінив tick/lazyTick порожніми й прибрав виклики VecHelper.getCenterOf.

## Зміна

Для 131 наявного методу заборонених машин додано захист із раннім поверненням. Початкові інструкції, точки ін'єкцій, локальні змінні й обробники винятків збережені. Джерела промислової енергії й обробка залишаються вимкненими; рецепти та список дозволених компонентів не розширені.

Готовий Create 6.0.8-medieval.2 однаковий у mods та server/mods; старі medieval.1 вилучені з обох. У клієнтській папці прибрано дубль vs_sails-1.20.1-0.3.2-forge.jar, збережено Empirecraft-варіант Sails. Оновлено запис Create у modpack-lock та чинному ADM ID-файлі без зміни сторонніх записів або ресурс-паків.

## Перевірки

- Початковий Create 6.0.8 перевірений за SHA-256; новий JAR детерміновано перебудований.
- ASM BasicVerifier перевіряє 144 змінених/доданих методи. Регресійний тест порівнює з upstream усі інструкції 131 захищеного методу та його обробники винятків.
- JVM з -Xverify:all виконує захист із реальною MedievalPolicy: побічна дія не виконується; повертаються false/0 або той самий предмет.
- Справжні MixinNozzleBlockEntity, MixinEncasedFanTileEntity та MixinSchematicannonBlockEntity з установленого VS успішно трансформують реальні класи нового Create в SERVER і CLIENT середовищах Mixin 0.8.5. Після трансформації класи записуються ASM і повторно перевіряються BasicVerifier. Для Minecraft-методів використано справжню refmap VS.
- Пройдено CRC, незмінність усіх вбудованих залежностей, обмеження рецептів, доступність компонентів воріт/креслень, KubeJS-скрипт у Node, формати й цілісність ADM; наявний список ADM успішно оновлений та перевірений штатним update_adm.py.

Повний запуск Mohist, графічного клієнта та ігрові випробування тут не виконані. Перевірки середовища CLIENT вище стосуються реальної Mixin-трансформації, а не запуску графічного клієнта.

JAR SHA-256: `c7c2f62a330a324368e8048113f447a2483a720489c928f7531ea6d8c5dbea03`.

Для встановлення зупинити гру/сервер, замінити Create medieval.1 на medieval.2 в обох папках mods, оновити ADM через medieval-create/update_adm.py і запустити заново. У кожній папці має бути лише одна версія Create та Sails.
