# Medieval Create 6.0.8 — перевірка 24.10.2026

Початковий JAR: Create Forge 1.20.1 6.0.8, SHA-256 `6fbb910c367dbce8e4fc7e5bf64b6edd4de980906ed00af8e47e4af843c0d9b0`.

Результат: `create-1.20.1-6.0.8-medieval.1.jar`, SHA-256 `4a79ba80088835f9d03f3669534900461189acb60dadc450027408788fcb2eea`.

- Збережено 1107 рецептів; прибрано 659; додано 12 ручних рецептів.
- Політика містить 532 дозволені ідентифікатори; 266 відомих ідентифікаторів вимкнено. Невідомий додатковий ідентифікатор простору `create` не дозволяється автоматично.
- Змінено/додано 144 методи. ASM BasicVerifier перевірив стекові операції кожного методу змінених класів.
- Java-код зібрано для Java 17. Дві збірки дали однаковий SHA-256.
- Перевірено CRC JAR; усі початкові класи та незмінені байти вбудованих Registrate, Flywheel, MixinExtras і Ponder збережено.
- У жодному збереженому рецепті немає забороненого прямого інгредієнта/результату або вимкненого виду обробки. Окремо враховано рядкові результати stonecutting і випадкові результати milling.
- Граф отримання ресурсів від ванільних матеріалів і видобутого цинку підтверджує доступність усіх основних деталей воріт, мостів та інструментів креслень. Ураховано, що прес/пилка/жорна мають бути створені перед відповідною обробкою.
- Згенерований KubeJS-скрипт завантажено Node; перевірено правила видалення рецептів, промивання, металів із жорен і збереження потрібних компонентів. Справжній рушій KubeJS не запускався.
- Скрипт ADM перевірено на JSON і текстовому форматах, порожніх/null-хешах, конфлікті integrity hash та збереженні сторонніх записів. На базовому текстовому списку збережено всі 113 записів; додатково перевірено поточний JSON після злиття Sails: усі 120 наявних записів модів і 4 ресурс-паки збережено. Тест виконувався на локальній копії; чинний файл репозиторію не змінено.

**Не виконано:** запуск Mohist/Forge, графічний клієнт, вхід гравця з ADM, ігрові випробування реального світу й сторонніх аддонів. Структурна перевірка байткоду не перевіряє доступність і поведінку всіх класів Forge під час гри.
