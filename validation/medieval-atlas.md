# Medieval JourneyMap appearance — 2026-10-23

Implemented as JourneyMap's native schema-2 theme, an optional waypoint icon resource pack and client settings installer. No Minecraft/JourneyMap/bridge JAR changes; no changes to the ADM mod composition or hashes.

## Validation

- Real JourneyMap Forge 1.20.1 / 6.0.7 `Theme` class deserializes the complete theme definition. Round-trip comparison, native color parsing and circular PNG masks: **688 assertions passed**.
- All toolbar icon filenames from the installed JourneyMap `flat/icon/` set are supplied. Buttons have on/off/hover/disabled artwork. Both circular and rectangular minimap frames are included. Circular mask sizes are 256 and 512; center is opaque, corners transparent, rim center transparent.
- **71 native theme PNGs**, **12 original 16×16 transparent waypoint icons**. Resource pack format 15; named icon-set support is present in the exact installed JAR.
- **6 installer integration tests passed** in PowerShell 7.6.8 on isolated client fixtures: fresh/repeated install, preservation of unrelated preferences and resource packs, per-world/verbose JSON fields, exact backup restoration, malformed-config rejection before mutations, server-folder rejection, and rollback after a filesystem write failure.
- Unicode/spaces in the client path, JourneyMap's `//` JSON headers and CRLF options files are covered. Existing mapped tile and waypoint binary files remain byte-for-byte unchanged.
- Built package is reproducible byte-for-byte with the same Inkscape/Python toolchain. Source artwork is original SVG generated by `medieval-atlas/build.py`; original JourneyMap textures are not redistributed.
- Preview rendered and visually inspected. It is explicitly labelled as an illustration using the shipped theme assets, with demonstration geography. It is not an in-game screenshot; Minecraft's font remains unchanged.

The Windows launcher uses PowerShell syntax compatible with Windows PowerShell 5.1; execution was tested in PowerShell 7 on Linux. A full Minecraft GUI render, resource reload and live-server login were not run here.

## Acceptance in Minecraft

1. Close Minecraft, extract the release ZIP and run `Install-Windows.cmd` against the actual client instance folder.
2. Launch the existing Forge 1.20.1 client with JourneyMap 6.0.7. Open J; confirm EmpireCraft Atlas, parchment buttons and bronze circular frame.
3. Confirm the topographic view uses the warm land and muted water palette; switch to the day map and back. Towny polygons, names and Shift-click ownership cards should remain available through the existing bridge.
4. Edit a waypoint, choose the Imperial Atlas tab and confirm the 12 icons; test at multiple Minecraft GUI scales and with both minimap presets.
5. Reopen the client to confirm theme/resource-pack selection persists. Restore the backup and verify the prior appearance returns.

Server overlay preset: only `fillOpacity` (0.18 → 0.12) and `borderWidth` (2.0 → 1.5) change in the existing bridge config. Restart the server to apply these two settings. Claim geometry, nation colors, update interval and gameplay permissions remain unchanged.
