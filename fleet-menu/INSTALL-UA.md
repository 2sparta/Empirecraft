# Нове меню міського флоту

Bridge **1.11.2** замінює повноекранне коричневе меню центрованим морським вікном: темна навігація, світлі картки, латунні акценти, піктограми, підсвічування активного розділу та чіткі основні кнопки.

- Реєстрація корабля доступна з окремої кнопки «Новий корабель» і картки у флоті. Як і раніше, перед заявкою треба навестися на блок майбутнього корабля.
- Форми мають окремі поля й адаптивні кнопки вибору корабля/гравця. Значення зберігаються під час зміни розміру вікна та переходу між сторінками полів.
- Довгі назви кнопок скорочуються з підказкою при наведенні; повна назва міста також доступна при наведенні, якщо не вмістилась.
- Прокрутка списків і подробиць обмежена робочою областю. Порожні стрілки сторінок для «1 / 1» прибрані. Під час очікування відповіді сервера повторні запити блокуються.
- Підтримано окрему мову меню: українську, англійську та російську. Назви кораблів і гравців залишаються оригінальними.

## Встановлення

Зупини клієнт і сервер, розпакуй `dist/Empirecraft-Fleet-Menu-1-install.zip` в окрему папку. Запусти Python 3.11+:

```text
python update_installation.py --client "/шлях/до/клієнта" --server "/шлях/до/сервера"
```

Можна передати тільки `--client` або `--server`. Однаковий `empirecraft-towny-journeymap-1.11.2.jar` встановлюється на обох боках. Попередній Bridge з тим самим mod ID переноситься в `.empirecraft-backups/fleet-menu-1`; два активні Bridge одночасно залишати не можна. Наявний серверний ADM оновлюється тільки для Bridge з перерахунком integrityHash; підтримано JSON і текстовий формат із хостингу. Інші записи, resource packs і файли гравців зберігаються. Після встановлення перезапусти обидва боки.

Серверні правила, дозволи, ціни, торги й підтвердження залишаються попередніми: серверні класи Bridge збережено байт у байт, плагін Feudal не замінюється.

## Перевірки та перегляд

`verification.json` містить результати перевірок форм, пошуку, мов, ремапінгу справжніх клієнтських API та геометрії на 72 розмірах вікна, від 320 × 240 логічних пікселів. Графічний клієнт і світ хостингу не запускалися.

У `preview/` — ілюстративні макети з Java-геометрії та ванільних bitmap-гліфів Minecraft. Це не скриншоти запущеної гри; назви кораблів у прикладі демонстраційні. Мод сам малює всі елементи через Minecraft GUI, окремий ресурс-пак не потрібний.

Збірка з підготовленим SDK:

```text
python fleet-menu/build.py --reference-repo /шлях/до/повного/checkout --sdk /шлях/до/toolchain --jdk /шлях/до/jdk17
```

Потрібні поточний Bridge 1.11.1 з SHA, зафіксованим у build.py, встановлені libraries/journeyMap та попередньо підготовлені named/srg mappings Minecraft 1.20.1. Жодні Minecraft/Bukkit класи або тестові замінники API до JAR не додаються.
