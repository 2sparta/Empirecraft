# Дебагінг клієнта Empirecraft

Необов’язковий клієнтський мод для Minecraft 1.20.1 і Forge 47.4.23+. Поклади `empirecraft-client-debug-1.0.0.jar` у `mods` свого клієнта. На сервер встановлювати не потрібно.

У грі відкрий **Налаштування → Дебагінг**, або **Моди → Empirecraft Client Diagnostics → Config**, і постав галочку **Дебагінг**. Повернись у гру, відтвори проблему, потім зніми галочку. Запис також завершується через 5 хвилин або під час штатного закриття гри. Після нового запуску запис вимкнений.

Кожен запуск створює окрему папку в `debug/empirecraft-client/`:

- `metrics.csv` — FPS за інтервал, середній час кадрів, рендера й клієнтських тіків, p50/p95/p99, максимуми та кількість стрибків. Також містить CPU процесу й системи, Java heap, GC, кількість завантажених клієнтських чанків та істот, контекст і фокус вікна.
- `summary.txt` — найчастіші Java-методи у вибірках CPU для потоку гри, локального сервера одиночної гри й решти потоків.
- `profile.jfr` — стеки CPU, вибірки виділення пам’яті, GC, очікування на блокування, повільні файлові операції й позначки кадрів або тіків від 50 мс. Його можна відкрити в JDK Mission Control. Якщо Java не підтримує JFR, числові метрики зберігаються окремо.

Час між кадрами враховує обмеження FPS та очікування. Час проходу рендера вимірюється на CPU через Forge і не є часом GPU. Дані залишаються локально. Профіль містить назви методів, потоків і може містити шляхи з повільних файлових операцій.

Збірка з JDK 17: у цій папці виконай `bash ../potato-client/gradlew build --no-daemon`. JAR буде в `build/libs`. Такий самий JAR зберігає GitHub Actions у артефакті `empirecraft-client-debug`.
