# Видалення Chipped Extras і виправлення календаря

Chipped Extras прибрано на сервері та клієнті. Chipped і Copycats+ збережені. Для нових сходів, плит і стін використовуйте відповідні форми Copycats+ з матеріалом Chipped. Міграція світу не виконується за підтвердженням власника, що ці блоки ще не використовувалися.

Причина надісланого крашу — CalendarMod.started у календарі 1.2.3: він кидав IllegalStateException при неправильних параметрах Serene Seasons. У 1.2.4 замість падіння встановлюються day_duration=57600 та sub_season_duration=30 ще до запуску календаря. Інші налаштування погоди та вимірів зберігаються. Перед виправленням існуючого файла мод створює seasons.toml.before-empirecraft-1.2.4. Якщо конфіг неможливо записати, значення залишаються виправленими в пам'яті, а в лог потрапляє повідомлення.

Для негайного запуску старого календаря можна зупинити сервер і виправити у config/sereneseasons/seasons.toml розділ [time_settings]:

```
day_duration = 57600
sub_season_duration = 30
```

Для повного оновлення зупиніть сервер і гру, розпакуйте архів та виконайте Python 3.11+:

```
python update_installation.py --server /шлях/до/сервера
python update_installation.py --client /шлях/до/клієнта
```

Пакет містить календар 1.2.4, конфіги Serene Seasons та очищені теги. Календар потрібно оновити на обох сторонах. Інсталятор резервує попередні файли в .empirecraft-backups/copycats-calendar-1, прибирає Chipped Extras і зберігає сторонні записи існуючого ADM. Якщо ADM відсутній, встановлюється підготовлений список для актуального клієнтського комплекту: надісланий лог прямо вказує, що файл був відсутній. Усталені локальні параметри сезону не скидаються; виправляються лише два параметри часу.

Файли світу та дані гравців не змінюються. На хостинг нічого автоматично не завантажувалося. Після оновлення клієнтського каналу лаунчера натисніть «Перевірити збірку» із закритою грою.

## Клієнтський краш води / мешів

ConcurrentModificationException виникав у LSO TemperatureUtilInternal.getWorldTemperature при виклику з Agriculture.PackClimate на потоках побудови чанків Embeddium. Інтеграція TFC 1.0.4 зберігає LSO на сервері й головному клієнтському потоці, але використовує біомний клімат для фонових потоків фарбування. Температура гравця та серверне землеробство LSO збережені. Пакет містить JAR інтеграції 1.0.4 на обидві сторони; інші її класи й ресурси збережені з попереднього встановленого JAR.
