# EmpireCraft — оновлення модів

Робоча гілка: перевірка сумісності ще триває. Не переносити на робочий сервер до завершення перевірки.

- `mods/` — клієнтська збірка з усіма спільними модами.
- `server/mods/` — серверні та спільні моди.
- Перелік версій та контрольних сум: `modpack-lock.json`.
- Великі файли автоматично відновлює GitHub Actions з перевіркою SHA-512.
- Початковий серверний набір успішно запущений на Mohist 71a84ff7 / Forge 47.4.23.
- Hybrid Aquatic 1.5.4 спричиняє збій завантаження Player; перевіряється сумісна версія.
