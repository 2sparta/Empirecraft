# Empirecraft Content Trim 1.0.1

Після встановлення [оновлення без Енду](../end-removal/README.md) поточний Chipped — `empirecraft.3`: цей наступний шар додатково вилучає End-родини, зберігаючи всі наведені нижче Nether-обмеження. Для відтворення поточної збірки використовуйте `end-removal/`; архіви Content Trim 1.0.1 залишаються знімком попереднього оновлення. Чинний CI перевіряє збереження попереднього маніфесту вилучення, а тест тимчасового світу End Removal перевіряє обидва шари реєстрів.

Minecraft 1.20.1, Forge 47.4.23 / поточний Mohist. Окремі клієнтський і серверний ZIP містять готові модифіковані JAR. Нативні моди потрібно оновити **на обох сторонах**.

## Вилучення безпосередньо з модів

- Epic Knights: усі 9 форм щитів у двох матеріалах — алмазному й незеритовому, разом **18 предметів**. Патч у рідному `ModItemsProvider` повертає штатний результат вимкненого щита до реєстрації предмета й додавання до списків. Рецепти й моделі предметів вилучено з JAR. Інші щити, броня й попередні правила збірки збережені.
- Chipped: **1147 блоків** (1144 предмети й 3 настінні смолоскипи) з 36 родин та 26 окремих незерських варіантів у змішаних палітрах. Нативні ініціалізатори замінено порожніми контейнерами реєстрації: предмети та блоки більше не реєструються. Поля залишені для сумісності внутрішніх споживачів модифікації.
- Chipped Extras: відповідні похідні плити, сходи й стіни вилучено з `assets/chippedexttras/generated/registry.json`, який безпосередньо визначає реєстрацію. Рецепти, loot tables, blockstates та моделі предметів вилучено; посилання з тегів і рецептів робочих столів очищено.

Родини: ancient debris, netherite, lodestone, blackstone, gilded blackstone, звичайний basalt, red nether bricks, crimson/warped деревина, двері, люки, гриби й коріння, nether sprouts, nether/warped wart blocks, shroomlight, три froglight. Додатково вилучено незерак, незерську цеглу, кварц, магму, пісок душ, ліхтарі душ, плакучий обсидіан та незерський декор у змішаних палітрах: ящики, смолоскипи, гарбузи, ліани тощо. Точні ID: `audit/removed.json`.

**Збережено всі 20 варіантів світлокамню**, включно з `nether_engraved_glowstone`, та ванільний світлокамінь. Звичайний обсидіан належить до матеріалів звичайного світу й також збережений. Незерські матеріали вилучаються незалежно від їхньої доступності через торгівлю або зруйновані портали. End-родини не входять до цього Nether-вилучення.

Вихідні версії у `mods.toml` навмисно збережено: чинний Content Policy 1.0.0 має точні залежності від цих версій. Chipped і Chipped Extras позначені `empirecraft.2`, Epic Knights — `empirecraft.1` у назві й `META-INF/empirecraft-trim.json` усередині. Контрольні суми клієнта й сервера однакові. Усі шість модів об'єднаного Knights JAR отримують нову фізичну SHA-256 в ADM; інші записи та ресурс-паки не змінюються.

## Моби й слиз

Серверний `empirecraft-content-trim-1.0.1.jar` забороняє приєднання до світу для creeper, spider/cave spider, zombie/zombie villager/husk/drowned, skeleton/stray/wither skeleton, witch, slime/magma cube, phantom і pillager. Це охоплює природний спавн, спавнери, яйця, команди й завантаження збережених істот; без дропу. Інші істоти залишаються дозволеними. Клієнтам цей серверний JAR не потрібен.

Рецепт дає **1 згусток слизу** у верстаку:

| | | |
|---|---|---|
| Кісткове борошно | — | — |
| Ламінарія **або** зелений барвник **або** блок моху | Колба води | Нитка |
| — | — | — |

Використовується `forge:partial_nbt` із `Potion: minecraft:water`. Порожня колба, інше зілля, вибухова й осідаюча пляшки не підходять. Це звичайний shaped-рецепт із нативним дзеркальним розташуванням; усі чотири інгредієнти витрачаються, включно з колбою. Інші рецепти слизу зберігаються.

## Установлення

1. Зупиніть сервер і клієнти; збережіть резервну копію перед зміною реєстрів.
2. На **обох** сторонах видаліть попередні версії файлів, перелічені в `REMOVE-OLD-JARS.txt`. Скопіюйте `mods/` із відповідного ZIP у корінь збірки. Одночасно старі й нові версії залишати не можна.
3. На сервері встановіть також новий серверний Content Trim JAR. Збережіть чинні World Rules, Calendar, Content Policy, Seasonal Leaves та решту модів.
4. Для чинного ADM перенесіть змінені SHA-256 з `reference-configs/admanticheat_id_list.json` або застосуйте `update_metadata.py` до репозиторію. Довідковий файл містить поточний список збірки; якщо у вас він відрізняється, не замінюйте власні інші записи.
5. Повністю перезапустіть сервер і кожен клієнт. `/reload` не замінює нативну реєстрацію блоків/предметів.

Серверний MissingMappings-перенос (оновлено для всіх додатково вилучених ID) спрямовує старі щити на сталеву форму, вилучені блоки/предмети декору — на камінь. Колір, форма й спеціальні властивості вилученого декору не зберігаються. Без встановленого серверного JAR старі ID залишаться відсутніми; не відкривайте старий світ одиночної гри лише з клієнтським пакетом. Серверний пакет не містить світу, БД або сторонніх налаштувань сервера.

## Відтворення та перевірки

Оригінали трьох вхідних JAR беруться з коміту `84f368498fd2c181aafa1a720bd239f61ec9ad6b`, шляхи — `server/mods/`. `policy.py` перевіряє їхні SHA-256. Декомпілятор і сторонні залежності для ASM-патчера не потрібні: використовується ASM із JDK 17.

```sh
python content-trim/build.py --upstream upstream --classpath-dir server/libraries
python content-trim/update_metadata.py --check
python content-trim/test.py
python content-trim/smoke.py --upstream upstream --runtime forge-runtime --toolchain seasonal-leaves/build/toolchain
python content-trim/package.py
```

`smoke.py` використовує тимчасовий світ та офлайн-порт лише на 127.0.0.1. Повна актуальна збірка Mohist із усіма плагінами та графічний клієнт цим тестом не запускаються.
