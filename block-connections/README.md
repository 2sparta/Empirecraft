# З’єднання огорож і стін

Виправлення для Minecraft 1.20.1 / Forge 47.4.23 / Mohist 71a84ff7.

Згенеровані NoEnd-теги перевизначали `minecraft:fences` і `minecraft:walls`
та містили обов’язкові посилання на вилучені або незареєстровані модові блоки.
Одна така відсутня реєстрація змушує Minecraft відхилити всю групу.
Стінки й огорожі тоді не розпізнають одна одну, навіть якщо самі блоки існують.

У серверних тегах залишалися `dawnoftimebuilder:warped_wall`,
`dawnoftimebuilder:crimson_wall` і `supplementaries:blackstone_tile_wall`.
У клієнтському профілі не було актуального KubeJS-перевизначення, тому діяли
вбудовані старі списки NoEnd з обов’язковими посиланнями на вилучені Macaw’s.

Посилання на модові блоки й теги тепер необов’язкові (`required: false`).
Ванільні записи збережено, актуальні серверні теги також додано до клієнтського
профілю для одиночної гри. Генератор End removal використовує те саме правило.
Правка не змінює модові JAR або ADM і не додає назад заборонені блоки End.

## Установлення

1. З пакета `dist/Empirecraft-Fence-Wall-Fix-1.0.0.zip` перенесіть вміст `server/`
   до кореня сервера зі збереженням шляхів. Замініть чотири файли в
   `kubejs/data/minecraft/tags/blocks/`.
2. Для одиночної гри перенесіть вміст `client/` до кореня клієнтської збірки.
   У мережевій грі сервер синхронізує теги з клієнтами.
3. Повністю перезапустіть сервер або виконайте `/reload` після копіювання всіх
   файлів; для одиночної гри перезайдіть у світ.
4. Старі блоки можуть зберігати попередні властивості з’єднання. Оновіть сусідній
   блок або переставте одну огорожу/стінку, щоб Minecraft перерахував форму.

Робочі світи та інвентарі пакет не містить і вручну не переписує.

## Перевірки

```sh
python3 block-connections/test.py
# JDK 17, для підготовки реальних named/SRG API:
python3 seasonal-leaves/build.py
# Java 21 для встановленого Mohist; javac з JDK 17 або 21:
python3 block-connections/smoke.py --java /path/to/java21/bin/java --javac /path/to/javac
python3 block-connections/package.py
```

Тест використовує тимчасові світи та точні встановлені моди, перевіряє
серверний і клієнтський KubeJS-профілі на логічному сервері. Перевіряються
реальний TagLoader, усі доступні огорожі/стіни в тегах, розміщення та
оновлення сусідів, різні породи дерева, хвіртки, збереження ванільних правил
матеріалів і відновлення старих станів після сусіднього оновлення.

WorldEdit, Bukkit-плагіни, графічний клієнт і робочі світи у цьому тесті не
запускаються. Свідомо вилучені NoEnd-блоки виключено з вимог з’єднання.
