# ChatPlus — канали й особисті налаштування Empirecraft

Клієнт `chatplus-forge-2.8.1-empirecraft.3.jar` додає два перемикачі у **Моди → ChatPlus → Налаштувати**. Налаштування застосовуються після натискання «Зберегти» без перезапуску гри та зберігаються між запусками.

- **Увімкнути ChatPlus**: вимкнення повертає звичайний чат Minecraft. Гарячі клавіші ChatPlus та перегляд чату під час прокручування перестають втручатися у керування. Повторно ввімкнути мод можна через його кнопку налаштувань у списку модів навіть у вимкненому стані.
- **Об’єднати глобальний чат і системні повідомлення**: замість двох вкладок з’являється одна **«Глобальне»**. Вона показує обидва потоки; набраний у ній текст надсилається в глобальний канал. Локальний, міський і королівський канали зберігають окремі вкладки.

Меню також відкривається через `/cp` і штатну гарячу клавішу налаштувань, коли ChatPlus увімкнено. За замовчуванням мод увімкнений і залишаються п’ять окремих вкладок: глобальний, локальний, системні повідомлення, місто та королівство. Окрема системна вкладка доступна лише для читання. Команди `/...` працюють з усіх вкладок.

Перемикання об’єднує й знову розділяє поточну історію за каналами та часом надходження. Одна вкладка зберігає до 5000 повідомлень за сеанс; після об’єднання цей ліміт спільний. Повторювані повідомлення з однаковим текстом зберігаються. При розділенні історії повідомлення, вже видалені через ліміт, не відновлюються. Перезапуск гри очищає історію, як у штатному ChatPlus. Геометрія вікон, переміщення, зміна розміру, пошук і копіювання залишаються штатними.

Стан увімкнення зберігає сам ChatPlus у `config/chatplus/chatplus-v2.7.0.json` (`enabled`). Додаткова опція — у `config/chatplus/empirecraft-channels.json` (`mergeGlobalAndSystem`). Видаляти наявну конфігурацію для оновлення не потрібно. Назви вкладок і меню вбудовані в JAR українською, російською та англійською; окремий ресурс-пак не потрібний. Ширина вкладок і ділянки натискання повторно вимірюються штатним кодом після зміни мови або шрифту.

## Канали та приватність

Серверний плагін залишається `empirecraft-chat-1.1.0.jar`. Сервер перевіряє членство Towny під час кожної доставки: міський чат доступний жителям того самого міста, королівський — громадянам тієї самої держави Towny. Васальні зв’язки й союзи між окремими державами не розширюють доступ. Локальний канал має сферичний радіус 50 блоків включно в одному світі. Адміністратори не отримують прихованого доступу до приватних каналів. Службові повідомлення використовують особистий вибір `/language en|uk|ru`.

Формат повідомлень: `[місто|королівство] нік політичний_титул косметичне_зображення: повідомлення`. Політичний титул визначає Feudal; косметика береться з вибраного титулу EmpirecraftTitles. Усі 39 косметичних варіантів мають вбудовані bitmap-гліфи. Немарковані серверні, службові й приватні повідомлення інших плагінів надходять у системний потік.

Без ChatPlus доступні `/ecchat global|local|town|kingdom повідомлення`. Команда без тексту встановлює канал звичайного чату до виходу з сервера. Вибрані вкладки увімкненого ChatPlus передають канал для кожного повідомлення. Приватність, скасування повідомлень іншими Bukkit-плагінами та перевірки членства не залежать від особистих налаштувань клієнта.

## Встановлення

Дистрибутив: `dist/Empirecraft-ChatPlus-1.2.0.zip`. Закрийте клієнт, приберіть попередній `chatplus-forge-*.jar` із `mods` і встановіть новий з папки `client/`. На сервері застосуйте відповідний список ADM із `server/`, зупинивши його перед заміною. Пакет також містить парний мод Empirecraft Pack Fixes і теги інструментів, потрібні актуальному списку ADM; інструкція — `PACK-FIXES-UA.md` у пакеті. Серверні плагіни цього оновлення не змінюються.

## Відтворення й перевірки

Потрібні JDK 17, Python 3, Pillow і PyYAML та встановлені бібліотеки збірки. Підготуйте закріплений Minecraft/Forge SDK командою `python3 sails/build.py --sails-only` (вона також перебудовує Sails; для окремої перевірки чату збережіть і відновіть встановлений Sails). Потім виконайте:

```sh
python3 chat-channels/build.py --client-only
python3 chat-channels/test.py
python3 bridge/test_interactive_mixin.py
python3 chat-channels/update_metadata.py --check
python3 chat-channels/package.py
```

Для випуску зміненого JAR спочатку оновіть метадані командою `python3 chat-channels/update_metadata.py` і перевірте загальний інвентар через `validation/reconcile_modpack.py`. Серверний плагін при `--client-only` не перебудовується. SDK використовується лише під час компіляції: класи Minecraft/Forge не додаються до ChatPlus.

Тести перевіряють маршрутизацію та приватність, реальний шлях Bungee JSON → Minecraft Component, об’єднання й розділення історії, ліміти, атомарний запис і повторне завантаження налаштувань, доступність меню після вимкнення та штатні вимірювання вкладок. Патч змінює рівно дев’ять перевірених upstream-класів. ASM і JVM `-Xverify:all` перевіряють байткод; окремий тест застосовує реальний Sponge Mixin мосту Towny/JourneyMap. Усі upstream Mixin-конфігурації та refmap збережені. Повний графічний клієнт і живий світ Mohist у цих перевірках не запускаються.

`ChatPlus-2.8.1-upstream-source.zip` містить upstream-код `ebicep/ChatPlus` на коміті `a8279ba480bb89fb3136da6a59db0585cd21af70`, гілка Minecraft 1.20.1. Оригінальний JAR у `upstream/` — закріплений вхід збірки, він не встановлюється. Власні зміни, тести й скрипти включено до `dist/Empirecraft-ChatPlus-1.2.0-sources.zip`; ліцензія GPL-3.0 — `LICENSE-ChatPlus.txt`. Джерела шрифту DejaVu та його ліцензія — `font/`. `frozen-assets/` містить перевірені растрові зображення для відтворюваної збірки.
