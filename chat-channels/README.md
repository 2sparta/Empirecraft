# ChatPlus — канали Empirecraft

Клієнт: `chatplus-forge-2.8.1-empirecraft.1.jar` замінює `chatplus-forge-2.8.1 (5).jar`.
Сервер Mohist: новий `empirecraft-chat-1.0.0.jar` і оновлений `empirecraft-feudal-1.4.1.jar` замість `empirecraft-feudal-1.4.0.jar`.

П’ять вкладок: глобальний, локальний, системні повідомлення, місто, королівство. Вибрана вкладка визначає канал звичайного тексту. Команди `/...` працюють з усіх вкладок; системна вкладка доступна тільки для читання. Немарковані серверні, службові й приватні повідомлення інших плагінів надходять у системну вкладку.

Сервер перевіряє UUID членства Towny під час кожної доставки. У міському каналі отримувачі — лише жителі того самого міста. У королівському — лише громадяни тієї самої держави Towny, включно з її містами. Васальні зв’язки між окремими державами та союзи не розширюють доступ до королівського чату. Локальний канал має сферичний радіус 50 блоків включно, у тому самому світі. Адміністратори не отримують прихованого доступу до приватних каналів.

Формат: `[місто|королівство] нік політичний_титул косметичне_зображення: повідомлення`. За відсутності міста/держави показується `—`; відсутні титули пропускаються. Політичний титул визначається поточними посадами та наданими дворянськими титулами Feudal. Береться найвищий чинний титул, з урахуванням політичного ладу, а не довільний префікс LuckPerms. Косметика береться з уже вибраного титулу EmpirecraftTitles (відомі суфікси LuckPerms з пріоритетом 100). Усі 39 варіантів мають bitmap-гліф: наявні ілюстрації збережено, кольорові текстові варіанти відтворено зображеннями. Видача, придбання й вибір титулів працюють через наявну систему.

Загальне меню конфігурації ChatPlus вимкнене: кнопка в списку модів не реєструється, `/cp`, гаряча клавіша та прямий виклик загального екрана його не відкривають. Керування чатом через `T`, переміщення, розмір, форма, скролінг, пошук, копіювання та прямі редактори вікна залишаються upstream. Налаштування геометрії продовжують зберігатися у штатному файлі ChatPlus; цей файл потрібен для збереження форми вікна.

Кожна вкладка має окрему штатну історію до 5000 повідомлень протягом ігрового сеансу, навіть коли активна інша вкладка. Нові повідомлення у неактивних вкладках збільшують штатну позначку з лічильником; відкриття вкладки скидає її. Перезапуск гри очищає історію повідомлень, як у штатному ChatPlus. Вкладки видно й із закритим чатом. У вузькому вікні працює штатна прокрутка панелі вкладок.

Команди без модифікованого клієнта: `/ecchat global|local|town|kingdom повідомлення`. Без тексту команда встановлює канал звичайного чату до виходу з сервера. Клієнтські вкладки передають канал у кожній команді незалежно від цього вибору. Команди проходять через Bukkit `AsyncPlayerChatEvent`, враховують скасовані повідомлення й обмежений іншими слухачами список отримувачів. Доступ до Towny, Feudal, контекстів LuckPerms і координат виконується в головному потоці. Звичайний текст не може вставляти службові маркери, коди кольорів або значки титулів.

## Встановлення

Зупинити клієнт і сервер. Видалити старий ChatPlus на клієнті та старий Feudal на сервері. Скопіювати відповідні папки `client/` і `server/` з дистрибутива. Замінити серверний список ADM із пакета. Інші клієнтські й серверні моди, бази та конфігурація Towny/Feudal залишаються на місці. Службове API титулів у Feudal 1.4.1 лише читає наявну базу; схема бази не змінюється. Перезапустити сервер і клієнт.

На сервері репозиторію до зміни були Towny, EssentialsX, LuckPerms, Feudal, EmpirecraftTitles і папка старого ChatManager, але JAR ChatManager/TownyChat/EssentialsXChat відсутні. Тому додано один власний плагін маршрутизації. Він не потребує встановлення додаткового загального чат-плагіна.

## Відтворення й перевірка

JDK 17, Python 3, Pillow, PyYAML. Виконати `python3 feudal/build.py`, `python3 chat-channels/build.py`, `python3 chat-channels/test.py`, `python3 chat-channels/update_metadata.py --check`, `python3 chat-channels/package.py` з кореня репозиторію. API Spigot, Towny та H2 у збірці Feudal закріплені SHA-256; ChatPlus перевіряється за SHA-256 до змін. Залежності Minecraft/Forge беруться з наявних `server/libraries`.

Патч змінює лише шість перевірених класів оригінального ChatPlus. Передбачено перевірку сигнатур, точної структури реєстрації Forge і ASM BasicVerifier усіх методів змінених класів. Нових Mixin-класів немає; усі upstream Mixin-конфігурації та refmap збережені. Окремо тестується реальний шлях Bungee JSON → Minecraft Component, включно з порожньою кореневою обгорткою, службовими позначками, порядком титулів та bitmap-шрифтом. Feudal проходить повний набір перевірок фінансів, політики й провізії плюс нові перевірки титулів. Повний графічний клієнт і живий світ Mohist у цих тестах не запускаються.

`ChatPlus-2.8.1-upstream-source.zip` містить upstream-код `ebicep/ChatPlus` на коміті `a8279ba480bb89fb3136da6a59db0585cd21af70`, гілка Minecraft 1.20.1. Оригінальний JAR перенесено до `upstream/` як закріплений вхід збірки, він не встановлюється. Зміни й відповідні вихідні тексти — `src/`, `patch/`, `build.py`; ліцензія GPL-3.0 у `LICENSE-ChatPlus.txt`. Джерела шрифту DejaVu та його ліцензія — `font/`. `frozen-assets/` містить перевірені готові растрові зображення для відтворюваної збірки незалежно від версії FreeType; `assets.py` відтворює їх з оригінальних зображень/кольорових назв.
