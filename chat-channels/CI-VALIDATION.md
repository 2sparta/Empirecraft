# Перевірка інсталяційного пакета ChatPlus

Push-збірка GitHub Actions `40234674507` пройшла повний набір Feudal, перевірки маршрутизації, справжній Bungee → Minecraft Component, bitmap-ресурси й усі українські/російські переклади встановленої збірки. PR-перевірка ChatPlus `40234919446` також підтвердила відтворюваність усіх JAR/ZIP; перевірки Feudal `40234919610`, перекладів `40234919546` і smithing `40234919819` успішні.

ChatPlus: `c68bf47d16cf6701fe9be5325290df3f325398140ee448b8578e980b5088c005`; Feudal 1.4.1: `9f39690c4c8ceb0197d8167431901a0c5f5b28a1c5fa501e6ee19ca8d3b6066a`.

У загальному lock-файлі виправлено успадковані лічильники: фактичні inventory містять 100 клієнтських і 104 серверних JAR. Порядок записів узгоджено з чинним генератором forging metadata. Обидва `chat-channels/update_metadata.py --check` і `forging-balance/update_metadata.py --check` успішні разом; записи модів, крім заміни ChatPlus, збережені.

У клієнтському JAR змінено лише шість закріплених класів ChatPlus; нових Mixin-класів немає. Повного графічного клієнта та живого світу Mohist ці перевірки не запускають.
