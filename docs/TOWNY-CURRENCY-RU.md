## Как читать команды и кто может ими пользоваться

В основных разделах `<аргумент>` обязателен, `[аргумент]` необязателен. `add|remove` означает выбор одного слова; вертикальную черту вводить не нужно. Введите `/` в игре; в консоли начальный `/` обычно не нужен. Команды с инвентарём, меню или местоположением выполняются игроком в игре.

Названия владений с пробелами вводите через `_`, например `Новая_Русь`. Чтобы различить одноимённые город и государство, используйте `місто:Черкаси` и `держава:Русь`. Также принимаются постоянные ID, которые показывает `/t vassal info`. В большинстве политических и вассальных команд без явно указанного владения выбирается старшее активное владение самого правителя. Обычному жителю для просмотра следует указывать название; для важных действий также лучше указывать владение явно.

| Корень | Псевдонимы / назначение |
|---|---|
| `/town` | `/t`: стандартный город Towny и дополнения Empirecraft |
| `/nation` | `/n`, `/nat`: нация Towny |
| `/resident` | `/res`, `/p`, `/player`: житель Towny |
| `/plot` | Личные участки внутри города |
| `/towny` | Информация, карта, цены и рейтинги |
| `/townyadmin` | `/ta`: администрирование Towny |
| `/townyworld` | `/tw`: настройки мира Towny |
| `/invite` | `/invites`: приглашения Towny |
| `/currency` | `/cu`, `/валюта`: валюта Empirecraft |
| `/trade` | `/торг`: обмен с игроком рядом |
| `/order` | `/замовлення`: заказы ресурсов |
| `/commerce` | Незавершённые передачи предметов |
| `/statedebug` | Отдельная административная команда отладки |

Дополнительные ветки `/t`: `treasury` = `казна`; `state` = `держава`; `fief` = `вотчина`; `castle` = `замок`; `union` = `унія`; `vassal` = `васал` = `feudal`; `title` = `титул`; `diplomacy` = `дипломатія`; `dynasty` = `династія`; `estateinfo` = `володіння`; `provision` = `провізія`. Также есть `/t confed` и `/t federation`.

Используйте именно `/t vassal`, `/t title` и другие ветки `/t`. Упоминаемые в старых README самостоятельные `/vassal`, `/васал`, `/титул`, `/wallet`, `/bank`, `/exchange` в текущем `plugin.yml` не зарегистрированы. `/cu bank` существует как совместимая вложенная форма; это не самостоятельный `/bank`.

| Кто | Что определяет доступ |
|---|---|
| Обычный игрок | Просмотр, личный кошелёк, обмен, приглашения; для участков требуется собственность/доверие |
| Мэр / помощник Towny | Городские действия в пределах назначенных Towny-рангов и разрешений |
| Правитель владения | Договоры, развитие и управление своим владением; политические решения могут требовать согласования |
| Банкир | Финансовая роль конкретного владения, назначенная действующим правителем; не даёт политическую власть |
| Администратор | Отдельные права Towny и Empirecraft; OP не подменяет роль эмитента для печати валюты |

Для дополнений нужен `empirecraft.feudal.use` — по умолчанию доступен всем. Администрирование: `empirecraft.feudal.admin`; отладка: `empirecraft.feudal.debug`; независимая проверка замков и учреждений: `empirecraft.feudal.castle.review`. Последние три по умолчанию выдаются OP. Владение должностью, независимость, гражданство и бюджетные ограничения проверяются дополнительно.

В сохранённом `townyperms.yml` города определены ранги `assistant`, `helper`, `donator`, `vip`, `sheriff`; нации — `assistant`, `helper`. Это названия **рангов Towny**, а не групп LuckPerms и не роль Банкир. Например: `/t rank add PlayerName sheriff`.

Для стандартного Towny действуют `towny.command.*`, `towny.town.*`, назначенные ранги и `townyperms.yml`. Наличие команды в справочнике не означает, что она выдана каждому жителю. В приложении указаны команды самой версии 0.101.2.0, включая возможности, которые могут быть отключены настройками.

## Быстрый старт

### Жителю

```text
/t list
/t join Название_Открытого_Города
/invite list
/accept
/t
/t spawn
/plot claim
/cu balance
/cu gold balance
/cu market
```

`/t join` работает для открытого города. Для закрытого дождитесь приглашения и примите его. `/plot claim` покупает выставленный участок внутри города, а не присоединяет новый чанк к городу.

### Мэру

```text
/t new Черкаси
/t add PlayerName
/t claim
/t set spawn
/t provision
/t treasury balance
/t state status
/t state progress
```

При вассальном основании используйте грамоту и `/t vassal found` из раздела о вассалах. Присоединению территории дополнительно нужен запас провизии на следующие 24 реальных часа. В сохранённой конфигурации репозитория создание города, нации и обычный новый чанк стоят `0`; реальные цены проверяйте через `/towny prices` — конфигурацию сервера могут изменить.

### Первые действия эмитента

Пример предполагает, что `держава:Русь` уже независима, имеет подходящий политический уровень и вы — её уполномоченный правитель.

```text
/cu create Крона KRN держава:Русь
/cu reserve deposit 64 KRN
/cu print KRN
/cu info KRN
/cu treasury держава:Русь
```

В меню печати задайте целое количество, посмотрите прогноз и подтвердите очередь. Монеты поступают в казну эмитента. При эмитенте, который является городом, его казна открывается через `/t treasury`; `/cu treasury` предназначена для негородских владений. Внесённые 64 слитка становятся резервом валюты и не превращаются в расходные деньги казны.

## Обычный Towny: город, нация, участки

Здесь — самые нужные команды. Все справочные ветки, редкие операции и административные команды приведены в [полном каталоге](#полный-каталог-стандартного-towny).

| Команда | Что делает | Кто использует |
|---|---|---|
| `/t [город]` | Показывает информацию о своём или указанном городе | Игрок |
| `/t ?` | Справка города | Игрок |
| `/t new <название>` | Создаёт город, если выполнены условия Towny | Игрок с правом основания |
| `/t list`, `/t here`, `/t online`, `/t reslist [город]` | Список городов, город под ногами, онлайн и жители | Игрок |
| `/t join <город>`, `/t leave` | Вступает в открытый город / выходит | Игрок; ограничения договоров сохраняются |
| `/t add <игрок>`, `/t kick <игрок>` | Приглашает / исключает жителя | Мэр / уполномоченный ранг |
| `/t spawn [город]`, `/t outpost [номер]` | Телепорт на городской спавн / аванпост | По разрешениям и публичности |
| `/t claim`, `/t claim rect <радиус>`, `/t claim circle <радиус>` | Присоединяет землю к городу | Мэр / ранг с правом привата |
| `/t unclaim`, `/t unclaim all` | Снимает приват текущей / всей разрешённой территории | Мэр / уполномоченный ранг |
| `/t deposit <сумма>`, `/t withdraw <сумма>` | Банк стандартного Towny | Внесение — житель; вывод — уполномоченный |
| `/t set mayor <игрок>` | Передаёт пост мэра | Мэр; дополнения могут ограничить передачу |
| `/t set homeblock`, `/t set spawn` | Главный городской чанк и место телепорта | Мэр / уполномоченный ранг |
| `/t set taxes <сумма>`, `/t toggle taxpercent` | Налог и переключение процентного режима | Мэр / уполномоченный ранг |
| `/t rank add\|remove <игрок> <ранг>` | Выдаёт / снимает городской ранг | Мэр / уполномоченный ранг |
| `/t toggle pvp\|fire\|explosion\|mobs [on\|off]` | Настройки защиты города | Уполномоченный ранг |
| `/t toggle public\|open [on\|off]` | Публичный спавн / свободное вступление | Уполномоченный ранг |
| `/n [нация]`, `/n list`, `/n online` | Информация о нации | Игрок |
| `/n new <название>` | Создаёт нацию Towny из города | Мэр с нужными правами |
| `/n add <город>`, `/n kick <город>` | Приглашает / исключает город | Правитель / уполномоченный ранг |
| `/n join <нация>`, `/n leave` | Вступление в открытую нацию / выход города | Мэр; действуют политические ограничения |
| `/n set king <игрок>`, `/n set capital <город>` | Правитель и столица стандартной нации | Правитель / уполномоченный ранг |
| `/n deposit <сумма>`, `/n withdraw <сумма>` | Стандартный банк нации Towny | По рангу и разрешениям |
| `/n ally add\|remove <нация>`, `/n enemy add\|remove <нация>` | Отношения наций Towny | Правитель / уполномоченный ранг |
| `/plot info`, `/plot perm` | Участок и его разрешения | Игрок |
| `/plot claim`, `/plot unclaim` | Покупает участок / отказывается от личного участка | Житель / собственник |
| `/plot forsale [цена]`, `/plot notforsale` | Выставляет / снимает участок с продажи | Владелец / уполномоченный |
| `/plot set perm <уровень> <действие> on\|off` | Настраивает защиту участка | Владелец / уполномоченный |
| `/plot trust add\|remove <игрок>` | Доверие игроку на участке | Владелец / уполномоченный |
| `/res`, `/res <игрок>`, `/res tax` | Житель, его сведения и налоги | Игрок |
| `/res friend add\|remove <игрок>` | Личный список друзей для разрешений | Игрок |
| `/towny map`, `/towny prices`, `/towny time` | Текстовая карта, цены и время расчётов | Игрок |
| `/confirm`, `/cancel` | Подтверждает / отменяет ожидающую операцию Towny | Участник операции |

Права земли состоят из уровней `friend`, `resident`, `nation`, `ally`, `outsider` и действий `build` (строить), `destroy` (ломать), `switch` (переключать), `itemuse` (использовать предметы). Доступность уровней зависит от объекта: для личного участка применяется `friend`, для общегородской земли — `resident`. `on/off` включает или выключает разрешение, а не назначает роль.

```text
/plot set perm outsider build off
/plot set perm friend build on
/t set perm outsider destroy off
```

`/t set title` и `/n set title` — оформление имени Towny. `/t title grant` — дворянский статус Empirecraft. Передача реальной должности выполняется отдельно.

## Какие деньги и счета существуют

| Деньги / счёт | Просмотр и управление | Важное отличие |
|---|---|---|
| Обычная экономика сервера / Vault | Стандартные `/t deposit`, `/n deposit`; команды экономического провайдера | Используется стандартными расходами Towny; не подменяется автоматически государственной валютой |
| Внутренний `BASE` | `/cu balance`, `/cu vault deposit\|withdraw` | Учёт базовых денег во Feudal; не имеет золотого курса |
| Государственные валюты, например `KRN` | `/cu balance`, `/cu pay`, `/cu exchange` | Электронные балансы с точностью 0.01 монеты |
| Личный золотой счёт | `/cu gold balance`, `deposit`, `withdraw` | 1 ЗО = 1 обычный золотой слиток; точность счёта — 12 знаков |
| Городская казна Feudal | `/t treasury` | Отдельна от стандартного банка `/t deposit` |
| Казна государства / региона Feudal | `/cu treasury <владение>` | Отдельные балансы конкретного владения |
| Золотой резерв валюты | `/cu reserve <код>` | Обеспечение валюты, а не расходная казна; нельзя просто вывести как бюджет |
| Казна союза | `/t union treasury <ID>` | Принадлежит союзу, а не личному правителю |

В командах обмена `@GOLD` означает золотой счёт. Код государственной валюты `GOLD`, если такой создан, — другой актив. `BASE` нельзя обменять в золото по выдуманному курсу. Физические монеты стороннего мода Lightman’s Currency не равны балансам `/cu`: эта система не предоставляет команду автоматического обмена LC-монет в `KRN`.

Суммы вводите через точку: `12.50`, не `12,50`. Для физического внесения/выдачи золота принимается **целое число слитков от 1 до 2304**. Для перевода золотого баланса возможна дробная сумма. Коды государственных валют состоят из **3–8 латинских букв**, команды нормализуют код к верхнему регистру; `BASE` зарезервирован.

## Все команды валюты

У всех строк `/cu` можно заменить на `/currency` или `/валюта`. Подкоманды пишите по-английски; `help` также принимает `допомога`.

### Меню, просмотр, история

| Команда | Назначение / доступ |
|---|---|
| `/cu` | Открыть валютный рынок в игре |
| `/cu help` | Текстовая справка |
| `/cu market [код_A] [код_B]` | Рынок выбранной пары |
| `/cu chart [код_A] [код_B]` | То же открытие рынка с графиком |
| `/cu menu [код_A] [код_B]` | Псевдоним открытия рынка |
| `/cu balance` | Положительные балансы своего внутреннего кошелька; золото смотрится отдельно |
| `/cu list` | Список валют, названий и типа обеспечения |
| `/cu info <код>` | Эмитент, общий объём, резерв, курс и состояние |
| `/cu value <код>` | То же, что `info` |
| `/cu reserve <код>` | Информация о резерве и курсе |
| `/cu audit <код>` | Сверить сумму всех валютных счетов с общим объёмом; `BASE` не поддерживается. Администратору дополнительно выводятся найденные нарушения |
| `/cu history [код]` | Свои операции без кода; с кодом — журнал своей управляемой валюты. Для публичного просмотра используйте `log` |
| `/cu log <код> [номер_записи]` | Публичный журнал; номер используется как курсор для более старых записей |
| `/cu policy` | Текстовое объяснение финансовых правил |
| `/cu fees [код]` | Экран политики и комиссий; без кода выбирается собственная валюта. Изменения доступны управляющему эмитента |
| `/cu settings [код]` | Псевдоним `fees` |
| `/cu redemptions` | Экран своих заявок погашения; отмена ожидающей заявки выполняется в меню |

Экранов нет без подходящего Forge-моста: в текущей документации проекта требуется **empirecraft-towny-journeymap 1.3.0 на клиенте и сервере**. При отсутствии государственных валют рынок не открывается. Для графика нужны две разные золотые государственные валюты; сравнение с собой и с `@GOLD` в графике не предлагается. Для командного обмена с золотом используйте `@GOLD`.

### Переводы, обмен и погашение

| Команда | Что происходит |
|---|---|
| `/cu pay <игрок> <сумма> <код>` | Перевод из своего внутреннего кошелька другому игроку |
| `/cu exchange help` | Справка обмена |
| `/cu exchange quote <сумма> <откуда> <куда> [min_out]` | Только расчёт результата, комиссий, спаления и влияния на курс |
| `/cu exchange convert <сумма> <откуда> <куда> [min_out]` | Выполнить обмен; направление в `@GOLD` создаёт заявку в очереди |
| `/cu redeem <сумма> <код> [минимум_ЗО]` | Заявка на погашение валюты в золото; для старого `LEGACY_BASE` — погашение 1:1 в `BASE` |
| `/cu vault deposit <сумма>` | Из внешней экономики Vault во внутренний `BASE` |
| `/cu vault withdraw <сумма>` | Из внутреннего `BASE` обратно во внешнюю экономику Vault |

`min_out` — минимальная сумма результата **в валюте назначения**, не процент. Если её не указать, применяется допуск −0.5% к котировке. `quote` ничего не списывает. `convert` исполняет операцию сразу после проверок и не требует следующего `/confirm`; сначала используйте `quote`, если хотите только посмотреть расчёт.

```text
/cu pay PlayerName 25.50 KRN
/cu exchange quote 10 KRN SOL
/cu exchange convert 10 KRN SOL 8.50
/cu exchange quote 5 @GOLD KRN
/cu exchange convert 5 @GOLD KRN
/cu redeem 10 KRN 1.50
```

`KRN` и `SOL` — примеры, а не предустановленные валюты. Между успешными обменами и подачами заявок одного игрока действует общий кулдаун 5 секунд. Параметры комиссий и резервные ограничения могут не позволить выполнить даже обеспеченный личным балансом обмен.

## Печать, резерв, курс и погашение

### Кто печатает

У эмитента должны одновременно быть: активное владение; независимость; политический уровень из таблицы; валюта с золотым обеспечением; уполномоченный действующий правитель или его актуальный банкир; требуемая принадлежность к столице. Мэр подчинённого баронства не получает право печати просто из-за наличия валюты у королевства. Для эмитента-города проверяется принадлежность к самому городу. OP не обходит эти условия.

| Политический уровень | Время на 1 целую монету |
|---|---:|
| `county`, `principality`, `horde`, `central_state` | 15 секунд |
| `duchy`, `khanate`, `trade_republic` | 10 секунд |
| `kingdom`, `central_kingdom` | 7 секунд |
| `empire`, `central_empire`, `khaganate` | 5 секунд |
| `settlement`, `barony`, `tribe`, `free_city` | Собственная валюта и печать недоступны |

`/cu print KRN` открывает экран. Задайте целое количество **1–1 000 000 000**, проверьте время и конечный курс, подтвердите запуск. Одна валюта имеет одну очередь. Монеты поступают в казну эмитента по одной; в меню есть отмена и продолжение приостановленной очереди. Потеря нужных полномочий, уровня или независимости приостанавливает печать. Перезапуск не уничтожает очередь; накопленной мгновенной пачки монет за простой нет.

### Что означает курс

Мгновенный курс: **P = R / M**, где `R` — золотой резерв, `M` — все монеты, включая казны и зарезервированные средства. При `M = 0` курс не определён; при `R = 0` нет золотого обеспечения. Печать увеличивает `M` без добавления золота; пополнение резерва увеличивает `R`; спаление монет уменьшает `M`.

Крупная сделка рассчитывается по интегральной кривой, поэтому результат не равен начальному курсу, умноженному на всю сумму. При A → B монеты A возвращаются казне A, золото перемещается между резервами, монеты B берутся из казны B. Новые монеты основного обмена не печатаются; отдельно может спаливаться комиссия. Если в казне B нет доступных монет, купить B не получится.

### Комиссии и политика

Откройте `/cu fees KRN`. Просмотр показывает текущие параметры; редактировать может управляющий эмитента. Изменения вступают в силу через **1 реальный час**. Повторное изменение не сокращает задержку; одновременно хранится одна ожидающая политика. Смена правителя или утрата полномочий автора может отменить её до активации.

| Параметр | Начальное значение | Допустимый диапазон |
|---|---:|---:|
| Золотая комиссия покупки / продажи | По 1% | 0–10% |
| Спаление монет покупки / продажи | По 0.10% | 0–1% |
| Выход резерва за одну сделку | 10% | Более 0, до 100% |
| Выход резерва за скользящие 24 часа | 30% | Более 0, до 100% |
| Минимальное обеспечение | 20% от 1 ЗО/монету | 0–100% |
| Суточная подача погашения одним игроком | 1000 монет | Положительное значение в пределах учёта |

Это исходные значения, а не неизменные серверные тарифы. В A → B складываются золотая комиссия продажи A и покупки B. Минимальное обеспечение 20% означает минимум **0.2 ЗО на монету**. Выход из валюты, который нарушает ограничения, не выполняется; сначала проверьте политику и доступный резерв.

### Погашение в золото

`/cu redeem 10 KRN` и `/cu exchange convert 10 KRN @GOLD` используют одну очередь, ожидание — **10–20 реальных минут**. Монеты временно резервируются и не могут быть потрачены повторно. Расчёт выполняется пакетом по фактическому резерву; прогноз при подаче не гарантирует окончательную выплату. До обработки заявку можно отменить через `/cu redemptions`.

Если итог ниже `min_out` или ограничения не позволяют выплатить золото, монеты соответствующей заявки возвращаются. Отменённые и возвращённые подачи тоже учитываются суточной квотой. Выплаченное золото появляется на **личном золотом счёте**, а не автоматически в инвентаре: затем используйте `/cu gold withdraw <целые_слитки>`. Старая валюта `LEGACY_BASE` погашается в `BASE`, а не в золото.

Здесь и далее «правитель» означает право управлять **конкретным** владением, а не только наличие красивого титула в чате.

| Команда | Назначение / доступ |

| `/t vassal domain [владение]` | Псевдоним `info` |
| `/t vassal tree [владение] [страница]` | Дерево подчинения, 20 строк на страницу |
| `/t vassal list [владение]` | Прямые вассалы |

| `/t vassal release <вассал>` | Сюзерен добровольно завершает договор; долги сохраняются |
| `/t vassal independence [владение]` | Запрос мирной независимости для согласования сюзереном |
| `/t vassal tribute status <владение>` | Долги, доступные сторонам договора / казны |

| `/t vassal charter <сюзерен> <игрок>` | Грамота основания на 3 реальных суток для подходящего гражданина |
| `/t vassal preview <название>` | Информационная предварительная проверка основания |

Автономия: `висока` или `обмежена` (по умолчанию `висока`). Военная обязанность: `добровільно`, `оборона`, `повний` (по умолчанию `оборона`). Срок: `0` — бессрочно, иначе 7–365 реальных дней. Предложение обычно действительно 48 часов. Военные условия описывают договор для RP и не запускают автоматическую войну.

Дань начисляется каждые **7 реальных суток** от подписания и оплачивается из внутренней казны вассала. Недостаток средств создаёт долг; расторжение договора его не стирает. По умолчанию сохраняется максимум два неоплаченных периода. Нельзя обходить действующий договор/долг выходом, удалением или слиянием через стандартный Towny: дополнение проверяет эти действия.

```text
/t vassal create держава:Русь герцогство Київське
/t vassal appoint Київське PlayerName
/t vassal offer місто:Черкаси Київське 50 KRN висока оборона 0
/t vassal offers
/t vassal accept ID_Предложения
```

Для основания нового города сюзерен сначала выдаёт грамоту. Игрок самостоятельно выходит из прежнего города, затем выполняет `preview` и `found`. Если Towny просит подтверждение, используйте штатное подтверждение. Дополнительная дистанция по сохранённой настройке — до 2048 блоков от ближайшего привата своей державы; остаются все стандартные ограничения Towny. Ошибка вступления в нацию не удаляет уже созданный город — после исправления причины используйте `found confirm`.

| Команда титулов | Назначение |
|---|---|
| `/t title help` или `/t title list` | Справка о титулах и должностях |
| `/t title info [игрок]` | Должности и выданные титулы; `domain` — псевдоним |
| `/t title grant <государство> <игрок> <барон\|граф\|герцог>` | Выдать дворянский статус в пределах полномочий |
| `/t title revoke <государство> <игрок>` | Отозвать выданный статус; земли и договоры сохраняются |

Дворянский статус не меняет мэра, короля или владельца земли. Для должности используйте `appoint` либо подходящую передачу власти Towny / выборы / наследование.

Украинские варианты первой подкоманды `vassal/title`: `допомога→help`, `інфо→info`, `дерево→tree`, `список→list`, `меню→menu`, `створити→create`, `призначити→appoint`, `запропонувати→offer`, `проситися→petition`, `пропозиції→offers`, `прийняти→accept`, `відхилити/скасувати→reject`, `договір→contract`, `звільнити→release`, `незалежність→independence`, `сюзерен→liege`, `історія→history`, `данина→tribute`, `грамота→charter`, `перевірка→preview`, `заснувати→found`, `видати→grant`, `відкликати→revoke`, `адмін→admin`. Например: `/t васал інфо`.

## Союзы, конфедерации и федерации

Семейства `/t union`, `/t confed`, `/t federation` используют общий обработчик. `create` у `federation` создаёт федерацию; у `confed` и `union` — проект конфедерации. Для явного выбора типа используйте `propose`.

| Команда | Назначение |
|---|---|
| `/t confed create <название> [государство]` | Начать проект конфедерации |
| `/t federation create <название> [государство]` | Начать проект федерации |
| `/t union create <название> [государство]` | Начать проект конфедерации через общий корень |
| `/t union invite <государство>` | Пригласить от автоматически определённого государства в единственный подходящий союз |
| `/t union invite <ID_союза> <от_государства> <другое_государство>` | Явное приглашение; у проекта добавляет участника, у действующего союза создаёт голосование |
| `/t union amend <ID> <государство> <устав...>` | Изменить проект устава; предыдущие подписи аннулируются |
| `/t union propose <государство> <тип> <название> <участники_через_запятую> <код> <взнос_в_сутки> <компетенции> <устав...>` | Полный проект союза; компетенции занимают один аргумент, например с `_` |
| `/t union status [государство]` | Союзы государства и их состояния |
| `/t union terms [ID]` | Устав, компетенции, взносы и участники; без ID нужен единственный подходящий союз |
| `/t union charter [ID]`, `/t union powers [ID]` | Псевдонимы просмотра `terms` |
| `/t union sign <ID> <государство>` | Подписать план; `accept` — псевдоним |
| `/t union confirm <ID> <государство>` | Окончательное подтверждение плана слияния |
| `/t union reject <ID> <государство>` | Отклонить план |
| `/t union treasury <ID>` | Балансы казны союза |
| `/t union contribute <ID> <государство> <сумма>` | Внести средства из казны государства по условиям союза |
| `/t union debt <ID> <государство>` | Погасить принятые обязательства по взносам |
| `/t union join <ID> <государство>` | Подтвердить приглашение к вступлению |
| `/t union leave <ID> <государство>` | Подать уведомление о выходе; срок/долги проверяются отдельно |
| `/t union terminate <ID> <государство>` | Создать голосование о прекращении союза |
| `/t union vote propose <ID_союза> <государство> BUDGET <получатель> <код> <сумма>` | Проект расхода казны союза |
| `/t union vote propose <ID_союза> <государство> INVITE <государство_кандидат>` | Проект приглашения |
| `/t union vote propose <ID_союза> <государство> CHARTER <текст...>` | Проект нового устава |

В остальных строках общий корень `union` тоже можно заменить на `confed` или `federation`; короткое автоматическое определение союза фильтрует соответствующее семейство. При нескольких союзах используйте явный ID. Голосовать и подписывать может представитель конкретного государства, с дополнительным внутренним согласием там, где оно требуется.

Типы: `personal`, `real`, `merge`, `confederation`, `federation`, `trade_league`. `merge` — политическое объединение с отдельным окончательным подтверждением; внимательно прочитайте план через `terms`. Это не то же самое, что стандартное `/n merge` Towny.

## Провизия

| Команда | Назначение / доступ |
|---|---|
| `/t provision` | Открыть продовольственный склад своего города; нужен статус жителя |
| `/t provision status <город>` | Администратор: запас, территория и данные голода |
| `/t provision history <город>` | Администратор: состояние и последние 15 действий с территорией |

В меню нажмите еду в своём инвентаре: ЛКМ — стак / доступную часть, ПКМ — один предмет. Забирать еду могут мэр и помощник; рядовой житель пополняет склад. Слот с бумагой обновляет данные. Отдельных текстовых `deposit`/`withdraw` у провизии нет.

Расход — **8 единиц пищевой ценности на Minecraft-чанк за реальные сутки**, умноженный на сезон: весна ×1.0, лето ×0.5, осень ×0.8, зима ×1.5. Насыщение еды не считается. Для новых чанков нужен запас на 24 часа с учётом расширенной территории.

По сохранённым настройкам после 48 часов непрерывного голода город начинает терять окраинные участки; затем каждые 12 часов — примерно 10% текущей территории. После 96 часов полного голода возможен распад города. Это фактическая игровая механика провизии: отсутствие денежных долгов от неё не защищает. Время и последствия могут быть изменены серверной конфигурацией.

## Частые ошибки

| Ситуация | Что проверить |
|---|---|
| `/cu` ничего не открывает | Создана ли хотя бы одна золотая государственная валюта; установлен ли мост 1.3.0 с обеих сторон |
| Нет вкладки печати / отказ в печати | Независимость и уровень эмитента; кто сейчас правитель; актуальная роль банкира **эмитента**; принадлежность к столице |
| В `/cu balance` нет золота | Золото хранится отдельно: `/cu gold balance` |
| После `/t deposit` нет средств в `/t treasury` | Это разные банки. `/t deposit` пополняет стандартный Towny, `/t treasury deposit` — Feudal |
| Казна не принимает выбранный код | Подчинённая казна принимает валюту верховного независимого государства; сначала обменяйте личные средства |
| Не хватает монет при наличии резерва | Резерв — обеспечение; для покупки должны быть доступные монеты в казне эмитента |
| Обмен запрещён при положительном балансе | Комиссии, минимальная сумма, ликвидность, предел сделки / суток, минимальное обеспечение, кулдаун |
| Курс не определён | При `M=0` сначала нужен выпуск; при `R=0` нет золотого обеспечения |
| Погашение не мгновенное | Очередь 10–20 реальных минут; `/cu redemptions` показывает статус |
| После погашения нет слитков в инвентаре | Проверьте `/cu gold balance`, затем выведите целое число слитков |
| Нельзя выдать 0.5 слитка | Физический вывод целый; дробь остаётся на золотом счёте и доступна для перевода |
| Не работают `/wallet`, `/bank`, `/васал` | Используйте актуальные `/cu`, `/t treasury`, `/t vassal`; самостоятельные старые корни не зарегистрированы |
| Выдан титул, но нет власти | Титул не передаёт должность. Проверьте текущего мэра / правителя и владение |
| Нельзя выйти / удалить / слить город | Возможны действующий договор, долг или политическое подчинение |
| Не присоединяется новый чанк | Проверьте Towny-лимиты и запас провизии на 24 часа для всей новой территории |
| Есть незавершённая выдача / списание | Не повторяйте выдачу вручную: `/cu gold pending`, `/commerce pending` и проверка администратора |

## Полный каталог стандартного Towny

Далее приведён расширенный каталог штатных веток **Towny 0.101.2.0**, включая администрацию. Краткие описания основаны на встроенной справке и русской локализации этой версии; уточнения добавлены по обработчикам команд. В этом приложении сохранена исходная нотация аргументов Towny: `[...]`, `{...}`, `(nation)` и `[$]` обозначают подставляемые значения и **не всегда означают необязательность**. Не вводите скобки, `[$]` или слово `rank` вместо настоящих значений. Для конкретного действия смотрите основное объяснение, подсказку `?` и Tab.

Команды `/ta` и `/tw` относятся к администрации. Многие их варианты меняют, удаляют или перезаписывают данные. Право `towny.admin` и отдельные разрешения Towny не заменяются `empirecraft.feudal.admin`. Ветка `/ta town <город> set|toggle|rank ...` использует соответствующие городские подкоманды, а `/ta nation <нация> set|toggle|rank ...` — подкоманды нации; такой делегированный синтаксис не размножается отдельной строкой для каждого имени объекта.

| `/tw <мир> toggle wildernessuse [on\|off]` | Применение правил использования дикой местности. |

В игре `/tw` без имени работает с текущим миром; для административной команды из консоли явно указывайте мир перед `set`/`toggle`. Для большинства штатных переключателей доступны `on` и `off`; без значения флаг переключается. У специальных действий вроде `toggle conquered` смысл отличается, как указано в таблице.

Старое меню Towny упоминает `friend add+` / `remove+`, однако текущий обработчик этой версии принимает `add` / `remove`; используйте эти обычные формы.

Стандартный Towny не регистрирует самостоятельные `/tc` и `/nc` в своём `plugin.yml`: чатовые команды предоставляются отдельным чатовым плагином. Они не являются гарантированными командами этой установки только из-за наличия Towny.
