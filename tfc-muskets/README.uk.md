# TFC Muskets для Empirecraft

Використано саме вкладення `tfc_muskets-1.20.1-forge-1.0.3.jar`; оригінал — у `native-inputs/`, SHA-256 — в `input.json`. Адаптований `dist/tfc_muskets-1.20.1-forge-1.0.3-empirecraft.1.jar` ставиться на обидві сторони через [загальний пакет](../ecology-update/FULL-UPDATE.uk.md).

Усі 9 Java-класів байтово тотожні оригіналу. Рецепти перенесені в TFC Integration 1.0.1 й використовують чинну складну кузню та наявні компоненти. Залежність від відсутнього TFC Items вилучена після перевірки, що його ID були лише в замінених рецептах. Ковадло TFC не повертається.

Стволи й ложа використовуються в семи складних рецептах зброї. Стрижень заліза або чавуну (50 одиниць) дає 5 заготовок кулі; обробка — наждачним папером вручну, млином Create або жорном TFC з наявним приводом від вала. Старі збережені стрижні доповнення залишаються придатними до витрати, але новий свинець для цього не потрібний. 1 порох ↔ 9 мірок. Куля + мірка + папір → 1 патрон. Нативні тести перевіряють обидва металеві маршрути, збереження інструментів, заряди й патрон.

Відтворення: `python tfc-muskets/build.py --input tfc-muskets/native-inputs/tfc_muskets-1.20.1-forge-1.0.3.jar` з кореня. `audit.json` містить контрольні суми класів та перелік замінених рецептів.
