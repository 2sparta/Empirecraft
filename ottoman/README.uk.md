# Ottoman Empire — інтеграція Empirecraft

Джерело: наданий користувачем `hamzabus_ottoman_mod-1.0.4-forge-1.20.1.jar`, SHA-256 `9868f790926162321cff38c45666b59b28ad3f6bcb145dc2390229a2254320e8`. Усередині оригінального JAR зазначено 1.0.3. Автор — HamzaBU / MCreator, ліцензія MIT; оригінальні кредити та моделі збережено. Випуск інтеграції — `1.0.4-empirecraft.1`.

`python ottoman/build.py` компілює вузькі сумісні заміни під Java 17, переводить назви Minecraft у Forge SRG та детерміновано пакує вихідний мод. Власна сталь замінена реєстровими посиланнями на Overgeared; MissingMappings переносить старі сталь/самородки та старий стан щита. Прибрані три рецепти дубльованої сталі, спеціальна процедура нищення броні топузом та кругова невразливість щита.

Калкан працює як звичайний утримуваний щит. Відкидання знімає сумісний Mixin з Empirecraft Armory. Шість рецептів зброї/щита перенесені на ковадло Overgeared; їхня вихідна вартість металу збережена. Вони підтримують ковальську якість і нагрівання TFC. Топуз і наккареджі — ударні, ятаган/килич/табар — різальні. Металевий шишак і тканинний одяг отримують правильні профілі PR #149 та теги шарів броні.

Empirecraft Armory перетворює чинні рецепти обладунків після KubeJS на поетапне складання. Під час фарбування жилетів зберігаються NBT, якість і частка зношення. Залишені оригінальні тканини, повсть, їжа, жаровня та декоративний вміст; сире м’ясо для кебаба приймає теги збірки, включно з TFC. Додано українські назви.

Потрібні однакові інтеграційні JAR на сервері та клієнтах. Інсталятор у `armory/dist/` постачає мод разом із сумісними Armory та Forging 1.1.5. Виробничі світи не використовуються тестами.
