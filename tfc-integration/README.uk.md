# Інтеграція TerraFirmaCraft для Empirecraft 1.0.5

Minecraft 1.20.1, Forge 47.4.23, Mohist 71a84ff7. Потрібні модифікований TFC 3.2.30, `empirecraft-tfc-integration-1.0.5.jar` та адаптований TFC Muskets на обох сторонах. Нативний TFC байтово тотожний попередньому випуску. Поточне доповнення до загального пакета — [очищення сервера](../server-cleanup/README.uk.md). Звичайний TFC поряд не встановлюється. Тестовий JAR не призначений для гри.

## Пісок у 1.0.5

Звичайний і червоний пісок Minecraft відразу підходять для кремнеземної та гематитової скляної шихти відповідно. Старі білі й червоні блоки TFC залишаються сумісними зі збереженнями й після видобутку дають відповідний ванільний пісок. Предмети в інвентарі гравця оновлюються під час гри.

У дюнах Сахари лишається звичайний пісок. У Намібі, центральній Австралії та Руб-ель-Халі трапляються витягнуті смуги червоного піску. Коричневі наноси формуються в руслах і на берегах річок. Чорний пісок з’являється на вулканічних узбережжях, рожевий біля Гарбор-Айленду та Бермуд, а зелений лише поблизу пляжу Папаколеа на Гаваях. Для рідкісних прибережних пісків важливі висота над рівнем моря та глибина води. Розташування пляжів наближене до роздільної здатності карти. [Координати Папаколеа](https://research-portal.uu.nl/ws/files/276688600/Kreuzburg_2025_Environ._Res._Lett._20_114074.pdf) · [Координати Пуналуу](https://hilo.hawaii.edu/documents/academics/mop/projects/JarvisO_turtledata_2022.pdf)

Прохід за координатами проходить крізь межі чанків і замінює до двох шарів наявного піску. Застосовується до чанків, у яких ще не завершився прохід природних матеріалів, із перевіркою Towny та кордону світу. Старі плями в уже оброблених чанках залишаються на місці.

На клієнті й сервері замініть `empirecraft-tfc-integration-1.0.4.jar` на `empirecraft-tfc-integration-1.0.5.jar`. Скрипт `build_sand_update.py` збирає цей випуск із JAR 1.0.4 і того ж Forge SDK (`--base` і `--sdk`).

У 1.0.3 прибрано залежність боєприпасів від вилученого моду, старі стрижні залишаються придатними до витрати.

У 1.0.2 додано незалежний одноразовий прохід пропущених порід, пісків, ґрунтів, каоліну та торфу, а також доступну сировину для скла. Старі рудні позначки збережено; [подробиці й перевірка міграції](MATERIALS-UPDATE.uk.md).

У 1.0.1 форми Overgeared замінено формами TFC зі збереженням 22 результатів і кількості металу. Додано деталі й патрони TFC Muskets без повернення ковальства TFC. Загальний пакет також оновлює природу, броню, кораблі й додає докладний довідник.

## Залишені та поєднані механіки

- Плавлення, температури металів, форми, тигель, сплави, горн, плавильна й доменна печі TFC. Ковадла, зварювання та мінігра TFC вимкнені; виплавка сталі й складних сплавів має теплові рецепти. Вогнетривка глина потребує каолініту й піску замість графіту.
- Єдині злитки: мідь/залізо/золото Minecraft; олово Antique Legacy; бронза Create Big Cannons; цинк/латунь Create; сталь Overgeared; срібло Epic Knights. Caupona вилучено; нові кулі використовують стрижні заліза та чавуну. У цьому випуску Epic Knights срібний злиток не реєструвався, хоча модель є: інтеграція відновлює саме `magistuarmory:silver_ingot`, якщо його немає.
- Товсті листи TFC містять два злитки, подвійні листи — чотири. Це окремі предмети від тонких листів Create: взаємозаміна дала б дублювання металу при переплавці. Два злитки складаються в подвійну заготовку, прес Create робить із неї товстий лист; два листи складаються в пакет. Пилка Create виготовляє стрижні й наконечники метальних списів.
- Розколювання каменю та гончарство TFC. Старе розколювання Overgeared і дешеві ванільні рецепти кам'яних інструментів вимкнені; кирка збирається з розколотого наконечника та палиць. Кам'яні молоти TFC працюють із ковальством Overgeared.
- Жорно TFC можна обертати вручну або через **вертикальний вал Create → привід жорна → жорно**. Вал входить знизу, привід стоїть безпосередньо під жорном. Потрібний жорновий камінь, його міцність витрачається. Привід споживає навантаження Create; зупинка та перевантаження припиняють помел. Вихід доступний збоку приводу для автоматичного вивантаження.
- Землеробство TFC: ґрунти, поживні речовини, добрива, культури й кліматичні вимоги. Звичайна мотика створює ґрунт TFC; ванільні культури на ньому зберігаються й витрачають поживні речовини. Насіння нових культур зрідка випадає з трави; плодові саджанці й ягідні кущі продає мандрівний торговець. Температура надходить із LSO, дата — з чинного календаря Empirecraft. Час світу й сезони TFC не замінює.
- Склоробство TFC та алебастр. Скляні інструменти отримали доступні рецепти після вилучення ковальства TFC.
- Борошно TFC працює в пивоварінні Brewin' and Chewin'; обидва пивоварні маршрути дають його пиво. Яблука TFC приймають відповідні рецепти Vinery, наявне витримування вина збережене.
- Мушкет, мушкет із багнетом/прицілом, пістоль, мушкетон, аркебуза та ручна гармата мають складні маршрути через гарячу сталь, заготовку ствола, замок, ложу, пилку Create й ковадло **Overgeared** із кресленням `firearm`. Усі прості рецепти цих семи предметів прибираються. Під час поліпшення мушкета переноситься його NBT.
- Наявний рецепт пороху Sulfur Gunpowder: **3 порошки селітри + сірка цього моду + деревне вугілля → 6 пороху**. Окрему систему пороху й вибухові бочки TFC вимкнено.
- Типи колючого, ріжучого й дробильного урону TFC поширені тегами на зброю збірки та типи вогнепальних снарядів. Мечі/булави TFC вилучені з отримання; метальні списи залишені.

## Тварини

Ведмеді є справжніми хижаками TFC: їхні AI, дроп, домашня територія, сон, атаки й притискання гравця збережені. Клієнт малює їх через модель Naturalist. Завантажені ведмеді Naturalist і ванільні білі ведмеді переносяться зі збереженням UUID, імені, положення, частки здоров'я та дитячого віку. Naturalist-кабани й леви замінюються TFC. Тигра в установленому Naturalist немає; додається TFC-тигр.

Погоджені дублікати оленів, карибу, качок, пінгвінів, вовків, лисиць, частини водних істот та свійських тварин зберігають наявні сутності й вигляд. Для наземних тварин адаптовані втеча від хижаків, слідування дитинчат і нічний відпочинок; приручені вихованці не отримують примусової втечі. Дорослі слони, носороги й бегемоти захищають групу. Це адаптація до AI інших модів; оригінальний мозок TFC безпосередньо працює на його власних сутностях.

Свійські тварини DragN's зберігають моделі та генетику. Додані звикання, щоденне годування, дорослішання, вагітність і розмір приплоду за параметрами TFC. Генетичний нащадок зберігається до пологів. Кури користуються гніздами TFC; запліднене яйце містить генетичного нащадка DLO. Заповнений ліміт фауни відкладає появу дитинчати, не знищує збережений приплід/яйце. Нові види TFC отримують спавн у відповідних наявних біомах без генератора світу TFC.

Із генетикою коней `empirecraft_equine` збережені успадкування здоров'я/швидкості/стрибка, походження та стерильність. Нові вагітності веде TFC; старі незавершені вагітності генетичного доповнення завершуються його власним механізмом. Повторне зачаття під час вагітності й перетворення готових пологів на нову вагітність заблоковані.

## Вимкнене

Ковальська мінігра TFC, труби/акведуки, його водяні колеса/вітряки/передачі, обвали й зсуви; вудки та гачки TFC; крафт ванільної вудки; харчові групи, особливе здоров'я, спрага й погода TFC; псування та рецепти консервації; обмеження ваги й зменшені стаки; графіт, кіновар, кріоліт і галіт. Звичайні злитки та інші придатні для складання предмети мають стак 64. Форми з рідиною й інструменти залишаються одиничними.

Рибальство лишається за Starcatcher; його поплавок більше не потребує забороненої ванільної вудки. Спрага/температура тіла — LSO, здоров'я гравця — ванільні 20 HP. Напої з керамічного глека поповнюють наявну спрагу LSO.

Вимкнені реєстрові ID залишені для сумісності збережень: прибрані рецепти, дроп, творче меню/JEI й використання. Це не фізичне видалення всіх класів та моделей із JAR. За окремим погодженням деревина, двері, меблі та металеві декоративні блоки TFC залишені.

## Старий світ: каміння та родовища

Повний перелік із призначенням — [minerals.csv](minerals.csv). Додаються 20 типів родовищ; мідь/залізо/золото не дублюються. Цинк, сірка та кварц мають попередній прохід `empirecraft-ore-retrogen`, його прапорці не скидаються.

Інтеграція обробляє **один уже завантажений чанк за 20 тіків**, без примусового завантаження. У межах кордону overworld/world_europe додаються дрібні підземні родовища та до чотирьох поверхневих каменів. Поля `Ores`, `Stones` і незалежне `Materials` у чанку переживають перезапуск: видобуте не відновлюється. Новий прохід доповнює також чанки зі старими завершеними прапорцями; він додає природні породи, піски, ґрунти, кольоровий каолін і торф. Генератор ландшафту не замінюється.

Чанки Towny з приватами пропускаються; якщо Towny на Mohist недоступний, зміни не виконуються. Руда замінює лише камінь/граніт/діорит/андезит/глибинний сланець/туф, без блок-сутностей, щонайменше на вісім блоків нижче поверхні. Штучно поставлений звичайний камінь поза приватами неможливо відрізнити від природного за самим блоком. Світ перед установленням слід скопіювати; виробничий світ під час розробки не запускався й не редагувався.

## Базова інтеграція та відтворення

Після базового архіву 1.0.0 встановіть поточний загальний пакет за посиланням вище; старі супровідні JAR із базового архіву замінюються новими.

Зупиніть гру/сервер, скопіюйте `mods/` і `server/` з інсталяційного архіву зі збереженням структури. Перевірте відсутність іншої версії TFC/цієї інтеграції. Конфіги Overgeared і серверний KubeJS-скрипт у пакеті відповідають цій збірці; для іншої збірки перенесіть відповідні зміни. Використовуйте Java 21 для наявного Mohist/Towny; код доповнення компілюється під Java 17.

Базовий архів 1.0.0 містить `empirecraft-equine-genetics-1.0.0.jar`, `empirecraft-layered-armor-1.0.2.jar` і `empirecraft-seasonal-leaves-1.3.2.jar` із чинного `main`. Перед копіюванням видаліть старі `realistic_horse_genetics-1.20.1-13.5.jar`, `empirecraft-layered-armor-1.0.1.jar` та `empirecraft-seasonal-leaves-1.3.1.jar` з клієнта й сервера, щоб не залишити дублікати. Повний перелік — `remove-before-install.txt` в архіві. Збережені дані коней мігрує генетичне доповнення DLO; вихідні тексти супровідних модів також включені в пакет.

`decisions.json` закріплює погоджені рішення, офіційний upstream commit і SHA-256. Вкладення понад ліміт перенесення середовища, тому використано офіційний TFC з указаною назвою/версією; байтову тотожність вкладенню не заявлено. Ліцензія TFC та похідних змін — EUPL-1.2, див. `LICENSE`.

```sh
python build.py --tfc /path/TerraFirmaCraft-Forge-1.20.1-3.2.30.jar --sdk /path/forge-toolchain --java-home /path/jdk17
python build.py --fixture --tfc /path/TerraFirmaCraft-Forge-1.20.1-3.2.30.jar --sdk /path/forge-toolchain --java-home /path/jdk17
python smoke.py --java-home /path/java21 --runtime /workspace/work/tfc/runtime
python smoke.py --full-pack --materials-update --java-home /path/java21 --runtime /workspace/work/tfc/full-runtime
python verify_materials.py
python ../ecology-update/release_full.py --install
```

Серверні результати й перевірені контрольні суми зберігаються в `audit/`. Графічний клієнт, анімації запозиченої моделі та продуктивність на великій кількості тварин потребують окремого ігрового огляду; серверний запуск їх не перевіряє.
