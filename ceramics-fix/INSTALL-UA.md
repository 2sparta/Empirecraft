# Наждачний папір, ямна піч і жорно

Пакет `dist/Empirecraft-Paper-Pottery-1-install.zip` додає сумісність пісків TFC із наждачним папером Create та довідник 1.0.5. Збережені ID предметів і книги не змінюються.

## Встановлення

Зупини гру й сервер, розпакуй пакет у окрему папку та запусти Python 3.11+:

```text
python update_installation.py --client "/шлях/до/клієнта" --server "/шлях/до/сервера"
```

Можна передати тільки один із боків. Оновлювач встановлює довідник 1.0.5, рецепти паперу/книг і новий скрипт наждачного паперу. Попередній довідник прибирається з `mods` за mod ID та зберігається в `.empirecraft-backups/paper-pottery-1` відповідного боку. Наявний ADM оновлюється лише для довідника, зі збереженням формату JSON або текстового звіту й решти записів. Перевірка обох боків відбувається до запису. Після встановлення перезапусти гру й сервер.

Саме нові рецепти додає файл `kubejs/server_scripts/zzzzzzzzzz_empirecraft_sandpaper.js` на сервері; оновлений JAR книги містить інструкції. Міняти модифіковані TFC або Create цим пакетом не потрібно. Налаштування AntiXray, авторизація, світи й playerdata цим оновленням не змінюються.

## Наждачний папір

В оригінальному рецепті Create дозволені Forge-теги звичайного й червоного піску. Нативна перевірка підтвердила: ванільні піски працюють, білий і червоний TFC не підходять. Новий скрипт зберігає два попередні ID рецептів та додає TFC-піски:

- Один папір + один білий, жовтий, чорний, зелений або коричневий пісок TFC → один звичайний наждачний папір Create.
- Один папір + один червоний або рожевий пісок TFC → один червоний наждачний папір Create.
- Ванільний звичайний і червоний пісок та сумісні Forge-теги залишаються придатними.

Розташування в сітці довільне, працюють сітки 2 × 2 та 3 × 3. Це звичайні рецепти крафту, придатні для показу в JEI. На предметі Create натисни R; на піску чи папері — U. Якщо рецепт не показується, перевір крафт у сітці: це дозволяє відрізнити відсутній серверний рецепт від проблеми клієнтського JEI.

## Ямна піч TFC

1. Підготуй яму 1 × 1 блок завглибшки один блок, із суцільним дном і чотирма негорючими стінками. Камінь і земля підходять, дерево для стінок — ні. Верх залиш відкритим.
2. Візьми сирий виріб у головну руку, наведися зверху на дно й натисни V — «Розмістити предмет» TFC. Звичайний ПКМ по порожній ямі не ставить його. За конфлікту клавіш перепризнач цю дію в налаштуваннях керування TerraFirmaCraft.
3. Додавай солому TFC правою кнопкою по розміщених виробах. Перша солома створює ямну піч. Усього потрібно 8 соломи.
4. Додай 8 колод. Ванільні дубові колоди підходять; усі колоди мають відповідати паливному тегу печі.
5. Візьми кресало й натисни Shift + ПКМ по заповненій печі. Залиш стінки, дно й верх у придатному стані до завершення випалу.
6. Після згасання вогню забери готову кераміку порожньою рукою правою кнопкою.

Типова тривалість — 8000 тіків TFC. У наданому конфігу хостингу розміщення через V увімкнене, а whitelist розміщуваних предметів не застосовується. Рецепти звичайних колод не додавалися: користувач уточнив, що питання було в керуванні.

## Жорно від Create

Розміщення зверху вниз:

```text
Жорно TFC
Привід жорна Empirecraft
Вертикальний вал Create
Джерело обертання / механічна передача
```

Звичайний вал над жорном його не приводить. Потрібен окремий блок `empirecraft_tfc:quern_drive`, який виглядає як андезитовий корпус. Його рецепт 3 × 3:

```text
      залізний лист Create
шестерня    дошки    шестерня
           вал Create
```

Шестерні — малі Create. У жорно встанови жорновий камінь TFC (`tfc:handstone`) і придатну сировину, наприклад зерно пшениці TFC. Вал знизу має обертатися від колеса або іншої наявної мережі Create. Камінь зношується; після його руйнування помел припиниться. Вихід продукту можна отримати збоку приводу.

## Перевірка

Нативні результати й межі перевірки — `verification.json` у пакеті та `audit/native-fixed.json` у вихідному коді. Випал перевіряється з реальною механікою TFC; у тесті пересувається тільки внутрішній час уже запаленої печі, щоб не чекати повного циклу. Механічний тест використовує окремий тестовий генератор на базі Create та справжню мережу Create в ізольованому світі. Тестовий генератор не встановлюється в ігрову збірку; штатний Creative Motor лишається відключеним. Графічний клієнт і світ із хостингу не запускаються.

Для відтворення у повному checkout з підготовленим SDK, результатами збірки `tfc-integration/build` (named-залежності та `compile-access.jar`) і згенерованим тестовим runtime:

```text
python ceramics-fix/run_native.py --fix --work /workspace/work/new-ceramics-test --reference-repo /шлях/до/checkout --sdk /шлях/до/toolchain --java-home /шлях/до/jdk17 --fixture /шлях/до/generated-fixture
```

Потрібен Java 21 для наявного Mohist; тестовий fixture мусить містити маркер `TFC-INTEGRATION-TEST-ONLY`. Тестовий JAR не встановлюється в ігрову збірку.
