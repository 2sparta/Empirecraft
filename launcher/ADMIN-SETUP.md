# Одноразове ввімкнення публічного каналу

Поточний `2sparta/Empirecraft` приватний. Його видимість не змінюється. Публікується окремий `2sparta/Empirecraft-Releases` із перевіреними клієнтськими файлами, без серверних папок, світів, playerdata, конфігів авторизації або приватних ключів. До явного рішення власника публікація вимкнена (`LAUNCHER_DISTRIBUTION_ENABLED` відсутній).

Спочатку переглянь і злий PR #137 після потрібних змін #136. У приватному комплекті адміністратора є `SETUP.ps1`, ключ підпису релізів, SSH deploy key і його публічна частина. Комплект адміністратора **не можна публікувати чи передавати гравцям**.

На своєму ПК встанови GitHub CLI та увійди як `2sparta` через `gh auth login`. Переглянь `SETUP.ps1` і запусти його з папки приватного комплекту. Скрипт:

1. Перевіряє обліковий запис та створює окремий публічний репозиторій із README, якщо його немає. Наявний приватний репозиторій автоматично публічним не робить.
2. Додає deploy key з write-доступом **тільки** до репозиторію дистрибуції.
3. Зберігає `LAUNCHER_SIGNING_KEY` та `LAUNCHER_DISTRIBUTION_SSH_KEY` у Secrets приватного джерела, не в git.
4. Вмикає `LAUNCHER_DISTRIBUTION_ENABLED=true` і запускає publisher workflow на main.

Не потрібен спільний PAT для гравців. Лаунчер ніколи не отримує приватні GitHub credentials. Воркфлоу формує список з дозволених клієнтських папок та власного клієнтського аддона; підозрілі ключі у текстових конфигах блокують експорт. SHA-256 і Ed25519 перевіряються клієнтом незалежно від доступності GitHub.

Після успішної публікації перевір без авторизації `https://raw.githubusercontent.com/2sparta/Empirecraft-Releases/main/channel/stable.json` та перший запуск легкого Windows архіву на чистому ПК. Поки каналу немає, використовуй архів `Windows-x64-Full`: він містить перевірений локальний кеш збірки, але потребує інтернету для офіційних Minecraft/Java/Forge.

Зроби приватну резервну копію комплекту. Якщо ключ підпису втрачено або скомпрометовано, знадобиться новий trust root і нова версія лаунчера; мовчазна заміна ключа в уже встановлених лаунчерах заборонена.
