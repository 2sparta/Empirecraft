# Налаштування наступних автоматичних релізів

Публічна клієнтська дистрибуція: `2sparta/EmpireCraftLauncher`. Початковий канал підписаний і доступний без GitHub-авторизації. Приватний `2sparta/Empirecraft` залишається джерелом серверної збірки; його видимість не змінюється.

Для автоматичного підписання наступних версій потрібне одноразове внесення ключів у GitHub Secrets. Сервісні інструменти цієї сесії не надають операції запису repository secrets, тому ключі передані власнику в окремому приватному комплекті. Його **не можна публікувати чи передавати гравцям**.

На своєму ПК встанови GitHub CLI, увійди як `2sparta` через `gh auth login`, переглянь `SETUP.ps1` і запусти його з папки приватного комплекту. Скрипт:

1. Перевіряє обліковий запис і публічний репозиторій дистрибуції.
2. Зберігає `LAUNCHER_SIGNING_KEY` у Secrets публічного репозиторію, вмикає `LAUNCHER_SIGNING_ENABLED=true` та запускає `publish-channel.yml`.
3. Додає SSH deploy key з write-доступом тільки до репозиторію дистрибуції.
4. Зберігає ключі у Secrets приватного джерела та вмикає `LAUNCHER_DISTRIBUTION_ENABLED=true` для експорту наступних оновлень збірки. Для цього workflow актуальний PR з оновленням приватного експорту має бути злитий; скрипт не зливає його самостійно.

Гравцям GitHub-токени або приватні ключі не потрібні. Воркфлоу з приватного джерела переносить тільки дозволені клієнтські папки; експорт блокується за наявності підозрілих ключів у текстових конфигах. Після публікації клієнт незалежно перевіряє Ed25519, SHA-256, строк дії та захист від відкату.

Новий канал формують після змін модів/конфігів і раз на квартал, щоб поновити строк дії 180 днів. Зміни самого EXE розповсюджуються окремим релізом. Перевіряй джерела JAR перед підписанням, обмеж write-доступ до main/workflows і ввімкни 2FA.

Перевір канал без авторизації: `https://raw.githubusercontent.com/2sparta/EmpireCraftLauncher/main/channel/stable.json`. Зроби приватну резервну копію ключів. Якщо ключ підпису втрачено або скомпрометовано, знадобляться новий trust root і нова версія лаунчера.
