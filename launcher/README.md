# Empirecraft Launcher 0.1.0

Легкий настільний лаунчер для Windows x64 і Linux x64. Minecraft 1.20.1, Forge 47.4.23, єдиний сервер `p2.foxter.top:25628`. Інтерфейс українською. Це перша версія; виміряного приросту FPS на реальному ноутбуці ще немає.

## Запуск

1. Завантаж `Empirecraft-Launcher-0.1.0-Windows-x64.zip` з перевіреного релізу/артефакту репозиторію `2sparta/Empirecraft`.
2. Розпакуй **усю** папку. Запусти `Empirecraft.exe` без прав адміністратора. Linux: `chmod +x Empirecraft/Empirecraft`, потім `./Empirecraft/Empirecraft`.
3. Обери профіль, введи свій нік і натисни «Вирушити на сервер». Пароль чинної серверної авторизації вводиться лише всередині гри. Лаунчер не збирає паролів. Microsoft OAuth у цій версії не реалізовано; потрібна чинна авторизація сервера за ніком.
4. Перше встановлення потребує інтернету та місця для кешу, Java, поточного профілю і попередньої версії. Наступні запуски перевіряють файли та завантажують тільки змінені об’єкти.

Windows SmartScreen може позначити новий виконуваний файл невідомого видавця: кодового підпису Authenticode у першої версії немає. Підпис каналу захищає оновлення збірки; він не є підписом EXE. Не відключай антивірус. Перевір джерело, контрольну суму та результати Actions.

## Профілі

| Налаштування | Potato | Balanced | High |
|---|---|---|---|
| Дальність / симуляція клієнта | 5 / 4 | 8 / 5 | 12 / 6 |
| Ліміт FPS за замовчуванням | 60 | 90 | 120 |
| Частинки | мінімум | зменшені | всі |
| Графіка / AO / тіні сутностей | fast / вимкнені | fancy / увімкнені | fancy / увімкнені |
| Міпмапи / змішування біомів | 0 / 0 | 2 / 2 | 4 / 3 |
| Звукова фізика, Dynamic FPS | не встановлюються | встановлюються | встановлюються |
| Спека/холод LSO, дихання, візуальний дощ/сніг | вимкнені | увімкнені | увімкнені |
| Oculus 1.8.0 | відсутній | відсутній | встановлюється |

High додає бекенд шейдерів, але не встановлює shaderpack і не вмикає шейдери автоматично. Власний вибір shaderpack зберігається. Дальність, ліміт FPS, RAM і зменшені ефекти можна налаштувати окремо. Ліміт FPS — верхня межа, а не обіцяна продуктивність. Серверна дальність і TPS можуть обмежити результат незалежно від профілю.

Embeddium, ModernFix, FerriteCore, EntityCulling, ImmediatelyFast і MemoryLeakFix залишаються в кожному профілі. Контентні моди, кораблі, тварини, ремесла, карта, голосовий чат, античит та індикатори виживання зберігаються. Нових асинхронних генераторів чанків немає. Лаунчер не змінює правила температури/спраги, серверну симуляцію, драйвери чи схему живлення ОС.

Кожний профіль має власну папку. Налаштування керування, мова, карти JourneyMap, screenshots, shaderpacks і особисті файли зберігаються при оновленні цього профілю. Моди з довільних папок не підхоплюються. Кнопка перевірки відновлює керовані файли та прибирає сторонні JAR із профілю; звичайна `.minecraft` не змінюється.

## Підлагування при низькому загальному навантаженні

Тихий ноутбук не визначає причину. Один зайнятий потік Minecraft може давати лише 10–15% загального CPU, а паузи також спричиняють GC, диск, swap, енергозбереження, неправильна GPU або очікування сервера.

Почни з Potato і автоматичного обсягу пам’яті. На 8 ГБ зазвичай виділяється до 4 ГБ, решта лишається ОС; не виділяй усю RAM. Підключи живлення; перевір F3 renderer та признач javaw.exe лаунчера високопродуктивну GPU у Windows, якщо вона є. Лаунчер не встановлює фоновий ліміт Dynamic FPS у Potato.

«Діагностика» показує RAM, доступну пам’ять, вільний диск, живлення і паузи GC. Під час гри кожні 2 с записуються CPU Java, RSS, доступна RAM, swap і сумарний дисковий ввід/вивід. Це локальні показники, не телеметрія. Показники GPU/FPS та серверний TPS автоматично не вимірюються. Звіт не надсилається без дій гравця.

Папка даних: Windows `%LOCALAPPDATA%\Empirecraft`; Linux `$XDG_DATA_HOME/Empirecraft` або `~/.local/share/Empirecraft`. Логи: `instances/<profile>/logs/{launcher-game.log,gc.log,performance.json}`. Звіт обладнання: `diagnostics.json`.

## Безпека та межі

Канал GitHub перевіряється Ed25519 за вбудованим публічним ключем. Розмір і SHA-256 перевіряються для кожного моду/конфіга; URL вказує на незмінний commit. Дозволені тільки HTTPS джерела зі списку, перевіряються також перенаправлення. Маніфест не може передавати команди, JVM-прапорці чи довільні шляхи. Спроби traversal, Windows ADS, дублікати регістру, симлінки, прострочений підпис та відкат уже прийнятої версії відхиляються. Встановлення виконується в новій папці з можливістю відновлення після переривання. Один процес утримує блокування на весь час роботи гри.

Forge installer додатково закріплений SHA-256 у коді. Java 17 і Minecraft встановлюються з офіційних джерел Mojang, бібліотеки — з офіційних Maven; бібліотека встановлення перевіряє їхні контрольні суми за офіційними метаданими. Користувач не повинен сам ставити Java. Оновлення самого EXE не виконується приховано: нову версію лаунчера встановлюють окремо.

Автоматичний вхід і клієнтський мод обмежують звичайний інтерфейс цим сервером. Мод перехоплює початок з’єднання до інших адрес та прибирає меню інших серверів/світів. Це обмеження нашого клієнта, а не захист від власника ПК, який змінює JAR або пише інший лаунчер. Воно також не забороняє іншим клієнтам заходити на сервер. Паролі/контроль доступу сервера залишаються відповідальністю серверної авторизації. Не послаблюй античит заради профілів.

## Оновлення для адміністратора

Початковий пакет містить останні погоджені зміни TFC з PR #136. Усі файли беруться з точного commit, серверні JAR і секрети не пакуються. До злиття каналу в main лаунчер може використати вбудований підписаний bootstrap. Якщо з’єднання з GitHub відсутнє, береться кешований канал; підписи і строк дії все одно перевіряються. Підроблений отриманий канал не замінюється мовчки кешем.

Для майбутніх автоматичних релізів потрібен **один** repository secret `LAUNCHER_SIGNING_KEY` з приватним ключем, створеним поза репозиторієм. Сам ключ у git і збірки не входить. Власник додає його через Settings → Secrets and variables → Actions. Не генеруй новий ключ замість поточного: вбудований trust root перестане збігатися.

Workflow `launcher-channel.yml` на main формує новий канал після змін mods/config/defaultconfigs/kubejs/native client і підписує точні Git blobs. Він не використовує секрети на PR, не запускає команди з маніфесту і не встановлює нічого на сервер. Після першого злиття запусти workflow вручну; потім оновлюй канал щонайменше раз на 180 днів. Перевіряй зміни виконуваних модів до підписання. Обмеж write-доступ до main і workflow та ввімкни 2FA.

## Розробка і перевірка

Python 3.12 з Tk: `python -m pip install -r launcher/requirements-build.txt`, далі `python launcher/run.py`. Тести: `python -m pytest launcher/tests -q`. Пакування: `python launcher/tools/package.py --build`. `python launcher/run.py --diagnostics` працює без графічного інтерфейсу.

CI збирає окремі Windows/Linux архіви, перевіряє справжні віджети Tk та встановлює Java17/Forge у порожню папку. Нативний клієнт зібраний Java17 проти справжнього Forge/Minecraft SDK, без підставних API; `native/build.py` документує ремап SRG. Свіже встановлення всього модпаку та вхід двох гравців на бойовий сервер потребують окремого приймального тесту; результати CI цього не замінюють.

Oculus береться з офіційного [релізу 1.8.0](https://modrinth.com/mod/oculus/version/iQ1SwGc3), LGPL-3.0. Усі моди зберігають свої ліцензії; лаунчер не перелiцензовує збірку. Джерела лаунчера і власного клієнтського моду — MIT. Minecraft і Forge завантажуються окремо, не включені в EXE.
