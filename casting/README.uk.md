# Ливарний стіл Empirecraft

Новий блок `empirecraft_casting:casting_table` автоматично перетворює **готовий розплав із тигля TFC** на холодні злитки, які складаються до **64**. Він використовує наявні рецепти лиття та результати збірки: мідь/залізо/золото Minecraft, олово Antique Legacy, бронзу Create Big Cannons, цинк/латунь Create, сталь Overgeared, срібло Epic Knights і решту злитків TFC.

## Використання

1. Постав стіл впритул до будь-якого горизонтального боку тигля, на тій самій висоті. Жолоб автоматично повертається до тигля; якщо поруч кілька тиглів, стіл використовує той, куди спрямований жолоб.
2. Відкрий стіл ПКМ. У лівий слот встав випалену форму злитка TFC: звичайну або вогнетривку. У кріпленні вона багаторазова й не ламається. Форми інструментів не підходять.
3. Забери ручну форму з вихідного слота самого тигля, щоб вона не відбирала частину розплаву. Приготуй метал чи сплав у тиглі та нагрій вище його температури плавлення. Стіл не плавить руду й не змінює рецептуру сплавів.
4. Коли достатньо металу для рецепта, стіл забере одну повну порцію — зазвичай **100 одиниць**. Охолодження й автоматичне виймання тривають **40 тіків, тобто 2 секунди при 20 TPS**. Перевірка нової порції виконується раз на чотири тіки.
5. Злитки з’являються у правому слоті. Їх можна виймати вручну, лійкою знизу або засобами Create збоку. Вставляти форму автоматично можна згори; виймати її — вручну. Труби, додаткове паливо, вода та обертання для самого стола не потрібні.

Порожній тигель, холодний метал, брак повної порції чи заповнений/несумісний вихід зупиняють новий розлив без витрати металу. Щоб перейти на інший метал, звільни вихід і перевір, що форма порожня або містить такий самий метал. Частково заповнена форма використовує лише відсутню кількість.

Метал під час циклу зберігається **у справжньому предметі форми**. Виймання форми або ламання стола зберігає її вміст. Збереження/завантаження чанка відновлює поточний цикл; поза завантаженими чанками стіл не працює й не завантажує сусідні чанки самостійно.

## Складний рецепт

```text
Латунний лист     Механічний прес     Латунний лист
Сталь            Лійка               Сталь
Вогнетривка      Андезитовий корпус   Вогнетривка
цегла (блок)                         цегла (блок)
```

Потрібні **2 латунні листи Create**, **1 механічний прес Create**, **2 злитки сталі Overgeared**, **1 ванільна лійка**, **2 блоки вогнетривкої цегли TFC** та **1 андезитовий корпус Create**. Усі компоненти витрачаються. Форму вставляють окремо. Рецепт доступний у JEI; із наявним тиглем у інвентарі відкривається і звичайний рецепт Minecraft.

До книги Empirecraft автоматично додається стаття «Ливарний стіл» у розділі металів. JAR книги не замінюється, тому попередні виправлення довідника зберігаються.

## Встановлення

Зупини гру й сервер, розпакуй `dist/Empirecraft-Automatic-Casting-1-install.zip` в окрему папку та запусти Python 3.11+:

```text
python update_installation.py --client "/шлях/до/клієнта" --server "/шлях/до/сервера"
```

Можна передати один бік окремо. Потрібен однаковий `empirecraft-casting-1.0.0.jar` на клієнті та сервері, TFC 3.2.30 і чинна Empirecraft TFC Integration 1.0.3+. Оновлювач додає тільки новий мод, зберігає резервні копії замінених власних файлів у `.empirecraft-backups/automatic-casting-1` та додає його запис у наявний серверний ADM, підтримуючи JSON і текстовий формат. Решта модів, конфігурація світу й дані гравців не замінюються. Після встановлення перезапусти обидва боки.

## Відтворення перевірок

Компіляція використовує справжні встановлені Forge/TFC API й SDK mappings 1.20.1. Compile-only access JAR повторює три офіційні Forge access transformers; Minecraft класи до моду не пакуються.

```text
python casting/build.py --reference-repo /шлях/до/повного/checkout --sdk /шлях/до/toolchain --jdk /шлях/до/jdk17
python casting/run_native.py --work /шлях/до/нового/тесту --reference-repo /шлях/до/повного/checkout --sdk /шлях/до/toolchain --jdk /шлях/до/jdk17 --fixture /шлях/до/generated-runtime
```

Тестовий Mohist запускається Java 21 (`/usr/bin/java`); для компіляції використовується JDK 17. Runtime мусить бути згенерованою тестовою копією з маркером `TFC-INTEGRATION-TEST-ONLY`, а не ігровим світом хостингу. Результати — у `audit/` та `verification.json` пакета. Тести не додаються до ігрової збірки. Графічний клієнт і продукційний світ не запускаються.
