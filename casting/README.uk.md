# Лиття, ковка й температура Empirecraft

Новий блок `empirecraft_casting:casting_table` автоматично перетворює **готовий розплав із тигля TFC** на холодні злитки, які складаються до **64**. Він використовує наявні рецепти лиття та результати збірки: мідь/залізо/золото Minecraft, олово Antique Legacy, бронзу Create Big Cannons, цинк/латунь Create, сталь Overgeared, срібло Epic Knights і решту дозволених злитків TFC.

## Використання

1. Постав стіл впритул до будь-якого горизонтального боку тигля, на тій самій висоті. Жолоб автоматично повертається до тигля; якщо поруч кілька тиглів, стіл використовує той, куди спрямований жолоб.
2. Відкрий стіл ПКМ. У лівий слот встав випалену форму злитка TFC: звичайну або вогнетривку. У кріпленні вона багаторазова й не ламається. Форми інструментів не підходять.
3. Забери ручну форму з вихідного слота самого тигля, щоб вона не відбирала частину розплаву. Приготуй метал чи сплав у тиглі та нагрій вище його температури плавлення. Стіл не плавить руду й не змінює рецептуру сплавів.
4. Коли достатньо металу для рецепта, стіл забере одну повну порцію — зазвичай **100 одиниць**. Охолодження й автоматичне виймання тривають **40 тіків, тобто 2 секунди при 20 TPS**. Перевірка нової порції виконується раз на чотири тіки.
5. Злитки з’являються у правому слоті. Їх можна виймати вручну, лійкою знизу або засобами Create збоку. Вставляти форму автоматично можна згори; виймати її — вручну. Труби, додаткове паливо, вода та обертання для самого стола не потрібні.

Порожній тигель, холодний метал, брак повної порції чи заповнений/несумісний вихід зупиняють новий розлив без витрати металу. Щоб перейти на інший метал, звільни вихід і перевір, що форма порожня або містить такий самий метал. Частково заповнена форма використовує лише відсутню кількість.

Метал під час циклу зберігається **у справжньому предметі форми**. Виймання форми або ламання стола зберігає її вміст. Збереження/завантаження чанка відновлює поточний цикл; поза завантаженими чанками стіл не працює й не завантажує сусідні чанки самостійно.

## Складний рецепт

```text
Латунний лист     Механічний прес     Латунний лист
Сталь            Лійка               Сталь
Вогнетривка      Андезитовий корпус   Вогнетривка
цегла (блок)                         цегла (блок)
```

Потрібні **2 латунні листи Create**, **1 механічний прес Create**, **2 злитки сталі Overgeared**, **1 ванільна лійка**, **2 блоки вогнетривкої цегли TFC** та **1 андезитовий корпус Create**. Усі компоненти витрачаються. Форму вставляють окремо. Рецепт доступний у JEI; із наявним тиглем у інвентарі відкривається і звичайний рецепт Minecraft.

До книги Empirecraft автоматично додається стаття «Ливарний стіл» у розділі металів. JAR книги не замінюється, тому попередні виправлення довідника зберігаються.

## Металургія 1.2.0

Тигель приймає предмети з ванільної лійки зверху та воронок Create збоку. Збоку можна забирати лише його вихідний слот; руда із вхідних слотів не витягується назад. Кожний вхід і далі містить один предмет, щоб плавлення не видаляло цілі стаки за одну порцію.

У ковальському горні TFC кожний паливний слот вміщує **16 одиниць деревного вугілля**. Горіння витрачає одну одиницю за раз, зокрема під час розрахунку пропущеного часу. Доменна піч має **16 порцій руди, флюсу та палива на рівень димаря**, зі звичною вогнетривкою ізоляцією та листовим обшиттям.

Фурми доступні через ковку **чотирьох гарячих злитків** відповідного металу. Нові головки, вістря та леза куйте на ковадлі Overgeared: нагрійте звичайні злитки в горні TFC, підготуйте креслення відповідного типу деталі й вставте його в слот креслення. Для фурми та доведення сталі креслення не потрібне; звільніть його слот.

Додано 68 рецептів деталей і фурм із дозволених інструментальних матеріалів, включно з вістрями для золотих та срібних списів Epic Knights. Креслення мають окремі типи деталей, щоб однаковий злиток не вибирав випадково іншу головку. Складання 60 інструментів TFC і 40 видів древкової зброї Epic Knights зберігає `ForgingQuality`; серед кількох деталей із якістю береться найнижча. Для списів Harnham, Kingston та Boar кількість сталевих кріплень відрізняється, щоб кожний рецепт вибирав потрібний спис. Золоті й срібні вістря можна переплавити назад без втрати металу.

### Сталь

1. Доменна піч виготовляється **до першої сталі**: 4 блоки вогнетривкої цегли TFC, 2 злитки заліза, 2 злитки бронзи CBC та тигель. Схема: `FIF / BCB / FIF`.
2. Сире залізо з флюсом і паливом у сформованій доменній печі дає рідкий чавун. Потрібні фурма, наддув і достатній жар.
3. Відлийте чавун у злиток. Нагрійте його щонайменше до **900 °C** і викуйте високовуглецеву сталь.
4. Нагріту високовуглецеву сталь можна довести ковкою до звичайної сталі Overgeared. При **1540 °C** її плавлення дає власну рідку високовуглецеву сталь.
5. Початковий рецепт Overgeared «залізо + вугілля → сира сталь» і пов’язаний обхідний ланцюжок прибрано. Перепакування наявної сталі в блоки/самородки та назад залишено.

### Чорна сталь

1. Отримайте слабку сталь у тиглі: **50–70% сталі, 15–25% нікелю, 15–25% звичайної бронзи**. Приклад: **600 / 200 / 200 одиниць**.
2. Спочатку відлийте її у злитки. Потім переплавте їх окремо з чавуном у співвідношенні **50% слабкої сталі / 50% чавуну**. Це важливо: склад початкової суміші у тиглі ще не є окремим компонентом слабкої сталі.
3. Отриману високовуглецеву чорну сталь відлийте, нагрійте від **900 °C** та доведіть ковкою до чорної сталі.

Темна бронза, червона та воронена (`blue_steel`) сталь, включно з їхніми проміжними формами, вилучені з нових рецептів і JEI. Старі ID збережено для сумісності зі світом. Чорна сталь (`black_steel`) залишається доступною. Книга отримує нову докладну статтю; старі статті вилучених сплавів приховані.

## Температура та щипці 1.2.0

Окремі гарячі злитки Overgeared замінено звичайними предметами з реальною температурою TFC. Печі нагрівають готовий метал, а ковадло перевіряє робочу температуру кожного металевого компонента. Наприклад, для міді потрібно 648 °C, для заліза — 921 °C. Вимога відображається в інгредієнті JEI. Зберігаються охолодження, передавання температури, запис у світ і синхронізація TFC.

Предмети від **80 °C** в інвентарі, руках або на курсорі обпікають на **1 HP щосекунди**. Щипці Overgeared потрібно **тримати в будь-якій руці**; вони витрачають 1 міцність раз на 2 секунди роботи. Зламані щипці не захищають. Вогнестійкість і творчий режим запобігають опікам.

Кинутий у воду предмет охолоджується за один ігровий тік. Не змінюються кількість, назва, зачарування чи якість. Гарячі результати ковки й складання інструментів зберігають температуру. Старі гарячі злитки автоматично переходять на нову систему, коли потрапляють до інвентаря або стають викинутими предметами.

## Аркебуза та заряди

- Заготовка ствола: 2 нагріті залізні злитки + 1 лист заліза Create на ковадлі. Пилка Create обробляє її в ствол.
- Ґнотовий замок: 2 залізні самородки, лист заліза, нитка й палиця на ковадлі.
- Аркебуза: ствол, замок, ще один лист заліза й дерев’яне ложе TFC Muskets на ковадлі. Якість визначає мінігра.
- Боєприпаси: **2 кулі TFC Muskets + щіпка пороху + папір → 4 заряди `medieval_boomsticks:round_ball`**. Вони використовують чинну обробку куль та коштують менше за мушкетні патрони в розрахунку на один постріл.

Мушкет зберігає дорогий маршрут зі сталевими заготовками. Нові рецепти та поводження з гарячими речами описані також у книзі збірки.

## Встановлення

Зупини гру й сервер, розпакуй `dist/Empirecraft-Heat-and-Arquebus-3-install.zip` в окрему папку та запусти Python 3.11+:

```text
python update_installation.py --client "/шлях/до/клієнта" --server "/шлях/до/сервера"
```

Можна передати один бік окремо. Потрібен однаковий `empirecraft-casting-1.2.0.jar` на клієнті та сервері, TFC 3.2.30 і чинна Empirecraft TFC Integration 1.0.3+. Оновлювач встановлює нову версію ливарного моду та узгоджені скрипти KubeJS (рецепти ковки й приховування вилучених металів), зберігає резервні копії замінених власних файлів у `.empirecraft-backups/automatic-casting-1` та додає його запис у наявний серверний ADM, підтримуючи JSON і текстовий формат. Решта модів, конфігурація світу й дані гравців не замінюються. Після встановлення перезапусти обидва боки.

## Відтворення перевірок

Компіляція використовує справжні встановлені Forge/TFC API й SDK mappings 1.20.1. Compile-only access JAR повторює три офіційні Forge access transformers; Minecraft класи до моду не пакуються.

```text
python casting/build.py --reference-repo /шлях/до/повного/checkout --sdk /шлях/до/toolchain --jdk /шлях/до/jdk17
python casting/run_native.py --work /шлях/до/нового/тесту --reference-repo /шлях/до/повного/checkout --sdk /шлях/до/toolchain --jdk /шлях/до/jdk17 --fixture /шлях/до/generated-runtime
```

Тестовий Mohist запускається Java 21 (`/usr/bin/java`); для компіляції використовується JDK 17. Runtime мусить бути згенерованою тестовою копією з маркером `TFC-INTEGRATION-TEST-ONLY`, а не ігровим світом хостингу. Результати — у `audit/` та `verification.json` пакета. Тести не додаються до ігрової збірки. Графічний клієнт і продукційний світ не запускаються.
