# Виправлення запуску: Calendar 1.1.1 + World Rules 1.0.2

Calendar 1.1.0 помилково дозволяв лише World Rules 1.0.1. Після встановлення World Rules 1.0.2 Forge припиняв запуск із `Unsupported installed optional dependencies`.

Calendar 1.1.1 підтримує перевірені World Rules 1.0.1 і 1.0.2. World Rules залишається необов'язковим на клієнтах. Збережено зміни для Multiverse `world_europe`, 48-хвилинну добу, реальний час і сигнал міської провізії. NBT-прив'язка календаря не скидається.

1. Зупиніть сервер і клієнти.
2. Видаліть старі `empirecraft-calendar-1.1.0.jar` (або 1.0.0) та однойменні `.sha256` із `mods` сервера й кожного клієнта. Залиште World Rules 1.0.2 на сервері.
3. Із цього ZIP скопіюйте вміст `server` у корінь сервера, `client` — у корінь кожної клієнтської збірки. Має залишитися один Calendar JAR 1.1.1 з однаковим хешем на обох сторонах.
4. Оновіть запис календаря в чинному списку ADM. Із каталогу розпакованого ZIP, Python 3.11+:

   ```sh
   python3 tools/update_calendar_adm.py --id-file /path/to/server/config/admanticheat/idfile/admanticheat_id_list.json --jar server/mods/empirecraft-calendar-1.1.1.jar
   ```

   У Windows використовуйте `py` замість `python3` і свій шлях до сервера. Скрипт зберігає інші записи та налаштування й перераховує цілісність списку. Якщо ваш список ADM точно відповідає репозиторію, можна замінити його готовим `reference/admanticheat_id_list.json`. Не замінюйте власний змінений список довідковим файлом.
5. Запустіть сервер і клієнти. Перевірте `/calendar` та зміну сезонів у `world_europe`.

Конфіги, світи, бази міст і World Rules JAR цей мінімальний пакет не містить. Їх не потрібно замінювати. Оновлення календаря обов'язкове і на клієнтах через його нову версію та хеш у ADM.

Автоматично перевірено старий конфлікт діапазонів і виправлену пару через Maven version ranges, які використовує Forge; справжні Mixin-трансформації World Rules 1.0.2, Mohist і Serene Seasons у SERVER/CLIENT середовищах; часову математику й NBT; однакові JAR, метадані та цілісність ADM. Повний запуск живого Mohist-світу тут не виконувався.
