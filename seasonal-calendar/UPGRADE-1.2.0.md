# Календар 1.2.0: роки й адміністративна зміна дати

Зупиніть сервер і клієнти. Збережіть резервну копію світів. Замініть попередній
`empirecraft-calendar-*.jar` та його `.sha256` на **empirecraft-calendar-1.2.0.jar**
на обох сторонах. Serene Seasons та World Rules залишаються встановленими.
На сервері також замініть попередній Fauna на вкладений **Fauna 1.1.0**:
це сумісна з Calendar 1.2.0 версія із сезонною появою тварин поблизу гравців. Збережені тварини й власна конфігурація
Fauna залишаються на місці; старий JAR і його `.sha256` приберіть.
Скопіюйте вкладений мовний пакет у клієнтський `resourcepacks` замість попередньої
копії цього пакета. Для незміненої збірки використайте еталонний ADM з `reference/`.
Для власного списку ADM виконайте з каталогу розпакованого пакета:

```sh
python3 tools/update_calendar_adm.py --id-file /path/to/server/config/admanticheat/idfile/admanticheat_id_list.json --jar server/mods/empirecraft-calendar-1.2.0.jar --resource-pack client/resourcepacks/Empirecraft-Translations-uk-ru-1.1.0.zip
```

Скрипт оновлює Calendar і вкладений мовний пакет, зберігаючи інші записи.
Повністю перезапустіть гру й сервер.

У календарі, повідомленні входу та `/calendar` / `/календар` тепер видно рік.
Новий світ починає відлік із року **1**. Під час оновлення стара дата, сонячний
час і UTC-прив’язка зберігаються; для старої прив’язки базовим роком стає 1.
Рік зростає при переході з 30 Студня до 1 Просинця; перехід із лютого до
березня не збільшує рік. Доба й надалі триває 48 реальних хвилин,
місяць — 24 реальні години, рік — 12 реальних діб.

Оператор із рівнем доступу **2+** або консоль може виконувати:

```text
/calendar set day 15
/calendar set month 8
/calendar set year 1420
/calendar set time 12:30
/calendar set time 6000
/calendar set date 15 8 1420
/calendar set date 15 8 1420 12:30
```

День: 1–30; місяць: 1–12; рік: додатне ціле число. Час задається у форматі
`HH:mm` (00:00–23:59) або в сонячних тіках Minecraft (0–23999).
Префікс `/календар` підтримує ті самі підкоманди. Гравці без адміністративних
прав можуть переглядати дату. Неправильні аргументи відхиляються без часткової зміни.

Команди діють на календар поточного світу; у вимірі без власного сезонного
календаря використовується основний світ. Ручна зміна одразу зберігає нову
прив’язку: синхронізація продовжує відлік від установленої дати й часу,
враховує простій і перезапуск. Вона не повертає попереднє значення.
`doDaylightCycle` та `doSeasonCycle` зберігають установлені адміністратором паузи.
Звичайні `/time set`, `/time add` і `/season set` продовжують працювати.

Дані років зберігаються у схемі 2 файла `data/empirecraft_calendar.dat`
усередині світу. Після оновлення відкат потребує узгодженої резервної копії
календаря й даних світу. Пакет не містить робочих світів або баз даних.
