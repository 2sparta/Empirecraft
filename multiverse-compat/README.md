# Вітер, риболовля та сезони у world_europe

Повний комплект із датапаком і налаштуваннями Serene Seasons: `dist/Empirecraft-World-Europe-Fix.zip`. Вміст `server/` скопіюйте в корінь сервера, а `client/` — у корінь кожної клієнтської збірки. Повністю перезапустіть сервер і клієнти. Причина та перевірка сезонів: [SEASONS.md](SEASONS.md).

Окремий серверний датапак для вітру й риболовлі: `server/world/datapacks/empirecraft-multiverse.zip`. Для сезонів потрібні також TOML-файли з повного комплекту.

## Причина

У серверному логу є `Preparing start region for dimension minecraft:world_europe`. Multiverse має для цього світу `environment: normal` та дозволяє погоду, але моди перевіряють ID виміру, а не назву його середовища.

- Sails 0.3.2 має стандартне правило вітру лише для `minecraft:overworld`. За відсутності відповідного правила `WindRuleRegistry` повертає `NO_WIND` із множником 0.
- Starcatcher **3.3.10** використовує групи `dimension_entry`. Пакет додає `minecraft:world_europe` до групи `overworld`, зберігаючи стандартні групи й решту властивостей риб. Старий пакет із визначеннями риб 2.x потрібно замінити.

Перевірено конфігурацію й лог із Empirecraft `d34070022a9924c381e16275c6d3df07689387f7`. Зміна `allow-weather` не додасть вимір до правил цих модів.

## Що робить пакет

- Додає правило Sails для `minecraft:world_europe` з такими самими параметрами вітру, як у звичайному Overworld; інтервал — 300 ігрових тактів.
- Додає Europe до таблиці груп вимірів Starcatcher 3.3 через окремий простір імен `empirecraft`, оскільки wdUtils 2.1 читає перший ресурс кожного стека. Визначення риб беруться з актуального мода.
- Зберігає біоми, час доби, погоду, сезони, висоту, рідину, шанси, складність, здобич та інші поля. Nether і End мають свої попередні обмеження.
- Не реєструє й не замінює сам вимір, не редагує `level.dat`, регіони світу, кораблі або прогрес гравців.

Це серверний пакет даних; JAR модів і контрольні суми ADM залишаються чинними.

## Встановлення датапака окремо

Скопіюйте `empirecraft-multiverse.zip` у **`server/world/datapacks/`** та повністю перезапустіть сервер. В архіві нічого розпаковувати не потрібно.

Основний світ у `server.properties` — `level-name=world`, тому глобальні датапаки сервер читає з папки `world`. Правило всередині пакета адресоване окремому виміру `minecraft:world_europe`.

У консолі `datapack list enabled` має показати `file/empirecraft-multiverse.zip`. Якщо пакет раніше вручну вимикали, увімкніть його командою `datapack enable "file/empirecraft-multiverse.zip"` та перезапустіть сервер. Після запуску дайте вітру до 300 тактів — приблизно 15 секунд за 20 TPS.

Вітрила мають бути розгорнуті, а якір піднятий. Вітер зберігає звичайні напрямок і силу; пакет не додає постійний двигун кораблю.

Для іншого додаткового світу внесіть його **точний ID виміру** в `config.json` і перезберіть пакет. У поточному логу `world_real` та `mine_4` не завантажилися через `WORLD_FOLDER_INVALID`, тому цей пакет адресовано підтвердженому робочому `world_europe`.

## Відтворення та перевірки

```sh
python multiverse-compat/build.py
python multiverse-compat/test.py --starcatcher multiverse-compat/build/starcatcher-3.3.10-FORGE-1.20.1.jar --sails multiverse-compat/build/vs_sails-1.20.1-0.3.2-forge.jar
```

Генератор завантажує тільки зафіксовані JSON-шаблони всередині оригінальних модів, перевіряє SHA-256 та створює детермінований ZIP. Бінарні класи модів до пакета не потрапляють. Повторна збірка дає той самий файл.

Статична перевірка порівнює групи з оригінальними даними Starcatcher 3.3, перевіряє незмінність правил вітру, відсутність старих визначень риб, відхилення неправильних псевдонімів і побайтове відтворення архіву.

Історична перевірка вітру й Starcatcher 2.x збережена у `../validation/multiverse-world-europe.json`. Актуальний тест `../civic-events/tests/CivicSmoke.java` завантажує справжній Starcatcher 3.3 і цей датапак у тимчасовому світі `world_europe`: перевіряє доступність Overworld-риби в обох світах і заборону в Nether. Результати — у `../validation/civic-events-1.0.0.json`.

Для видалення виправлення приберіть ZIP на зупиненому сервері. Після перезапуску відновляться початкові правила вітру й вимірів риболовлі.
