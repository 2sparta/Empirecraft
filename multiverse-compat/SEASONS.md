# Serene Seasons у world_europe

У Serene Seasons 9.1.0.3 серверна й клієнтська конфігурації містили лише `minecraft:overworld` у `dimension_settings.whitelisted_dimensions`. Multiverse завантажує Europe під окремим ID `minecraft:world_europe`.

Установлений календар Empirecraft 1.1.0 також перевіряє цей список перед ініціалізацією годинника. Тому виключення світу вимикало сезонні ефекти й відлік календаря для Europe.

Виправлено обидва файли:

- `server/config/sereneseasons/seasons.toml` — серверна копія.
- `config/sereneseasons/seasons.toml` — конфігурація клієнтської збірки.

Єдина зміна значення:

```toml
[dimension_settings]
whitelisted_dimensions = ["minecraft:overworld", "minecraft:world_europe"]
```

Тривалість доби `57600`, місяця `30`, ріст культур, сніг, погода та сезонні кольори збережені. Nether і End не додавалися до сезонних світів. Файли даних світу й збережені прив'язки календаря не редагувалися.

## Встановлення

Готовий повний комплект: `dist/Empirecraft-World-Europe-Fix.zip`.

1. На зупиненому сервері скопіюйте вміст `server/` у корінь сервера.
2. Скопіюйте вміст `client/` у корінь кожної клієнтської збірки.
3. Повністю перезапустіть сервер і клієнти. Це також повторно ініціалізує календар для завантаженого Multiverse-світу.

Архів уже містить попередній датапак вітру та Starcatcher для Europe. Встановлені JAR і ADM залишаються чинними. Модульні налаштування Serene Seasons не застосовуються простим копіюванням лише датапака.

Перевірте дату командами `/calendar` або `/календар` у `world_europe`. Якщо адміністратор вимкнув `doSeasonCycle`, календар залишиться призупиненим відповідно до цього правила; виправлення не переписує gamerules.

## Перевірка

Завантажені точні серверні JAR Serene Seasons 9.1.0.3, GlitchCore 0.0.1.1 та Empirecraft Calendar 1.1.0. У тестовому Forge 47.4.23 використано окремий вимір із тим самим ID Europe. Початкова конфігурація відтворила виключення світу — 10 перевірок. Виправлена дозволила його, запустила годинник Empirecraft і забезпечила приріст фактичного сезонного лічильника — 15 перевірок. Обидва приймальні запуски завершилися з кодом 0 та збереженням усіх вимірів.

Тестовий мод `tests/SeasonsSmokeMod.java` сам зупиняє сервер; використовувати його можна лише в ізольованому тестовому середовищі. Результати: `../validation/seasons-world-europe.json`.

Графічне відображення на клієнті та повний стек Mohist/Multiverse у цьому тесті не запускалися. Конфігурації клієнта й сервера збігаються за всіма значеннями.

Для відтворення інсталяційного архіву:

```sh
python multiverse-compat/package.py
```
