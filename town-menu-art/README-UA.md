# Іконки міста Empirecraft 1.1.0

Нові **предметні значки саме в комірках `/t menu` та `/t provision`**, включно з нижніми кнопками договорів, наймання рекрутів і гарнізону. Стандартне вікно скрині зберігається.

46 окремих іконок у стилі латуні та темної зелені: місто, жителі, територія, скарбниця, щит васалів, договір, унії, корона, династія, пропозиції, хліб, історія, стрілки, оновлення, закриття, сховище, запас, голод, рекрути та інші дії. Предмети мають власні стабільні ID і моделі; OptiFine, CIT, зовнішній ресурс-пак і збіг за назвами не потрібні. Старий екранний мод 1.0.0 більше не використовується.

**Назви предметних іконок — українські. Мова меню за замовчуванням — українська**, незалежно від мови команд. Раніше збережений окремий вибір мови меню зберігається. Для української в такому випадку: `/language menus uk`. Назви міст, імена гравців та авторський текст не перекладаються.

## Установлення

Minecraft **1.20.1**, Forge **47.4.23**, актуальний EmpirecraftFeudal **1.20.2**. Закрий клієнт і зупини сервер. Розпакуй `Empirecraft-Town-Icons-1.1.0-install.zip` у окрему папку. Оновлювач потребує Python 3.11+:

```text
python update_installation.py --client "/шлях/до/клієнта" --server "/шлях/до/сервера"
```

Оновлювач перевіряє обидві сторони до запису, замінює попередній мод за його ID, резервує файли в `.empirecraft-backups/town-icons-1.1` та оновлює лише запис нового мода в чинному ADM-списку. Невідому збірку плагіна не переписує. Налаштування, база Feudal, світи та сторонні записи ADM зберігаються.

Для ручного встановлення:

1. **На клієнті й сервері:** установи однаковий `mods/empirecraft-menu-art-1.1.0.jar`. Старий `empirecraft-menu-art-1.0.0.jar`, якщо він є, прибери. Новий мод реєструє предмети, тому потрібен на обох сторонах.
2. **На сервері:** заміни `plugins/empirecraft-feudal-1.20.2.jar` на `plugins/empirecraft-feudal-1.20.3.jar`. Залиш одну версію плагіна.
3. Якщо встановлював вручну, запусти оновлювач з `--server`, щоб узгодити контрольну суму клієнтського мода в ADM.
4. Повністю перезапусти клієнт і сервер.

## Що змінюється

Кожний значок — справжній предмет `empirecraft_menu_art:...` з власною PNG-текстурою 32 × 32 і штатною моделлю `minecraft:item/generated`. Глобальні текстури Minecraft, шрифти, масштаб і геометрія вікна скрині не замінюються. Прототипи торгових операцій, їжа у сховищі, її кількість, дані й поживність зберігаються. Службові значки не мають рецептів і вкладки творчого інвентарю та приховані з JEI.

Кнопки рекрутів, додані іншими обробниками відкриття меню, отримують новий тип предмета **зі збереженням назви, підказки та PersistentDataContainer для натискання**. Дії, права й транзакції не змінюються. Відсутній мод на сервері дає явне повідомлення у журналі та тимчасовий звичайний значок.

## Перевірка в грі

Відкрий `/t menu`: перевір усі значки з головної сторінки, обидві кнопки рекрутів, договори, вкладені сторінки й стрілки сторінок. У `/t provision` перевір чотири інформаційні елементи та внесення/вилучення їжі ЛКМ і ПКМ. Перевір українські підказки й звичайну скриню. Файли `preview.png` та `icons.png` показують готові текстури; це ілюстрації розкладки, не знімки запущеного клієнта.

Повний графічний клієнт під час цього випуску не запускався. Автоматично перевіряються моделі й текстури всіх 46 предметів, відповідність ID, реальні сигнатури Forge/JEI, збереження даних кнопок рекрутів, мови, операції провізії й безпечне встановлення.

## Повторна збірка

Потрібні checkout зі справжніми бібліотеками сервера, поточним JEI та закріпленим Feudal 1.20.2 у `native-inputs/`, Python 3.11+ з Pillow, JDK 21 для компілятора та JDK 17 для цільової платформи:

```text
python town-menu-art/generate_items.py
python town-menu-art/build.py --jdk17 /шлях/до/jdk17
python town-menu-art/release.py
python town-menu-art/test.py
```

Джерело ID й назв — `icons.json`; вхідні артефакти — `inputs-1.1.json`; результати — `audit/`. Клієнтського SDK чи ремапера для цього мода не потрібно: байткод використовує справжні SRG-сигнатури встановленого Forge. Історичні ZIP 1.0.0 та інструменти попереднього відновлення скрині збережено для відтворення старих випусків.
