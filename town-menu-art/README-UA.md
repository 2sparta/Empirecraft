# Empirecraft Town Hall 1.0.0

Оформлення `/t menu` і `/t provision` для **Minecraft 1.20.1, Forge 47.4.23** та наявного Towny / EmpirecraftFeudal.

44 оригінальні іконки, темно-зелена панель, латунна рамка, пергаментні заголовки й підсвічування при наведенні. Оформлення поширюється на вкладені сторінки TownMenu: жителів, землю, скарбницю, васалів, дипломатію, унії, державні рішення, династію, списки й підтвердження. На сторінці провізії оформлені чотири елементи панелі; 45 комірок із їжею та інвентар гравця зберігають рідні текстури й кількості.

## Установлення

Закрий клієнт і зупини сервер. Розпакуй **Empirecraft-Town-Hall-1.0.0-install.zip** у окрему папку. Оновлювач потребує Python 3.11+:

```text
python update_installation.py --client "/шлях/до/клієнта" --server "/шлях/до/сервера"
```

Можна оновлювати сторони окремо параметрами `--client` або `--server`. Оновлювач перевіряє файли перед записом, прибирає попередню версію за mod/plugin ID, зберігає резервні копії у `.empirecraft-backups/town-hall-1` і додає контрольну суму клієнтського мода у чинний серверний ADM-список. Сторонні записи, ресурс-паки, конфігурація, світи й база Feudal зберігаються.

Для ручного встановлення:

- **Клієнт:** додай `client/mods/empirecraft-menu-art-1.0.0.jar` у `mods/`. Зовнішній ресурс-пак, OptiFine чи CIT не потрібні.
- **Сервер:** заміни `plugins/empirecraft-feudal-1.19.3.jar` на `server/plugins/empirecraft-feudal-1.19.4.jar`. Одночасно має бути одна версія плагіна. Сам клієнтський мод на сервері не потрібен. За ввімкненої перевірки ADM додай новий мод через оновлювач із параметром `--server`.
- Повністю перезапусти обидві сторони.

Мод і серверне оновлення потрібні разом: плагін позначає елементи керування, а мод малює їх. Без мода ці самі кнопки залишаються звичайними предметами. Без оновленого плагіна клієнт показуватиме старе оформлення.

## Як перевірити у грі

Відкрий `/t menu`, наведи курсор на кнопки, пройди вкладені сторінки й повернися назад. Перевір пагінацію на довгому списку та підтвердження дій. У `/t provision` перевір показники запасу, оновлення, внесення їжі ЛКМ/ПКМ і вилучення з належними правами. Відкрий звичайну скриню: її оформлення має бути звичайним. За потреби перевір `/language menus en`, `uk`, `ru` і різні масштаби GUI.

`preview.png` — ілюстрація розкладки з текстур готового мода, не знімок запущеної гри. Автоматичні перевірки не замінюють перевірку рендерингу у графічному клієнті; повний графічний клієнт для цього випуску не запускався.

## Реалізація та збірка

Іконки визначаються парою `PublicBukkitValues["empirecraft:menu_skin"]` (`town/1` або `provision/1`) і `CustomModelData` 742100–742143. Назви й мова не беруть участі в розпізнаванні. Мод застосовує оформлення лише до шестирядного ChestMenu з відповідною кнопкою-якорем у комірці 53. Інвентар гравця не перемальовується. Vanilla item models, шрифти й глобальні текстури скринь не перевизначаються. Мод використовує штатні Forge render events, без mixin і мережевих пакетів.

Серверне оновлення змінює лише `TownMenu`, `ProvisionController`, їхні вкладені класи, додає `MenuSkin` і оновлює версію у `plugin.yml`. Решта записів базового Feudal 1.19.3 залишаються побайтово однаковими; логіка провізії, SQL, права, команди та вибір мови зберігаються.

З checkout з установленими серверними бібліотеками: Python 3.11+, Pillow, JDK 21 та JDK 17 для системних класів цільової платформи:

```text
python town-menu-art/generate_assets.py
python town-menu-art/build.py --jdk17 /шлях/до/jdk17
python town-menu-art/release.py
python town-menu-art/test.py
```

Джерела клієнтського мода використовують SRG-імена членів Minecraft 1.20.1 безпосередньо. Компілятор перевіряє їх за справжніми встановленими Forge/Mohist JAR, завантажувати Minecraft SDK чи ремапер не потрібно. Вхідні артефакти закріплено у `inputs.json`, протокол іконок — у `catalog.json`, результати перевірок — у `audit/`.
