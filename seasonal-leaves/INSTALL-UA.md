# Установлення 1.3.1

Це Forge-мод для Minecraft 1.20.1. Тепер потрібен на сервері та кожному клієнті.

1. Зупиніть сервер і гру. Збережіть резервну копію світу та старого конфігу.
2. На сервері приберіть попередній `empirecraft-seasonal-leaves-*.jar` і покладіть JAR із `server/mods/` у `mods/` сервера.
3. JAR із `client/mods/` покладіть у `mods/` кожного клієнта. Обидва JAR однакові. ZIP розпакуйте; не перейменовуйте його на JAR.
   Якщо в цих папках пакета також є `empirecraft-engagement-1.1.0.jar`, замініть ним однойменний файл на обох сторонах. Він виправляє залежність для Sails 18, а вкладений ADM уже містить його нову контрольну суму.
   Якщо пакет містить `empirecraft-pack-fixes` і `kubejs/`, скопіюйте їх також: вони забезпечують вбудовані переклади й виправлені теги інструментів та відповідають вкладеному ADM.
4. Serene Seasons 9.1.0.3 і GlitchCore 0.0.1.1 залиште на обох сторонах. Embeddium 0.3.31 необов'язковий. Calendar, Towny, Recruits та інші моди не замінюються.
5. Не видаляйте старий конфіг і дані крон/рослин. Новий розділ `[atmosphere]` додасться автоматично. Стан `/plantgrowth off` зберігається.
6. За наявності ADM потрібен запис `empirecraft_seasonal_leaves`, версія `1.3.1`, SHA-256 із `.jar.sha256`. Вкладений повний ADM-файл відповідає складу цієї гілки Empirecraft. Для іншого складу оновіть лише рядок цього моду звичайним механізмом ADM.
7. Повністю перезапустіть клієнт і сервер.

Перевірка: `/season set mid_autumn` — неоднорідні крони; `/season set mid_winter`, `/weather rain`, `/seasonweather auto`, потім `/seasonweather status` — довгий зимовий період опадів. У помірному біомі має йти сніг; зимове небо й туман блідіші. Ніч лишається темною.

Пострибайте по кроні під час сезонного опадання: опора має залишитися; після відходу й наступного проходу листя знову може опадати. Рідкі/модові дерева підтримуються через стандартний тег листя або `additional_leaves`. Інструментальне ламання листя не блокується.

`/seasonweather status` і `/seasonweather auto` доступні адміністратору з рівнем прав 2. `/weather clear` і `doWeatherCycle=false` поважаються. Сезонні команди змінюють календар: тестуйте на копії світу або поверніть потрібний сезон.

Підтверджено автоматичними перевірками та чотирма запусками тимчасового Mohist. Повний графічний запуск вашої збірки ще потрібно перевірити. Файли опубліковано в окремій гілці без злиття в main.
