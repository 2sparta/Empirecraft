# Towny і Feudal на Forge

Серверний мод `empirecraft-towny-forge-0.6.0.jar` працює з Minecraft 1.20.1 і Forge 47.4.23. У чистому світі він сам створює `world/empirecraft/towny-state.json` та `world/empirecraft/feudal/feudal.mv.db`. Клієнтам залишається звичайна збірка Empirecraft. [Forge 47.4.23](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.20.1.html)

## Підготовка нового світу

Потрібні JDK 17 або 21, Python із PyYAML, бібліотеки Forge для збірки й моди чинного пакета. Для накладання інтеграції JourneyMap потрібен той самий Forge SDK із Tiny Remapper. H2 2.2.224 входить у зібраний JAR. [Вихідний код і ліцензія H2](https://github.com/h2database/h2database/tree/version-2.2.224)

```sh
curl -fL -o /tmp/h2-2.2.224.jar \
  https://repo.maven.apache.org/maven2/com/h2database/h2/2.2.224/h2-2.2.224.jar
python3 forge-migration/build.py \
  --h2 /tmp/h2-2.2.224.jar \
  --libraries /шлях/до/forge/libraries \
  --pack-mods /шлях/до/пакета/mods --sdk /шлях/до/forge-sdk --test
curl -fL -o work/forge-migration/serverlogin-1.0.3.jar \
  https://github.com/iwosw/server-login/releases/download/v1.0.3/serverlogin-1.0.3.jar
python3 forge-migration/migrate.py \
  --server /шлях/до/пакета --stage work/forge-migration/forge-fresh --fresh-world \
  --login-jar work/forge-migration/serverlogin-1.0.3.jar \
  --companion-jar work/forge-migration/empirecraft-forge-migration-0.1.0.jar \
  --forge-runtime /шлях/до/чистого/forge
python3 forge-migration/verify.py work/forge-migration/forge-fresh
python3 forge-migration/start.py work/forge-migration/forge-fresh
```

`--fresh-world` створює окрему копію збірки на `127.0.0.1:25629` із білим списком. Зі старої папки світу бере лише `datapacks` і `serverconfig`. Регіони, інвентарі, привати, економіка й логіни стартують порожніми. Можна також підставити підготовлену нову карту до першого запуску та згенерувати дані Towny й Feudal поверх неї. За потреби можна передати `--installer` з офіційним інсталятором Forge замість готового ядра. [Server Login 1.0.3](https://github.com/iwosw/server-login/releases/tag/v1.0.3)

## Команди

`/feudal` і `/town menu` відкривають клікабельне меню в чаті Minecraft. З нього можна перейти до окремих меню ринку, скарбниці, валюти, провізії та флоту. Кнопки перегляду одразу відкривають відповідний список. Кнопки, які потребують введення або підтвердження, підставляють команду в поле чату.

| Система | Початкова команда | Дії |
| --- | --- | --- |
| Towny | `/town new <назва>` | Створення міст і націй, привати, аванпости, ранги й ділянки. |
| Податки | `/towny taxcycle on` | Адміністратор запускає щоденний цикл. Ставки задаються через `/town set taxes`, `/nation set taxes` і `/town set plottax`. Адмін задає початковий баланс командою `/towny setbalance <resident\|town\|nation> <назва> <сума>`. |
| Договори | `/town treaty help`, `/town diplomacy help` | Проєкти, редакції, підписи, склад договірних ресурсів, вихід і дипломатичні угоди. |
| Державні справи | `/town state help`, `/town union help`, `/town dynasty help` | Статути, тип уряду, голосування за бюджет і рішення, вибори, унії та спадкоємці. |
| Скарбниці | `/treasury help`, `/currency help` | Міські й особисті рахунки Feudal, банкіри, видатки за рішенням ради, валюти та золотий резерв. Прогрес володіння й перевірка замку доступні через `/town state help` і `/town castle help`. |
| Ринки | `/market help` | Проєкти та перевірка будівель, купівля й продаж, золотовалютне забезпечення, обмін, аукціони, торгові договори, міські закупівлі, робота й дошка оголошень. |
| Провізія | `/provisions help` | Міські запаси, сезонне споживання, резерв на 24 години для розширення міста та харчування TownyRecruits. |
| Флот | `/fleet help`, `/shiprequest help`, `/shipadmin help` | Заявки на збирання, призначення міста-власника, адмірали, екіпаж, прапори, захист суден, продаж та аукціони. |

Договірні платежі та поставки виконуються в день розрахунку з доступного балансу чи запасу. Кредити, штрафи за прострочення й арешти прибрано. Звільнення привату чи нестача провізії не запускають руйнування блоків. Щоденні податки початково вимкнені, як у поточній конфігурації Empirecraft.

JourneyMap читає поточні межі, володіння й ієрархію Feudal. Claim Guard, Siegeworks і прохід ґрунтів TFC звертаються до Forge Towny. TownyRecruits зберігає облік людського ресурсу і використовує провізію рідного міста рекрута. Валюти Feudal і базові баланси податків Towny ведуть окремий облік.

У збірці Forge використовуються клікабельні команди. Формат інвентарних меню Bukkit потребує власного клієнтського інтерфейсу. Discord-розгляд, угоди про найм полків і рибальські торги через Contact залишаються окремими інтеграціями. Архів старої бази Feudal, який робить імпортер без `--fresh-world`, не підключається до нової економіки.

## Ярмарки й листівки Contact

На сервері мають бути Contact із чинної збірки та серверний міст JourneyMap із цього релізу. Звичайна пошта гравців залишається у скриньках Contact.

1. Підійдіть до стійки відкритого відділу ринку. `/market fair help` покаже команду створення. Час задається у форматі `YYYY-MM-DDTHH:mm` за Києвом. Ярмарок можна запланувати щонайменше за 24 години, на 2–72 години.
2. Запишіть запрошення через `/market fair letter edit <ID> <текст>` або `/market fair letter editbook <ID>`, тримаючи книгу з пером. Місце, час і збори додаються до тексту зі збережених умов.
3. `/market fair letter preview <ID>` видає листівку за один аркуш паперу. Прочитайте її й візьміть у головну руку. Команда показує кількість одержувачів і підставляє точну команду підтвердження з версією та токеном.
4. Підтвердьте розсилку. Для копій потрібно по аркушу на скриньку. `/market mail status [ID]` показує стан. Доставлені листівки можна забрати зі скриньки Contact після входу. Папір за скасовані чи недоступні адреси зараховується у `/market assets`.
5. Гравці бачать публічні події через `/market fair list`. Редагування чернетки змінює версію зразка. `/market fair cancel <ID>` зупиняє нерозіслані копії.

Черга працює партіями по вісім листівок. Повна або вивантажена скринька чекає повторної спроби без завантаження чанку. Квитанція Contact зберігається разом із листівкою, тому повтор запиту після перезапуску зберігає ту саму доставку.

## Перевірки

`build.py --test` перевіряє чисту ініціалізацію, права приватів і правила податків, підписання договорів, передплачені платежі та поставки, скарбниці, ринок, резерви рекрутів і дозволи екіпажу. `--native-probe` збирає тестовий мод для ізольованого сервера. Для порожнього світу додайте `-Dempirecraft.test.freshFeudal=true` та `-Dempirecraft.test.nativeBridges=true` до параметрів JVM. Проба створює місто і ринок, перевіряє Forge-інтеграції та зупиняє сервер. `-Dempirecraft.test.fairMail=true` додає відкриття ринку, підготовку ярмарку, створення і підтвердження зразка, доставку офлайн-одержувачу й повторного виконання черги. Для другого запуску того самого тестового світу використайте `-Dempirecraft.test.mailRestart=true` без `freshFeudal`.
