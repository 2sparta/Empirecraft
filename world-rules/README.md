# EmpireCraft World Rules 1.0.0

Серверний мод для поточної збірки: Minecraft 1.20.1, Mohist 71a84ff7, Forge 47.4.23, CombatLog **2.8.4**. На сервері потрібна Java 21 через Towny; JAR цього моду має Java 17 bytecode. Клієнтам установлювати його не потрібно.

## Що змінюється

- CombatLog більше не включає AIR і Supplementaries cannon у списки заборонених предметів/блоків. Порожні налаштування CombatLog 2.8.4 раніше помилково давали AIR. Час бойового режиму, заборони команд і покарання за вихід залишаються чинними. Патч не скасовує Towny-перевірки й не змінює дозволів на шкоду. Остаточну роботу гармати під бойовим тегом потрібно перевірити в грі.
- Усі `Enchantments` і `StoredEnchantments`, включно з прокляттями, очищаються під час доступу до ItemStack та збереження. Зачаровані книги стають звичайними. Старі предмети в інвентарях, сховищах, дропі та спорядженні мобів також очищаються при використанні/завантаженні. Немає обходу всіх чанків або зміни файлів світу офлайн. Назви, міцність, кількість та модові дані на кшталт якості Overgeared зберігаються.
- Вимкнені стіл зачарувань, `/enchant`, пряме зачарування ItemStack та нові ванільні пропозиції зачарованих книг у селян. Старі пропозиції можуть залишитися, але їхній результат стає звичайною книгою. Звичайний ремонт на ковадлі залишається.
- Ванільна зіллеварка не виконує серверний tick: старе варіння також не завершується. Звичайні ванільні зілля стають водою; вибухові й осідаючі — порожніми пляшками, стріли з ефектами — звичайними стрілами. `nirvana:potion_bong` стає звичайним бонгом. Модові напої не прирівнюються до ванільних зіль: їхні ефекти/витримка зберігаються.
- Рецепти столу зачарувань і зіллеварки вимкнені в datapack самого JAR. KubeJS додатково прибирає вихідні рецепти за типом предмета, зберігаючи стару заборону siege workbench. Для звичайного Nirvana bong додано рецепт: скляна пляшка + відро води + `nirvana:weed`; ванільна механіка повертає порожнє відро.

## Культури й сіль

Природні зміни працюють лише у світах із `worlds` у конфігурації, за доступного Towny і тільки в незапривачених чанках. За відсутності плагіна/API або помилки перевірки зміни зупиняються. Перевірки виконуються на головному потоці. Мод не завантажує й не генерує чанки.

За замовчуванням кожні 10 секунд перевіряється максимум один випадковий уже завантажений чанк на світ у радіусі двох чанків від випадкового онлайн-гравця. Для рослин також мають бути завантажені сусідні 3×3 чанки. Рослина займає тільки повітря над наявним природним ґрунтом: будівлі, інші рослини й грядки не замінюються. У чанку допускається до шести рослин із налаштованого переліку, успішна посадка — не частіше разу на 20 хвилин. Дерева автоматично не садяться.

Є 26 видів із Farmer's Delight, Farmer's Respite, Rustic Delight, Supplementaries, Nirvana, Vinery, Fruits Delight і Caupona. Для температурних груп перевіряється базова температура біому, а для всіх видів — рідний `canSurvive` моду. Група `wet` покладається на ці рідні правила, без окремого пошуку води. Рослини з особливим субстратом, зокрема дикий рис, можуть не пройти умови посадки; рис також є в торговому асортименті.

Сіль з'являється **лише замість блоків** `minecraft:lapis_ore` / `minecraft:deepslate_lapis_ore` у шахтах. Предмет `minecraft:lapis_lazuli` в інвентарі ніколи не перетворюється.

- За seed і координатами стабільно обирається приблизно 25% придатних чанків, а не нові 25% при кожному tick.
- У кожному такому чанку дозволене **одне перетворення за весь час**. Квота записується в SavedData світу та зберігається після звичайного перезапуску й зміни приватів.
- Діапазон за замовчуванням: Y −48…64, 256 випадкових перевірок за інтервал.
- Потрібно знайти щонайменше три сполучені гранями блоки лазуритової руди в завантаженій частині світу. Перетворення залишає щонайменше два; жили з одного-двох блоків не змінюються.
- Результат — `meadow:alpine_salt_ore`, із рідним дропом `meadow:alpine_salt`. Новий клієнтський блок не додається.

Для дерев, насіння, вапняку, олова та трьох руд Boomsticks додано ротаційні рідкісні пропозиції мандрівного торговця. Ціна — два смарагди, запас — чотири покупки. Саджанець/насіння видається по одному, вапняк — по 16, сира руда — по два. Потрібна звичайна поява мандрівних торговців (`doTraderSpawning`); мод не вмикає gamerule і не створює NPC примусово. Повний асортимент не з'являється в одного торговця одночасно.

## Установлення

1. Повністю зупиніть сервер і зробіть резервну копію світу та змінюваних конфігурацій. Очищені чари й замінені предмети не повернуться після видалення моду.
2. Скопіюйте `mods/empirecraft-world-rules-1.0.0.jar`, `config/empirecraft_world_rules-common.toml` і `kubejs/server_scripts/5_enchantments.js` із серверного ZIP у корінь сервера. Старий `5_enchantments.js` замінюється цілком: у ньому були непідтримувані події KubeJS.
3. У наявному `config/rusticdelight-common.toml` задайте `enable_potions = false`. У `config/vinery.toml` замініть `vinery:taiga_red_grape_seeds` → `vinery:taiga_grape_seeds_red`, `vinery:taiga_white_grape_seeds` → `vinery:taiga_grape_seeds_white`. У ZIP є `reference-configs` із повними виправленими версіями; використовуйте їх цілком лише якщо не маєте власних змін цих налаштувань.
4. У `worlds` нового конфіга вкажіть фактичні Bukkit-назви ігрових світів. За замовчуванням це `world` і `world_europe`.
5. Залиште встановленим `empirecraft-claim-guard-1.0.0.jar`: цей мод не замінює захист приватів від гармат/бомб. Повністю запустіть сервер; `/reload` не застосовує Mixin-патчі.
6. Виконайте ігрові перевірки з `validation/world-rules-1.0.0.md`. Базова збірка має 92 серверні JAR; після встановлення нового моду — 93. Клієнт і ADM-збірка не змінюються.

Стан відновлення зберігається в `data/empirecraft_natural_renewal.dat` відповідного виміру. Не видаляйте його для скидання кулдаунів: це також скине історію використаних сольових квот. Автоматичного відкату змін світу немає.

## Збирання й перевірки

```sh
python world-rules/build.py --classpath-dir server
python world-rules/test.py --classpath-dir server
python world-rules/check_assets.py server/mods
python world-rules/audit_resources.py server/mods
python world-rules/package.py
```

Потрібні JDK 17+ і повні встановлені бібліотеки Mohist/Forge. `--classpath-dir` можна передавати кілька разів. Компіляція без завантажень Gradle; збірка JAR детермінована. Звіт аудиту в репозиторії стосується 92 базових модів **до** додавання цього JAR.

Тести охоплюють політики ресурсів, реальний NBT, рефлексивний Towny API з тестовими плагінами та справжню Mixin-трансформацію чотирьох установлених класів. Вони не замінюють запуск повного Mohist із живим Towny. Версії CombatLog/Mohist/Forge не слід оновлювати без повторної перевірки патчів.
