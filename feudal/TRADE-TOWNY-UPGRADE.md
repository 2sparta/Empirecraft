# Trade та команди міста — 27.10.2026

У вікні `/trade` поряд із золотим самородком розміщено дві кнопки:

- **Валюта 1** — тип валюти поточної пропозиції. Наведення показує назву,
  код та баланс саме особистого гаманця. Натискання перебирає лише валюти,
  у яких гравець має монети. Кошти скарбниць та інших гравців не додаються.
- **Валюта 2** — валюта для порівняння. Наведення показує, скільки її можна
  купити за **1.00 монету валюти 1**. Натискання перемикає другу валюту.
  Це перегляд курсу; переказ не виконується. Розрахунок використовує чинні
  золоті резерви, обіг та округлення `/exchange`. Якщо обмін недоступний,
  кнопка показує причину.

Зміна валюти 1 обнуляє запропоновану суму та скидає готовність обох учасників.
Перемикання валюти 2 не змінює їхніх пропозицій або підтверджень. Коли монет
немає, обмін предметами залишається доступним. Після вибору предметів та
суми обидві сторони фіксують пропозиції, чекають 3 секунди й підтверджують.

## Команди міста

Команди використовують власний диспетчер Towny. `/town` працює так само,
як `/t`, включно з аргументами та автодоповненням.

| Було | Тепер |
| --- | --- |
| `/state` | `/t state` |
| `/vassal` | `/t vassal` |
| `/fief` | `/t fief` |
| `/castle` | `/t castle` |
| `/union` | `/t union` |
| `/confed` | `/t confed` |
| `/federation` | `/t federation` |
| `/title` | `/t title` |
| `/diplomacy` | `/t diplomacy` |
| `/dynasty` | `/t dynasty` |
| `/estateinfo` | `/t estateinfo` |
| `/provision` | `/t provision` |

Усі наступні аргументи збережено, наприклад `/t state status`,
`/t vassal help`, `/t castle inspect`. Українські назви також доступні:
`/t держава`, `/t васал`, `/t провізія` тощо. Окремі кореневі команди
з лівого стовпця більше не реєструються. Особисті `/trade`, `/wallet`,
`/currency`, `/bank`, `/exchange`, `/order` та службова `/commerce` працюють
як раніше. Перевірки посад і права `empirecraft.feudal.use` діють також
для нових шляхів та українських назв.

## Встановлення та перевірки

Зупиніть сервер, замініть `plugins/empirecraft-feudal-1.4.1.jar` файлом
із пакета й запустіть сервер. Клієнт оновлювати не потрібно. Пакет не
містить чинної конфігурації сервера, світів чи бази H2.

Перевірки: `python3 feudal/build.py`, `python3 provisions/test.py`,
а на Java 21 — `python3 provisions/test_claims.py` та
`python3 provisions/test_trade_towny.py`. Нові регресії використовують
справжню H2 і Towny 0.101.2.0: власні баланси, живі курси без списання,
округлення, відсутній курс, вкладені аргументи, українські назви,
автодоповнення, права та конфлікт команд. Повний Mohist-сервер і
графічний Minecraft-клієнт у цих тестах не запускаються.
