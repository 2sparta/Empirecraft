# Державні валюти Empirecraft 1.1.0

Курс кожної нової державної валюти: **V = R / M**, де R — фізичний золотий резерв у ЗО, M — сума всіх монет у гаманцях, скарбницях та інших внутрішніх рахунках. **1 ЗО = 1 звичайний золотий злиток Minecraft.**

## Встановлення та перехід з 1.0.0

1. Зупиніть сервер і збережіть копію `plugins/EmpirecraftFeudal/` та даних гравців світу.
2. Приберіть старий `empirecraft-feudal-1.0.0.jar` із `plugins/`; покладіть `empirecraft-feudal-1.1.0.jar`. У папці має бути один JAR цього плагіна.
3. Запустіть сервер і виконайте `/vassal admin check`.

Towny залишається обов’язковим. Vault потрібний лише для старої базової економіки BASE, а новий золотий облік працює без Vault. Плагін використовує наявні володіння, правителів, скарбниці, договори та H2.

Схема бази автоматично переходить з v1 на v2. Перед переходом створюється онлайн-копія H2 у `plugins/EmpirecraftFeudal/backups/before-currency-v2-*.zip`.

Наявна валюта з непогашеним випуском позначається `LEGACY_BASE`: власник може погасити її за старими умовами 1:1 у BASE. Новий випуск та міжвалютний обмін для неї вимкнено. **BASE ніколи не перетворюється на фізичне золото автоматично.** Після повного погашення випуску й резерву король виконує `/currency upgrade <код>` і вносить справжні злитки. Порожні старі валюти переходять на GOLD під час міграції. BASE продовжує працювати як раніше через `/wallet deposit|withdraw`.

## Швидкий початок для короля

Назви з пробілами вводьте через `_`. Для наведеного прикладу король має тримати 1500 звичайних золотих злитків у головному інвентарі:

```text
/currency create Крона KRN
/currency reserve deposit 1500 KRN
/currency mint 500 KRN
/currency info KRN
/wallet treasury держава:Русь withdraw 100 KRN
/currency pay ІншийГравець 10 KRN
```

Після першої емісії курс дорівнює 3 ЗО за монету. Наступний випуск `/currency mint 1000 KRN` збільшить обіг до 1500 і знизить курс до 1 ЗО. Золото при цьому не списується. Нові монети надходять до внутрішньої скарбниці емітента, звідки їх можна витрачати або переказувати.

|---|---|
| `/currency list` | Валюти й тип їх забезпечення |
| `/currency info <код>` | Назва, держава, обіг, резерв і курс |
| `/currency value <код>` | Інформація про золотий курс |
| `/currency reserve <код>` | Резерв, обіг і курс |
| `/currency audit <код>` | Порівняння обігу з сумою всіх рахунків |
| `/currency policy` | Правила емісії, резерву та округлення |
| `/currency pay <гравець> <сума> <код>` | Переказ без зміни обігу |
| `/currency history` | Останні 20 власних операцій, включно з отриманими переказами |
| `/currency history <код>` | Журнал валюти; лише її правитель або адміністратор |
| `/currency create <назва> <код> [держава]` | Одна валюта на державу; лише чинний король або адміністратор |
| `/currency mint <сума> <код>` | Випуск до скарбниці без вимоги нового золотого покриття |
| `/currency burn <сума> <код>` | Вилучення монет зі скарбниці емітента зі збереженням резерву |
| `/currency reserve deposit <цілі_злитки> [код]` | Фізичні злитки з інвентарю до державного резерву |
| `/currency reserve fund <сума_ЗО> [код]` | Золото з особистого рахунку короля до резерву, включно з дробами |
| `/currency upgrade <код>` | Перехід повністю погашеної старої валюти з BASE на GOLD |
| `/bank gold balance` | Особистий золотий рахунок |
| `/bank gold deposit <цілі_злитки>` | Злитки з інвентарю на особистий золотий рахунок |
| `/bank gold withdraw <цілі_злитки>` | Цілі злитки з особистого рахунку до інвентарю |
| `/bank gold pay <гравець> <сума_ЗО>` | Переказ золота без переміщення предметів |
| `/bank gold treasury <володіння>` | Золотий рахунок керованої скарбниці |
| `/bank gold treasury <володіння> deposit\|withdraw <сума_ЗО>` | Переказ між особистим золотом і скарбницею |
| `/bank redeem <сума> <код>` | Монети погашаються, золото зараховується на особистий рахунок |
| `/exchange quote <сума> <звідки> <куди>` | Поточний розрахунок без зміни рахунків |

Псевдоніми кореневих команд: `/валюта`, `/банк`, `/обмін`. Якщо інший плагін займає назву, використайте `/empirecraftfeudal:currency`, `/empirecraftfeudal:bank` або `/empirecraftfeudal:exchange`.

Старі команди `/wallet currency create <держава> <код> <назва> <символ>`, `/wallet currency mint <код> <сума>` і `/wallet currency redeem <код> <сума> [володіння]` збережені. Для GOLD випуск використовує нову формулу, а погашення повертає золото на рахунок. Для LEGACY_BASE погашення повертає BASE. Регіональні та архівні скарбниці також можуть погашати власні монети через стару команду з аргументом володіння.

## Обмін, дроби та резерв

Монети мають точність 0.01, золото — 0.000000000001 ЗО; обчислення використовують десяткові числа, без `double`. Нульові суми операцій, від’ємні значення, NaN, експоненти, надлишкова точність і переповнення відхиляються. Максимальний обіг однієї валюти — 9 000 000 000 000.00 монет.

Погашення обчислюється безпосередньо з R та M. Проміжні виплати округлюються вниз до точності золотого обліку, а повне останнє погашення забирає весь залишок резерву. Отже, неперіодичні дроби можуть змінювати курс на величину округлення; золото не створюється й не губиться.

При обміні вихідні монети спалюються, їх золоте забезпечення списується з першого резерву; забезпечення нових монет переходить до другого резерву, а нові монети зараховуються гравцеві. Комісія — **0**. Результат округлюється вниз до 0.01 монети; потрібне для них золото округлюється вгору до 12 знаків, решта золота надходить гравцеві на особистий рахунок. Це не дає емісії під час обміну розмивати забезпечення цільової валюти. Усі зміни обох резервів, грошової маси, рахунків і журналу проходять однією транзакцією H2. Помилка на будь-якому кроці відкочує всю операцію.

Резерв не є скарбницею. З нього немає звичайного переказу або видачі злитків, зокрема для адміністратора. Він зменшується лише при погашенні або перенесенні забезпечення під час обміну. Для державних витрат є монетна та окрема золота скарбниця.

При M=0 курс не визначений; для початку потрібен перший випуск. Дозволена емісія при R=0: ціна тоді нульова, а погашення та обмін вимкнені до поповнення резерву. Спалення всього обігу залишає резерв захищеним до нового випуску. Обмін у валюту з нульовим обігом, нульовим резервом або неактивною державою заборонений. Валюту зниклої держави можна погасити або обміняти на активну валюту.

Данина у валюті сюзерена підтримується чинними договорами: вкажіть її код у `/vassal offer`, обміняйте свої монети та поповніть внутрішню скарбницю васала цією валютою. Автоматична данина переказує монети, не змінюючи M; автоматичного обміну валют при списанні немає.

## Фізичні злитки й відновлення після збою

Банк приймає лише звичайні `GOLD_INGOT` без назви, lore та інших метаданих. Використовуються 36 клітинок головного інвентарю; золото в скринях, руці поза головним інвентарем, курсорі чи модових сховищах автоматично не враховується. За одну операцію — 1–2304 злитки. Видача відхиляється за нестачі місця: предмети не викидаються на землю. Дробова частина завжди залишається на золотому рахунку.

Інвентар Minecraft та H2 — два окремі сховища, тому між ними немає спільної атомарної транзакції. Перед зміною предметів плагін записує `PREPARED` з інвентарями до/після; для видачі золото резервується. Далі змінює інвентар, викликає збереження даних гравця та одноразово завершує фінансову операцію.

Якщо сервер упав або сталася помилка між кроками, нові операції цього гравця з фізичними злитками блокуються. Предмети не видаються повторно автоматично. Перевірка:

```text
/bank gold pending
/bank gold inspect <ID>
/bank gold resolve <ID> applied
/bank gold resolve <ID> failed
```

Останні три команди доступні адміністратору. `inspect` показує намір та збіг поточного онлайн-інвентарю зі збереженими станами; такий збіг є лише підказкою, адже гравець міг змінити речі після збою. Перевірте журнал і збережені дані гравця. `applied` означає, що предметна операція відбулася, `failed` — що не відбулася. Ці команди завершують тільки облік; предмети повторно не переміщуються. Відновлення резервної копії H2 слід узгоджувати зі станом даних гравців на той самий момент.

## Перевірки

`python feudal/build.py` перевіряє SHA-256 залежностей, компілює з Java `--release 17`, запускає 36 сценаріїв феодальної системи, 17 сценаріїв валют на справжній H2 і 4 перевірки планування інвентарю. Серед них — приклад 15000/5000, емісія, burn, обмін, дроби, відкат через помилку після списання, заборона витрати резерву, повторні операції, міграція v1, перезапуск та відновлення онлайн-копії.

Збірка використовує Spigot API 1.20.1 і Towny 0.101.2.0. **Живий запуск Mohist 71a84ff7 та перевірка збереження інвентарю на цьому ядрі не проводились.** Перед перенесенням на основний сервер перевірте внесення/видачу злитків і погашення на тестовій копії.
