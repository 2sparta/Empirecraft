# Удари по частинах тіла китів

Виправлення Accurate Hitboxes `2.4.2-empirecraft.1` для встановленого Wonderous Sea
та Better Combat 1.9.0 у Minecraft 1.20.1 / Forge 47.4.23 / Mohist 71a84ff7.

F3+B показував куби моделі далеко за звичайним хітбоксом кита. Але пошук цілей
Accurate Hitboxes спершу відбирав сутностей за звичайним центральним хітбоксом.
Better Combat додатково перевіряв саме його під час зіткнення зі зброєю,
а сервер перевіряв відстань до центрального хітбокса. Через це видимі хвіст,
голова й плавці могли залишатися недосяжними для удару.

Змінено:

- Пошук цілей Accurate Hitboxes для прицілювання та снарядів враховує морських
  істот Wonderous Sea, центральний хітбокс яких лежить поза початковою областю.
  Додатковий обхід обмежено 64 блоками виступу моделі; він працює тільки з уже
  завантаженими сутностями. Остаточне попадання й надалі перевіряється за кубами
  моделі, а не за великою суцільною коробкою навколо кита.
- Better Combat перевіряє перетин об'єму зброї з фактичними повернутими кубами
  моделі. Дальність, сектор атаки та видимість перевіряються за точками того
  самого перетину. Зберігаються налаштування відносин із мобами, комбо й шкоди.
- Серверні `canReach` / `canReachRaw` використовують частини моделі, уже
  синхронізовані Accurate Hitboxes, з його звичайним запасним blueprint.
  Значення дальності не збільшується. Перешкоди між гравцем і моделлю
  перевіряються на сервері; пошкодження проходить через звичайний пакет атаки
  та Forge-події, тому скасування атаки зберігається.
- Інші моди, ванільні сутності та відсутні/вимкнені модельні хітбокси
  використовують попередню поведінку. Розміри фізичного хітбокса кита,
  анімації, здоров'я й таблиці луту не змінюються.

Замінити старий `accuratehitboxes-neoforge-2.4.2-1.20.1.jar` новим
`accuratehitboxes-neoforge-2.4.2-empirecraft.1-1.20.1.jar` на клієнті та сервері
й повністю перезапустити обидві сторони. Готовий пакет у `dist/` містить мод
обох сторін та оновлений ADM. Better Combat і Wonderous Sea окремо не замінюються.

## Відтворення

Оригінальний JAR зафіксований SHA-256
`3463181daf0c64d4de531ef821bfad9215c9e67bef659a85fd4db804f479915f`.
Збірка використовує встановлені серверні бібліотеки й інструмент перетворення
мапінгів із `sails/tools/OfflineMappings.java`; завантаження сторонніх файлів
не потрібне. Компілювати з JDK 17:

```sh
python accurate-hitboxes/build.py
python accurate-hitboxes/test.py
python accurate-hitboxes/release.py --apply
python accurate-hitboxes/release.py --check
```

`smoke.py --java /path/to/java21` запускає окремий Mohist-світ. Тестовий мод
не входить до релізу. Він перевіряє справжні сутності, модельні хітбокси,
пакети атаки та снаряди. Виконуються геометричні перевірки Better Combat зі
справжнім об'ємом зброї й даними сутностей. Окремий тест застосовує клієнтські
Mixin до справжнього байткоду Better Combat без графічного вікна. Це не
замінює ручний ігровий тест графічного клієнта.
